# Pring 周期驾驶舱 V1 数据盘点

> 范围：只回答“有哪些数据”，不讨论看板布局、卡片、图表或视觉设计。  
> 基线：[V1冻结指标目录](v1-metric-catalog.md)。  
> 注意：新项目目前处于规划阶段。下文“可取”表示来源能力和口径已经确认，不表示新项目数据库已经完成采集。

## 1. 数据分为四类

1. **来源数据**：TuShare或认证官方来源取得的原始行情、宏观值和政策事件。
2. **派生数据**：由固定公式从来源数据计算，例如120日趋势、信用脉冲和订单－库存差。
3. **状态数据**：正式阶段、核心资产状态、转折观察、宏观确认和库存周期解释。
4. **治理数据**：发布时间、系统可用时间、来源、修订、冲突、时效、模型版本和获取状态。

冻结目录共有**61组指标定义**，另有阶段、趋势、时效、血缘和运行状态等系统派生数据。

## 2. 正式周期与趋势数据

### 2.1 Pring阶段数据

- 当前正式阶段：Stage I–VI或空；
- 上一确认阶段；
- 债券、股票、商品三资产牛熊组合；
- 非典型组合；
- 阶段开始、结束和持续交易日；
- 阶段变化事件；
- P0缺失、陈旧、冲突或初始化不足造成的不可判定区间；
- 数据快照、模型版本和趋势规则版本。

### 2.2 每个核心资产的趋势数据

- 原始OHLC、前收和官方涨跌幅；
- 连续收益链；
- 30交易日收益；
- 120交易日收益；
- MA120；
- 价格相对MA120距离；
- 最近20日波动率`σ20`；
- `1.5 × σ20`噪声带；
- MA120的20交易日斜率；
- 120日稳定牛/熊状态；
- 候选方向、候选持续天数和8日确认要求；
- `transition_pending`及冲突持续时间；
- 30日快速方向和转折观察；
- 月末价格、12月均线和独立12M代理状态；
- 30日、120日、12M之间的方向背离。

## 12. 可形成的宏观与库存状态数据

### 12.1 政策方向

- 宽松；
- 收紧；
- 中性；
- 政策行动与市场传导冲突；
- 数据不足。

证据分为政策行动、市场传导、信用响应三层。

### 12.2 过热程度

- 升温；
- 过热；
- 降温；
- 数据不足。

由订单、生产、产能、利润和信用解释，不形成阶段票。

### 12.3 物价压力

- 上游压力；
- 生产端扩散；
- 消费端扩散；
- 回落；
- 数据不足。

观察链为：商品/原油 → PMI价格 → PPI生产资料 → PPI生活资料 → CPI → 核心CPI。

### 12.4 库存周期

- 主动去库存；
- 被动去库存；
- 主动补库存；
- 被动补库存；
- 数据不足或证据冲突。

库存证据还分为七类：订单－库存差、原料－产成品关系、实际库存、库销/周转、价格－利润、产能、信用/注册仓单。七类不合成库存总分。

## 13. 数据质量、状态与血缘

每组数据还可以提供：

- 最新值、上一期、环比、同比和累计值；
- 统计期及120日证据窗口覆盖关系；
- `current`、`awaiting_release`或`stale`时效；
- 获取成功、尚未发布、无权限、限频、源失败或校验失败；
- 规范观测为`selected`、`conflicted`或`unavailable`；
- `reported_value`、`not_applicable`或`not_disclosed`；
- 来源认证状态；
- 主来源和认证后备声明；
- 容差和来源冲突；
- 首发、修订、回填和撤回vintage；
- 指标定义、公式、模型和规则版本；
- 来源URL、内容哈希和派生输入血缘。

## 14. 运行与获取数据

系统运行后还会形成：

- 数据刷新任务、报告任务和恢复任务；
- 任务排队、领取、心跳、完成、失败和重试；
- TuShare、官方直连、Tavily、Exa和受限AI的逐级获取结果；
- 每级耗时、错误分类、负缓存和下一重试时间；
- 单发布事件、单次运行和每日检索预算；
- 来源健康和最近成功时间；
- 报告快照、证据包、正文哈希和AI适配器版本。

这些是运行与审计数据，不属于宏观指标，也不参与阶段判断。

## 15. 明确不纳入的数据

- 生猪`LH`；
- 燃料油`FU`、低硫燃料油`LU`、沥青`BU`、LPG`PG`；
- 国内黄金作为商品核心或验证；
- 沪深港通资金流、ETF份额和新闻情绪；
- 未冻结的细行业宏观分项；
- 用FXCM黄金或原油替代COMEX、LBMA或EIA标准数据；
- 用ETF或综合指数替代VIX和SOX；
- 十年全市场广度；V1只计算最近120个交易日及必要预热。
