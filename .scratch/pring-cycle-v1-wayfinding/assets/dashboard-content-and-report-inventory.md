# Pring 周期驾驶舱：数据与报告内容清单

> 用途：作为 Markdown 页面契约和后续 Open Design 的内容输入。  
> 状态：设计前内容盘点；不包含视觉、布局尺寸、配色或 Dash 实现。  
> 数据基线：[V1 冻结指标目录](v1-metric-catalog.md)、[point-in-time 证据模型](point-in-time-evidence-model.md)和[120日趋势状态机](../issues/06-calibrate-120d-trend-state-machine.md)。  
> 报告边界：本文件只描述报告要消费和展示的信息块；AI输入输出协议由“验证双 AI CLI 的证据报告协议”单独决定。

## 1. 必须始终成立的内容规则

1. **正式阶段只有 Stage I–VI**，并且只由债券、股票、商品三个120日稳定核心资产状态机械映射。
2. **资产候选状态与转折观察不是候选阶段**。页面和报告禁止使用“预计进入Stage X”“最接近Stage X”或“候选阶段”。
3. 政策、库存、过热和通胀只形成**转折观察**或**宏观事后确认**，不能投票、否决或改写正式阶段。
4. `current_stage=null`时，主内容必须显示“当前阶段暂不判定”；`last_confirmed_stage`只能作为历史上下文。
5. 当前驾驶舱默认读取同一份完整`system_as_of`投影。刷新期间保留上一完整投影，不拼接新旧卡片。
6. 页面证据窗口是最近120个中国交易日覆盖的日期范围。月频和季频只显示该范围内已经发布的观测及必要上期/同比基线，不要求120条。
7. 低频旧值沿用时保留原统计期、发布时间、年龄和时效，不每天复制成新数据。
8. 搜索结果和AI文字不是证据。只有通过来源、统计期、单位、字段、发布时间与质量校验的观测可以进入页面和报告。
9. 不显示资产配置权重、买卖建议、收益承诺或让AI生成正式阶段。
10. 生猪`LH`及已明确排除的燃料油、低硫燃料油、沥青和LPG不进入V1页面或报告。

## 2. 全局内容外壳

所有当前页面共用以下顶部信息；历史快照使用单独的只读历史标识。

| 字段 | 用途 |
| --- | --- |
| `projection_set_id` / `projection_version` | 证明当前页面属于哪一套完整投影 |
| `system_as_of` | 当前页面实际可使用证据的截止时间 |
| `data_snapshot_id` | 本次结构化数据快照身份 |
| `model_version` / `trend_rule_version` | 正式阶段和趋势规则版本 |
| `evidence_window_start/end` | 最近120个中国交易日定义的页面范围 |
| `generated_at` | 投影完成时间，不冒充数据发布时间 |
| `refresh_state` | 空闲、排队、运行、部分失败或完成 |
| `completeness` | 完整、降级或无法形成当前阶段 |
| `global_warnings` | P0缺失、来源冲突、来源未认证、报告失败等 |

导航内容分为：

- **周期判断**：首页、核心资产、宏观证据、库存特征、阶段历史。
- **运行与追溯**：发布日历、报告、运行状态。
- **证据追溯**不是一级导航；从指标、阶段事件、报告引用或错误状态进入。

## 3. 页面内容总览

| 页面 | 回答的问题 | 首要内容 | 不应出现 |
| --- | --- | --- | --- |
| 首页 | 当前正式阶段是什么，为什么当前可判或不可判？ | 正式阶段、三核心资产、转折观察、宏观确认、时效和变化摘要 | 候选阶段、宏观总分、配置建议 |
| 核心资产详情 | 某一核心资产的120日状态如何形成？ | 核心序列、趋势条件、候选持续、30日、12M及确认指标 | 用确认指标替换核心票 |
| 宏观证据 | 政策、过热、价格与国际环境如何解释周期？ | 三个独立国内状态及P2国际背景 | 综合宏观投票或单一景气分 |
| 库存特征 | 当前更接近哪种库存行为，证据是否一致？ | 四象限解释、七张特征卡、冲突和时效 | 库存总分、把名义库存当实物库存 |
| 发布日历 | 哪些数据已发布、待发布、延迟或抓取失败？ | 预期窗口、实际事件、首次可用、宽限和状态 | 把计划日当实际发布时间 |
| 阶段历史 | 历史正式阶段、空档和资产状态如何变化？ | 阶段区间、非典型/不可用空档、变化事件和版本 | 强行连续填充阶段 |
| 报告 | 哪份不可变报告对应哪套证据和规则？ | 报告列表、状态、正文、证据引用和快照元数据 | 打开历史报告时重新生成 |
| 运行状态 | 数据更新和检索链路是否健康？ | 任务、来源、预算、缓存、失败和下一动作 | 密钥、Authorization、完整外部响应 |
| 证据追溯 | 一个值从哪里来、何时可用、是否修订或冲突？ | 观测、来源声明、vintage、发布时间和血缘 | 用抓取时间代替发布时间 |

## 4. 首页内容

首页必须按以下层级排列；这里的顺序也是语义优先级。

### 4.1 正式阶段区

| 内容 | 说明 |
| --- | --- |
| `current_stage` | Stage I–VI或空；空时显示“当前阶段暂不判定” |
| `stage_started_at` / `duration_trading_days` | 当前正式阶段起点和持续交易日 |
| `last_confirmed_stage` | 仅在当前为空或需要历史比较时次级显示 |
| `stage_mapping` | 债/股/商三状态组合与机械映射，不显示宏观打分 |
| `stage_change_from_previous_projection` | 是否较上一完整投影发生变化及确定性原因 |
| `stage_unavailable_reason` | 非典型组合、P0缺失/陈旧/冲突、初始化不足等 |

### 4.2 三核心资产摘要

每类资产一张摘要卡，共同字段如下：

- 资产名称、核心指标、代码、价格口径；
- 120日稳定状态：`bullish`、`bearish`或`unavailable`；
- `transition_pending`、候选方向和候选持续天数；
- 30日收益、120日收益；
- 价格相对MA120距离、1.5σ噪声带和20日均线斜率；
- 最近稳定状态变化日；
- `freshness_status`、`selection_status`与来源机构；
- 进入资产详情和查看证据的入口。

### 4.3 转折观察

按资产或转换方向列出已经触发的观察，不生成“下一阶段预测”。每条至少包括：

- 观察名称和目标资产；
- 证据角色：30日价格、广度、政策、订单、库存或价格拐点；
- 当前方向、开始时间、持续时间；
- 支持证据和反证；
- 时效、缺失和冲突；
- 明确声明“不改变正式阶段”。

### 4.4 宏观事后确认摘要

只摘要以下独立结论：

- 政策方向：宽松、收紧、中性、传导冲突或数据不足；
- 过热程度：升温、过热、降温或数据不足；
- 物价压力：上游压力、生产端扩散、消费端扩散、回落或数据不足；
- 库存周期解释：四象限之一、冲突或数据不足；
- 国际环境：只列显著风险/通胀背景和数据缺口，不形成中国阶段票。

### 4.5 数据与报告状态

- P0/P1/P2的缺失、陈旧和来源冲突数量；
- 下一重要发布事件；
- 当前刷新任务状态及上一完整投影时间；
- 最新报告状态：可读、生成中、失败或30天正文已过期；
- “较上一完整投影为何变化”的结构化原因列表。

## 5. 核心资产详情数据

### 5.1 共同趋势内容

| 组 | 字段/序列 |
| --- | --- |
| 核心身份 | `metric_id`、名称、代码、来源、价格/收益口径、认证状态 |
| 120日正式轨道 | 连续收益链、原始收盘、MA120、距离、σ20、1.5σ带、20日斜率、稳定状态 |
| 候选状态 | 候选方向、已持续/要求持续天数、最近中断原因、冲突持续天数 |
| 30日观察 | 30日趋势、收益、快速方向、持续时间及其转折观察 |
| 12M代理 | 最近月末价格、12月均线、月频状态、与120日是否背离 |
| 变化记录 | 最近状态变化、候选开始/取消、P0不可用和规则版本变化 |
| 数据质量 | 统计日、available_at、freshness、来源冲突、缺口和点位调整 |

图表数据必须由只读投影提供；浏览器不重新计算均线、噪声带、状态或阶段。

### 5.2 股票专属内容

- 正式核心：`CN_EQUITY_CORE_000985`中证全指。
- 交叉确认：沪深300、中证500、中证1000；均明确标记“不投票”。
- 市场广度：上涨/下跌/平盘家数、涨跌差、涨跌比、120日新高/新低、MA120上方比例、上涨股票成交额占比。
- 风险偏好：融资余额和融资买入额，按T+1真实可用时间展示。
- P2估值：主要指数PE、PB、股息率和换手率；缺字段时不补0。

### 5.3 债券专属内容

- 正式核心：`CN_BOND_CORE_000012`上证国债指数，按债券价格方向解释。
- 价格确认：`000012CNY030.CSI`国债全价指数、`930916.CSI`约10年国债指数。
- 收益率/利率只作反向或环境说明，不得把收益率上涨写成债券上涨。
- 市场传导关联：DR007、逆回购利率、两者利差和Shibor；它们不替代债券核心。
- 未来迁移到财富指数只能显示为模型版本变化，不在当前页面动态择优。

### 5.4 商品专属内容

- 正式核心：`CN_COMMODITY_CORE_NHII`南华工业品指数。
- 外部宽基确认：`CN_COMMODITY_BROAD_NHCI`，明确“不投票”。
- 七袖套：铜、螺纹、聚丙烯、棉花/PTA、橡胶、纸浆、原油的方向和贡献；当后备篮子成为核心时不得再用于自我确认。
- 注册仓单只称交易所注册仓单，不称产业总库存。
- 页面不出现生猪或已排除的燃料油、低硫燃料油、沥青、LPG。
- 新年度/临时成分文件的无生猪审计状态必须可追溯。

## 6. 宏观证据数据

### 6.1 政策方向

**政策行动**

- 7天逆回购操作利率；
- 操作量、到期量和派生净投放；
- 降准/升准事件的公告日、生效日、幅度和范围；
- 各类央行工具月度投放；
- 正式政策表述只作为带来源的事件，不压成每日数值。

**市场传导**

- DR007加权利率；
- DR007－7天逆回购操作利率利差；
- Shibor隔夜、1周、3月；
- 债券价格和收益率方向说明。

**信用响应**

- LPR 1年和5年以上；
- M1/M2余额、同比与环比；
- 社融增量、累计与存量；
- 社融结构、贷款结构和信用脉冲。

三层分别显示“方向、最新变化、统计/事件时间、时效、冲突和来源”，不能合成一个政策分数。

### 6.2 过热程度

- PMI制造业、生产、新订单和采购量；
- 工业增加值当月/累计实际同比与季调环比；
- 产能利用率及同比百分点；
- 工业利润、营业收入和成本的官方同比；
- 社融、贷款结构和信用脉冲；
- 股票/商品周期广度只作市场交叉说明。

状态只允许：升温、过热、降温、数据不足。若证据分裂，应显示冲突来源而不是平均。

### 6.3 物价压力

按照传导层级展示：

```text
商品/原油 → PMI购进与出厂价格 → PPI生产资料 → PPI生活资料 → CPI → 核心CPI
```

具体数据包括：

- NHII、NHCI和EIA Brent/WTI方向；
- PMI主要原材料购进价格、出厂价格；
- PPI总项、生产资料、生活资料的环比和同比；
- CPI总项的环比、同比、累计平均；
- 核心CPI扣除食品和能源后的环比、同比、累计平均同比。

核心CPI是消费端滞后确认；能源不是核心CPI组成，不得写成直接等同关系。

### 6.4 国际环境（全部P2）

| 内容 | 标准口径 | 当前来源状态/限制 |
| --- | --- | --- |
| 纽约金 | COMEX GC活跃月官方结算 | 接入/许可认证前显示`awaiting_source_certification` |
| 伦敦金 | LBMA Gold Price PM美元价 | 接入/许可认证前显示`awaiting_source_certification` |
| 国际原油 | EIA Brent现货为主、WTI现货为辅 | 官方直连接入；不使用停更FXCM油价 |
| 美债 | 2Y、10Y名义收益率和2s10s利差 | TuShare可取；明确是收益率，不是债券价格 |
| 波动率 | Cboe现金VIX | 官方适配器认证前显示待认证；禁用VOLX替代 |
| 半导体 | Nasdaq PHLX SOX | 官方接口/授权认证前显示待认证；禁用ETF或综合指数替代 |

P2失败到Exa为止，不进入AI WebSearch，不影响中国正式阶段或页面整体可用性。

## 7. 库存特征内容

库存页面使用四象限解释和七张独立特征卡。证据不足或冲突时不强行分类，也不输出库存总分。

| 特征卡 | 主要数据 | 必须说明 |
| --- | --- | --- |
| 订单－库存差 | 新订单－原材料库存、新订单－产成品库存 | 项目派生、公式版本、同一期PMI输入 |
| 原料－产成品关系 | PMI原材料库存、产成品库存、采购量 | PMI是扩散指数，不是库存数量 |
| 实际库存 | 产成品存货余额/同比及PPI近似调整 | 名义金额与价格调整结果并列 |
| 库销与周转 | 产成品周转天数、营业收入、库存关系 | 不用不可比金额静默重算官方同比 |
| 价格－利润 | PMI价格、PPI、工业利润率/利润变化 | 成本冲击与需求改善分别说明 |
| 产能 | 产能利用率、生产－新订单差 | 季度数据只在实际发布后更新 |
| 信用与实物库存 | M1、企业中长期贷款、信用脉冲、七袖套相关注册仓单 | 注册仓单不代表全部产业库存 |

四象限内容：

- 主动去库存：需求弱、生产采购主动收缩、库存随后下降；
- 被动去库存：需求先回升、生产尚未完全跟上、库存下降/库销改善；
- 主动补库存：订单、生产和采购扩张，库存有序回升；
- 被动补库存：需求转弱、生产调整滞后，产成品库存或周转压力上升。

## 8. 发布日历内容

### 8.1 日历事件字段

- 指标或真实发布族；
- `expected_window_start/end`及其规则来源；
- `release_at`、`public_available_at`、`available_at`；
- 统计期、频率和来源时区；
- 当前值是否仍为上一期；
- `freshness_status`、最近获取结果和宽限期；
- 关联的实际发布事件与证据观测数量；
- 下一计划检查时间。

### 8.2 事件类型

- 中国交易日与盘后核心行情完成窗口；
- T+1数据；
- 有官方日程的月/季发布；
- 无固定日期但每月发布的数据；
- 稀疏政策行动；
- 国际市场日频发布。

计划日程只用于预期和监控。页面必须把“预计”“已实际发布”“系统已取得”作为三个不同时间状态。

## 9. 阶段历史内容

- Stage I–VI正式阶段区间及开始/结束事件；
- 每日债、股、商品稳定状态；
- 非典型组合区间；
- P0缺失、陈旧、冲突或初始化不足造成的空档；
- `last_confirmed_stage`只作为空档上下文；
- 资产候选开始、完成、取消和冲突事件；
- 30日观察与12M代理的独立状态及背离；
- `data_snapshot_id`、`model_version`、`trend_rule_version`和投影版本；
- 打开某个历史点时进入不可编辑的快照/证据追溯，不改变当前页面。

## 10. 报告内容清单

### 10.1 报告列表

每条列表记录至少包括：

- 报告业务日与`report_cutoff`；
- 报告快照ID和同日版本号；
- 状态：排队、生成中、完成、失败、取消、确定性简版；
- `current_stage`或“暂不判定”；
- 生成适配器：Codex CLI、Claude Code CLI或确定性模板；
- 生成时间、耗时、证据包哈希、模型/提示词/schema版本；
- 正文是否仍在30天保留期；
- 数据/AI失败摘要。

### 10.2 报告正文信息块

1. **报告身份与截止点**：业务日、120日证据窗口、`system_as_of`、快照和版本。
2. **一句话结论**：当前正式阶段或暂不判定，以及最关键的确定性原因；不含交易建议。
3. **正式阶段依据**：债/股/商三个120日稳定状态和机械映射。
4. **三核心资产分析**：核心趋势、候选持续、30日观察、12M背离和确认指标。
5. **转折观察**：正在观察的资产方向、领先证据、反证和持续时间；禁止称下一阶段预测。
6. **货币政策链**：政策行动、市场传导、信用响应分别解释。
7. **库存与过热**：四象限库存解释、七张特征卡、订单/生产/产能/利润及冲突。
8. **物价传导**：商品/原油、投入品、PPI、CPI和核心CPI的分层变化。
9. **国际环境**：纽约金、伦敦金、原油、美债、VIX和SOX；仅作为P2背景。
10. **较上一报告为何变化**：新观测、修订、核心资产越阈值、候选完成/取消、来源/规则版本变化分别列出。
11. **数据质量与缺口**：未发布、陈旧、冲突、源失败、未认证和检索预算耗尽。
12. **证据与来源**：关键陈述绑定`evidence_observation_id`或已验证来源URL。

### 10.3 报告禁止项

- AI新增、推测或改写`current_stage`；
- 把转折观察写成“即将进入Stage X”；
- 资产配置比例、买卖建议、目标价和收益承诺；
- 使用证据包之外的自由搜索事实；
- 暴露token、API key、Authorization、内部路径或完整提示词；
- 把报告生成失败解释为数据失败，或反过来；
- 打开旧报告时用最新数据重写正文。

### 10.4 AI失败时仍需可读的内容

若两个AI CLI都失败，确定性简版仍输出：报告身份、正式阶段、三资产状态、转折观察、三个宏观状态、重要缺口、下一发布事件和证据入口。驾驶舱数据更新不受报告失败阻塞。

## 11. 运行与检索状态内容

### 11.1 任务状态

- `run_id`、`job_id`、任务类型、幂等键；
- 计划/排队/领取/心跳/完成时间；
- 当前步骤、完成比例或不可量化标识；
- 尝试次数、错误分类、是否可恢复和下一重试；
- 关联的新投影版本或报告快照。

### 11.2 来源与检索

- 指标/实际发布事件、P0/P1/P2、是否应该已发布；
- 本地、TuShare、官方直连、Tavily、Exa、受限AI的逐级结果；
- 每级延迟、失败分类、负缓存和下一重试；
- 单事件、单运行、每日预算使用与剩余量；
- 来源认证状态、最近成功时间和连续失败次数；
- 全链路失败对正式阶段、转折观察或P2卡片的影响；
- 用户显式手动深搜及预算豁免审计。

运行状态不得显示密钥、请求认证头、未脱敏外部正文或报告AI内部提示上下文。

## 12. 证据追溯内容

从任何指标或报告引用进入时，至少显示：

- 指标定义版本、标量含义、单位、频率和证据角色；
- 观测身份、观测版本、统计期与规范维度；
- 值和合法`value_state`；
- 来源机构、来源声明、制品版本与已验证URL；
- `release_at`、`public_available_at`、`fetched_at`和`available_at`；
- freshness、选择状态、质量和来源认证状态；
- 其他来源声明、容差和冲突；
- 修订链、被替代版本和是否回填；
- 派生公式版本、确切输入观测版本和计算截止点；
- 被哪些阶段事件、页面投影和报告快照引用。

## 13. 状态与空状态文案矩阵

| 条件 | 保留展示 | 必须说明 | 业务影响 |
| --- | --- | --- | --- |
| 新一期尚未发布 | 上一期值 | 统计期、年龄、预计窗口、`awaiting_release` | 不搜索；按角色继续或降级 |
| 超过宽限仍无新值 | 上一期值 | `stale`及最后成功时间 | P0冻结新阶段；P1不能当前确认；P2仅背景 |
| 获取失败 | 上一有效值或空 | 失败渠道、错误分类、下一重试 | 与freshness分开表达 |
| 来源冲突 | 主/备声明和差异 | 容差、选择状态、来源 | P0不产生新阶段；P1不确认；P2带警告 |
| 合法未披露/不适用 | 不显示0 | `not_disclosed`或`not_applicable`及来源 | 是合法来源声明，不是抓取失败 |
| 来源尚未认证 | 不显示代理值 | `awaiting_source_certification`及缺少的认证项 | 指标暂缺，不静默替代 |
| 非典型三资产组合 | 原始三资产状态、上一确认阶段 | `current_stage=null`、组合和起始日 | 不近似映射 |
| P0初始化不足 | 已有价格和预热进度 | 缺少的窗口/持续期 | 当前阶段为空 |
| 报告生成中/失败 | 完整结构化驾驶舱 | AI任务状态和简版入口 | 不阻塞投影发布 |
| Web轮询失败 | 上一完整投影 | 连接/读取失败和最后成功读取时间 | 不清空页面 |

## 14. 建议的卡片最小字段

Open Design可以按内容密度设计不同组件，但任何指标摘要至少保留：

```text
title
primary_value + unit 或 value_state
period_label
comparison_value / mom / yoy（适用时）
direction_or_role
freshness_status + age
quality_or_conflict
source_authority
evidence_trace_action
```

核心资产卡另加稳定状态、候选持续、120日关键阈值距离和阶段权限；发布事件卡另加预计/实际/系统可用三个时点；运行卡另加任务状态、预算和下一动作。

## 15. 仍需在“定义 Markdown 页面与只读投影契约”确认的事项

1. 是否采用同一`projection_set_id`下的多个页面投影，而不是巨型JSON。
2. 核心资产详情是否采用共同骨架加资产专属模块。
3. 宏观证据是否固定为政策方向、过热程度、物价压力和P2国际环境四个独立分区。
4. 库存页面是否允许输出四象限解释性状态，同时坚持七卡无总分。
5. 阶段历史是否显示正式区间、非典型/不可用空档和每日三资产状态。
6. 页面刷新、单指标补取、手动深搜和报告重跑的动作权限与确认方式。
7. 每个投影的字段schema、分页、时间序列下采样和错误封装。

以上事项确认后，本文件可以直接成为Markdown页面契约和Open Design内容输入；视觉层不得改变其中的阶段权限、状态含义和证据边界。
