# 冻结 V1 指标目录与证据角色

## Question

在 TuShare 能力审计和官方补源核验完成后，V1 的确切指标集合是什么？为每个指标锁定唯一规范名称、领域角色、P0/P1/P2优先级、原始字段、派生公式、单位、频率、发布时间、`available_at` 规则、新鲜度、主来源、降级来源、页面位置，以及它能否参与核心状态、转折观察或宏观确认。哪些候选指标明确延后到下一模型版本？

## Answer

已冻结[V1指标目录](../assets/v1-metric-catalog.md)。目录按“角色驱动”而不是“接口可取即纳入”收录指标，并锁定规范名称、P0/P1/P2、证据角色、原始字段或派生公式、频率、时点、新鲜度规则、来源、降级、页面位置和阶段影响。

核心决策：

- 产品和报告使用120日证据窗口；月季指标只取窗口覆盖期内已发布值和必要比较基线，不要求120条连续观测。更长历史只允许三类核心价格离线校准；市场广度不做十年回填。
- 股票核心仍为中证全指，交叉确认改为沪深300、中证500和中证1000；市场广度保留最近120个交易日和必要预热。
- 债券核心、政策行动、市场传导和信用响应分层；`yc_cb`无权限不阻塞V1。
- 商品核心为NHII，去生猪七袖套只作预认证后备；删除FU/LU/BU/PG内部燃料观察，能源仅保留SC。
- PMI、通胀、工业、库存、产能、货币和信用采用有限白名单；指标可用不等于自动进入目录。
- 国际环境加入纽约金COMEX GC结算、伦敦金LBMA PM、EIA Brent/WTI、美债2Y/10Y与2s10s、Cboe VIX、Nasdaq SOX。国际指标全部P2，不改变中国正式阶段或宏观确认。
- COMEX/LBMA、VIX、SOX及CFETS 16:30等渠道未完成授权和账号验收前使用`awaiting_source_certification`，禁止用FXCM、ETF、CFD或相似序列静默替代。
