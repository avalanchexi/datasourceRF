# 提取旧项目回归场景与迁移边界

## Question

在只读旧项目且不把旧报告当真值的前提下，整理可以移植的接口经验、真实数据缺口和行为级失败场景，形成新版必须覆盖的回归案例。至少核验商品牛市条件不可达、缺失默认高分、Neutral转熊、全不确定映射Stage VI、非典型近似映射、债券收益率方向、宏观改写阶段、月季数据前视和期货换月假拐点，并明确哪些旧代码绝不迁移。

## Answer

已完成旧项目只读静态审计，并冻结[旧项目回归场景与迁移边界](../assets/legacy-regression-cases-and-migration-boundaries.md)。

结论是只迁移结构化适配器、追加式证据、租约/幂等、原子写入和离线重放等行为契约；不迁移旧 Stage 文件流水线、评分分类器、Neutral 布尔化、宏观/货币改写、代理核心、宽 JSON 日期语义、旧报告/golden 或直接模型 API 路径。资产定义了 35 个 `REG-*` 回归案例，覆盖题目要求的九类已知故障，并补充核心身份、P0 门控、修订不可变、任务/结果身份、崩溃恢复和 CLI 降级边界，作为 12 号实施与验收计划的强制输入。
