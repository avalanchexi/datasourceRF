# 验证检索降级链的预算与缓存参数

## Question

以冻结后的 P0/P1/P2 指标缺口为样本，Tavily、Exa和受限AI WebSearch的最小查询、命中率、延迟、失败分类与消耗基线是什么？原型需要据此决定单指标、单次运行、每日及单渠道硬预算，搜索摘要和页面片段上限、负缓存重试窗口、发布事件合并策略，以及全链路失败时的可观测输出；不得让报告AI绕过该链路。

## Answer

已接受[检索预算与缓存逻辑原型](../prototypes/retrieval-budget-prototype.html)，并冻结为V1初始参数：检索严格按本地证据、TuShare、认证官方直连、Tavily、Exa、受限AI WebSearch顺序串行执行；预算身份是一次实际`release_event_id`，不是其中每个指标。一次联合发布可以拆成多条规范观测，但只消耗一次事件查询。

单事件硬预算为Tavily 1次、Exa 1次、AI WebSearch 1次，P2的AI预算恒为0；单次运行预算为8/4/1次；每日预算为16/8/2次；自动关键词改写为0次。搜索最多返回3条候选、摘要合计1,800字符，只有选中的认证官方页面可向确定性解析器提供最多1,600字符片段。搜索结果只是候选，必须再通过官方域名、统计期、单位、字段、发布时间和point-in-time校验，任何AI都不能直接写入值。

未发布时不搜索，沿用上一期并显示数据年龄。402/403按明确配额重置时间或次日00:05重试，429服从`Retry-After`或等待60分钟，超时/网络/5xx负缓存15分钟，空结果和统计期、单位、语义或值校验失败按P0/P1 6小时、P2 24小时负缓存；同一事件同一渠道当日仍只允许一次自动请求。链路失败时，P0冻结新阶段并保留`last_confirmed_stage`，P1旧值仅展示且不能验证当前转折，P2显示暂缺并在Exa后停止。

每次尝试必须记录任务、发布事件、指标列表、priority、as-of、渠道、延迟、结果分类、预算余量、缓存与下一重试时刻，禁止记录密钥或未脱敏认证信息。原始搜索响应保留30天，已验证观测、来源URL、内容指纹和审计长期保存。报告AI只能提交结构化缺口请求，不能持有凭据、直接调用检索渠道或绕过验证写证据。

2026-08-21脱敏探针中，Tavily 3/3和Exa 2/2均返回限定官方域且覆盖预设语义组，中位延迟分别为2.713秒和1.638秒；AI WebSearch因链路未触发而保持0调用。该样本只证明初始预算和降级逻辑可运行，不代表生产命中率；真实运行后的任何参数调整必须版本化并保留变更原因。原型纯逻辑自测8/8通过。
