# 校准 120 日趋势状态机与稳定性门槛

## Question

在已认证的核心历史和 point-in-time 语义上，哪套确定性规则最适合 120 交易日正式轨道？通过无前视原型比较价格相对趋势线、趋势线斜率、持续期、滞回宽度和冲突保持规则，量化阶段抖动、确认延迟、参数敏感性、非典型组合和典型失败区间，并形成可实现的默认参数与再校准规则。30日观察与12个月代理必须独立评估，不能投票合并。

## Answer

用户于2026-08-21确认先以原型推荐规则进入实现与实际影子测试，测试后允许按版本化流程调整；本结论是V1的**暂定默认值**，不是永久不变参数。

[120 日趋势状态机逻辑原型](../prototypes/120d-trend-state-machine-prototype.html)使用2018-06-01至2026-08-19的1,995个三资产共同交易日执行只用当日及过去数据的稳定性比较。它不用旧报告、未来收益或宏观叙事充当正确标签，因此结果只能证明规则的抖动、延迟和尺度性质，不能声称识别了不可观测的“经济真阶段”。

### 120日正式轨道暂定规则

1. 生产计算序列按官方`change/pre_close`构造连续收益链；原始`close`、`pre_close`、调整标记与官方日收益并列保存和展示。当前严格校准区间中，原始点位与连续收益链的稳定状态一致率为100%，但仍采用收益链避免未来供应方点位调整静默影响趋势。
2. 以当日及此前120个有效交易日计算简单移动均线`MA120`；以`MA120(t) / MA120(t-20) - 1`定义20交易日均线斜率。
3. 以连续收益链最近20个有效日收益的总体标准差`σ20`定义资产自身噪声尺度，滞回带`H = 1.5 × σ20`。不采用三资产统一百分比：统一1%规则在严格区间让债券出现0次转换，尺度失衡。
4. 当`price / MA120 - 1 >= H`且均线斜率大于0时形成牛向候选；当距离小于等于`-H`且斜率小于0时形成熊向候选。候选必须连续满足8个有效交易日才更新核心资产稳定方向；中断或回到噪声带即清零候选天数。
5. 价格位置与斜率反向时，清零候选、保留上一稳定方向并持续标记`transition_pending`，不设置固定冲突过期日。只有相反方向完成8日确认，或P0核心数据失效，才结束沿用。历史上20日冲突过期会让20.15%的共同日期失去完整阶段，故不采用。
6. 初始化或规则版本切换必须先取得120日均线、20日斜率与波动计算所需预热；在新方向完成8日确认前，当前资产状态为空，不能把未初始化状态折算为熊市。

该规则在严格区间产生21次三资产方向转换、0次20交易日内快速资产反转、11次正式阶段变化、0次20交易日内快速阶段变化；相对价格首次穿越均线的中位确认延迟为23个交易日。项目选择用这部分速度换稳定性，因为30日轨道会单独承担早期观察。

### 阶段、冲突与独立轨道

- 只有三个120日稳定方向机械映射Stage I–VI。`债牛/股熊/商牛`与`债熊/股牛/商熊`均为非典型组合，`current_stage=null`并保留`last_confirmed_stage`；不近似匹配、不创建Stage VII/VIII。
- 任一P0核心序列缺失、陈旧、冲突或校验失败时，对应当前资产状态不可用，`current_stage=null`；历史稳定方向和`last_confirmed_stage`只作上下文，30日、12M、宏观或代理数据不得顶替。
- 30日轨道每日独立计算快速方向和持续天数，只产生`transition_watch`。裸30日均线穿越在严格区间分别出现债34次、股190次、商品186次，证明它不适合成为另一张阶段选票。
- 公开Pring 12M代理只在月末用月末价格相对12个月简单均线独立更新。它与120日轨道并列展示分歧，不平均、不投票、不在月中改写月末状态。

### 实际测试与再校准

- 当前参数作为实现和影子运行默认值；实际测试必须同时展示候选天数、噪声带距离、均线斜率、冲突天数、稳定方向和阶段原因，便于定位误判来自数据、尺度还是状态逻辑。
- 试运行发现问题时可以提出调整，但不得针对单份报告即时调参。调整必须形成新的规则候选，重跑开发段、验证段和保留段，并比较快速反转、确认延迟、邻近参数一致性、P0不可用比例及典型失败区间。
- V1正式冻结前可根据实际测试做一次明确的参数定版；冻结后季度只监测漂移，年度评审或核心来源/编制方法变化才触发重评。任何参数变化生成新规则/模型版本，不覆盖旧派生结果和报告快照。
- 新旧版本的并行历史、默认展示、迁移和回滚语义转交[确定模型版本升级、历史重算与可比性边界](15-decide-model-version-migration.md)冻结。
