# 03：打通全链路——新模型版本与 PMI 一项确认度

**Parent:** [规格](../spec.md)

**What to build:** 新增一个模型版本，跑通确认度从清单到页面与 AI 报告的整条路径，只接 PMI 一项关键指标：

- 清单新增确认度规则数据（关键指标、主要／辅助成员、读法、维度、六阶段预期表中 PMI 的各格条件、投影输出结构标识），计入清单哈希；旧清单缺省走旧路径、旧输出，四标签领域函数不动。
- 投影构建中正式阶段先算出并共享给确认度构建；非典型组合时确认关系为"不适用"、读法照常输出。
- PMI（主成员制造业 PMI；辅新订单、生产、采购量）按水平（50 线）、动量（较上月）、斜率变化（变陡／放缓／转向）读；未知记未确认、持平单列；先列成员一致与分化，有成员与主成员相反则不高于仅观察；对照当前阶段格子给出确认关系与所支持或反证的命题。
- 过热维度汇总给出计数；其余维度显示"尚未接入"，不伪造四标签。
- 回看通过票 02 的声明取 3 期。
- 页面（首页、宏观页）与 AI 报告输入按输出结构标识分派：新结构朴素列出维度汇总与关键指标读法，旧结构照旧。AI 报告输入与输出 schema 升级以承载结构化计数，解释校验保证报告不改写确认关系与计数。新模型投影校验不再要求旧七张库存卡。

**Blocked by:** 02

- [ ] 投影接缝测试：给定小型证据库、新模型清单、判定日与正式阶段，六阶段下 PMI 各给出符合预期表的支持／反证／仅观察；未知→未确认；持平不读成缓和；主辅分化→不高于仅观察；非典型组合→不适用。
- [ ] 同一份证据在旧模型下得到旧四标签与旧库存卡，在新模型下得到新结构（兼容测试）。
- [ ] 确认度缺口不阻止正式阶段发布、不改写阶段史。
- [ ] 页面与报告契约测试：新结构渲染不报错且可见 PMI 读法与过热计数；旧投影照旧；报告改写确认关系时被校验拒绝。
- [ ] 取数计划测试：新模型为 PMI 声明 3 期。
- [ ] 受影响测试、两例冒烟、完整目录正例与三核心反例通过；Codex 两轴审查无阻断。
