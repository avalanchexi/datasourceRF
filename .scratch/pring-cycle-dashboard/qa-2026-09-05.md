## ISSUE-003：证据链接时区未编码，追溯 API 返回 422（应用缺陷已修复）

- 严重度：medium；类别：功能 / 链接。
- 复现：库存首张卡的证据链接包含未编码的 `as_of=...+00:00`。HTTP 复查同一地址，
  服务端把加号解析为空格，返回 422 `datetime_from_date_parsing`；实际页面链接解码的回归断言同样失败。
- 修复：原始证据行与派生卡片统一 URL 编码查询参数，提交 `42da5c7`。
- 复测：浏览器 DOM 中 href 已包含 `%2B00%3A00`；同一编码地址返回 HTTP 200，
  `as_of_cutoff=2026-08-31T20:51:41.285300+00:00`，保留两条输入版本 ID。
  22 项 Web 测试通过，两位独立审查者无新增发现。
- 验证限制：Chrome/CUA 直接导航该 JSON 页在修复前后均报 `ERR_BLOCKED_BY_CLIENT`，
  没有把浏览器完整跳转标为通过，也未修改扩展设置。API 与页面 href 已分别验证。
- 证据：库存截图、“核对可见证据链接的目标”记录、422 原始响应、
  “验证修复后的证据跳转”编码链接记录及 HTTP 200 结果。
