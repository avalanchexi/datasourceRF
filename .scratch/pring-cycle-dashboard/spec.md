# Pring 周期驾驶舱 V1 权威规格

## Problem Statement

个人研究者需要一个在 WSL2 本机运行、通过 Windows 浏览器访问的中文 Pring 周期驾驶舱，用可信、可追溯、无前视的数据回答三个彼此分离的问题：债券、股票和商品当前是否构成正式 Stage I–VI；哪些领先证据正在形成转折观察；后来发布的政策、库存、增长和物价证据是否支持当前周期叙事。

旧系统把价格趋势、宏观评分、缺失值默认、近似阶段匹配和自然语言报告混在一起，可能把不确定状态折算成熊市、让宏观证据改写正式阶段、用代理值掩盖核心数据缺口，或在不同截止点之间拼接结果。旧系统的阶段和报告因此不能作为新系统真值，也不能作为运行时降级源。

用户还需要在不假设电脑和服务全天在线的前提下控制数据刷新、外部检索与 AI 成本。浏览器打开、Web 启动或进程重启不能自动补跑、联网或调用 AI；中断任务必须可审计并由用户明确继续。新版本只有在证据、模型和全部页面投影使用同一截止点并通过校验后才能原子发布。

前端需要把上述严格语义转化为可快速阅读的桌面驾驶舱。当前原型的总览优先结构已经得到确认，但元数据层级、主题、中文市场颜色、投影身份、报告状态和可读字号必须成为正式产品约束，而不是停留在一次性演示中。

## Solution

构建一个单用户、本机、无登录的 Pring 周期驾驶舱。系统使用追加式点时证据仓库、不可变模型版本、无网络确定性趋势与阶段引擎、原子分析投影集、持久运行账本以及受证据约束的 CLI 报告适配器，按七个逐步可运行的里程碑交付。

正式阶段只由三个核心资产的 120 个中国交易日稳定价格状态机械映射。30 日轨道只形成资产候选状态和转折观察；政策、过热、物价和库存只形成宏观事后确认。任何核心数据缺失、陈旧或冲突都不会被宏观证据、AI 或相似指标顶替。

数据刷新以手动完整运行为主。独立 Worker 在 SQLite 持久账本和全局单 Worker 租约下刷新、校验、推导并构建整套只读投影；全部必需投影验证通过后才原子切换当前指针。刷新期间 Web 继续读取上一套完整投影。报告在投影发布后生成，失败不会回滚数据；两个 CLI 都失败时保存确定性简版。

Web 保留已确认原型的八页导航、卡片组合、总览优先首页、证据抽屉和报告工作区。默认使用明亮主题并保留暗色主题，按中国市场习惯使用红涨绿跌，桌面为验收目标。字号采用 12px 元数据、13px 紧凑标签、14px 次要信息、16px 正文与关键解释的层级。

## User Stories

1. 作为个人研究者，我希望首页首先显示当前正式阶段，以便立刻知道三类核心资产是否形成有效 Pring 组合。
2. 作为个人研究者，我希望正式阶段只由债券、股票和商品的稳定价格状态决定，以便宏观叙事不能改写机械分类。
3. 作为个人研究者，我希望当前条件不足时看到“当前阶段暂不判定”，以便不会把未知状态误解为 Stage VI 或其他阶段。
4. 作为个人研究者，我希望在当前阶段为空时看到上一确认阶段，以便获得历史上下文而不把它冒充当前判断。
5. 作为个人研究者，我希望看到债券、股票和商品的原始稳定状态组合，以便验证 Stage I–VI 的机械映射。
6. 作为个人研究者，我希望阶段允许跳跃和回退，以便产品忠实反映资产状态而不强制经过相邻阶段。
7. 作为个人研究者，我希望非典型三资产组合保留为空，以便系统不使用最近模式或置信度强行分类。
8. 作为个人研究者，我希望债券始终按价格方向解释，以便收益率上涨不会被错误写成债券上涨。
9. 作为个人研究者，我希望股票核心固定使用认证后的中证全指序列，以便确认指标不会临时替代核心票。
10. 作为个人研究者，我希望债券 V1 核心固定使用上证国债指数，以便财富指数迁移只能通过新模型版本发生。
11. 作为个人研究者，我希望商品核心固定使用通过认证的南华工业品指数，以便运行时不会逐日切换代理并制造虚假转折。

13. 作为个人研究者，我希望同时查看 120 日正式轨道、30 日转折观察和 12 个月公开代理，以便比较不同时间尺度而不把它们合成投票。
14. 作为个人研究者，我希望看到资产候选方向、持续天数和冲突原因，以便理解尚未完成的状态切换。
15. 作为个人研究者，我希望转折观察明确声明不改变正式阶段，以便不会把候选信号误读为阶段预测。

## Implementation Decisions

### 产品与领域边界

- V1 是个人使用、单用户、无登录的中文本地应用，运行于 WSL2，只绑定 `127.0.0.1`，由 Windows 浏览器访问。
- 产品严格区分正式阶段、转折观察和宏观事后确认。页面信息层级固定为正式阶段第一、转折观察第二、宏观事后确认第三。
- 正式阶段只有 Stage I–VI，由债券、股票、商品三个核心资产的稳定牛熊状态机械映射：`+--` 为 Stage I、`++-` 为 Stage II、`+++` 为 Stage III、`-++` 为 Stage IV、`--+` 为 Stage V、`---` 为 Stage VI。
- 非典型组合、初始化不足、趋势条件冲突或 P0 无效时，`current_stage` 为空；`last_confirmed_stage`只提供历史上下文。
- 30 个交易日轨道只生成资产候选状态和转折观察。公开 12 个月代理独立展示，不与 120 日正式轨道平均或投票。
- 120 日证据窗口按最近 120 个中国交易日定义。月频和季频只纳入窗口覆盖统计期内、在截止点前已发布的观测及必要比较基线；计算预热不扩大页面窗口。

### 核心资产与趋势规则

- 股票核心固定为认证后的中证全指；其他宽基、广度和融资数据只作确认或环境说明。
- 债券 V1 核心固定为上证国债指数并按价格方向解释；全价指数、约 10 年国债指数和收益率只确认。迁移财富指数必须创建新模型版本。
- 商品核心固定为南华工业品指数。已确认的官方历史权重链证明认证区间无生猪；严格校准从 2018-06-01 开始。来源认证前的更早历史只可在通过口径和质量验收后用于校准与预热，不能形成正式版本回放。
- 去生猪七袖套篮子只作为预认证的模型级后备或不投票确认数据，不能在运行时按日切换。生猪及已排除燃料品种不进入页面和报告。
- 首个候选模型暂定使用 `1.5 × σ20` 噪声带、8 个交易日持续要求和 MA120 的 20 日斜率。趋势条件冲突时保留上一核心资产状态并标记候选冲突；任何调整都必须形成新模型版本。

### 点时证据与数据质量

- 证据层采用追加式来源声明、规范观测、派生观测、发布事件、获取尝试和修订 vintage，不原地覆盖历史事实。
- 查询必须显式选择 `public_as_of` 或 `system_as_of`。公开点时用于无前视校准和版本回放；系统点时用于重现当时页面与报告。
- `release_at`、`public_available_at`、`fetched_at` 和 `available_at` 是不同时间。下载成功但语义或质量校验失败不能形成系统可用时间。
- 同一指标定义版本、统计期和规范维度组成观测身份；来源和抓取批次不创造新的经济事实。
- 多个认证来源超出容差时保留冲突声明，不平均。P0 冲突阻止新正式阶段；P1 冲突阻止对应当前确认；P2 冲突只带警告。
- 合法值状态包括已报告、制度上不适用和已发布但未披露。尚未发布、权限不足、限频、源失败和校验失败属于获取状态，不写入空观测，也不以 0 代替。
- 冻结指标目录使用 P0/P1/P2 优先级。P0 覆盖交易日历、三核心价格及正式阶段必需数据；P1 覆盖转折观察和国内政策、库存、过热、物价；P2 仅提供国际和普通解释背景。

### 证据获取与预算

- 检索链固定为：有效本地证据、TuShare、已认证官方直连、Tavily、Exa、受限 AI WebSearch。各级串行降级，同一缺口不默认并行调用 Tavily 与 Exa。
- 搜索以实际发布事件作为预算身份。同一发布包含多个指标时合并一次查询，再拆分为独立规范观测。
- 初始硬预算为：单事件 Tavily/Exa/受限 AI 各 1 次；单运行分别 8/4/1 次；每日分别 16/8/2 次。P2 到 Exa 为止，不进入受限 AI WebSearch。
- 尚未进入预计发布窗口时不搜索。无结果形成负缓存，缓存至下一预计发布窗口或配置的短重试点。
- 搜索发现的未知来源只能进入候选来源队列；通过来源、身份、统计期、单位、发布时间、权限和许可认证后才能写入正式证据。
- TuShare和已认证官方来源只对短暂传输错误执行初始请求加最多 2 次短重试；认证、权限、额度、尚未发布和语义校验失败不重试。
- 手动深搜只作用于用户明确指定的单个指标，记录预算豁免、查询路径和结果；定时任务无权自动触发。

### 技术架构与安全边界

- 使用 Python 3.12、`uv`、SQLite WAL、Alembic、WSL 原生 XDG 状态目录和内容寻址制品。
- 一个 FastAPI + Plotly Dash Web 进程提供版本化 REST 和页面；一个独立单 Worker 执行采集、校验、推导、投影和报告长任务。
- 不引入 Redis、Celery、WebSocket、Dash 后台回调、Node.js、Docker或第二个 Web 服务。
- Web 只读取投影和运行读模型，或追加短小、幂等的用户命令。浏览器不得托管任务，不得计算趋势、阶段、宏观状态或库存状态。
- 外部适配器是 TuShare、认证官方来源、Tavily、Exa、受限 AI WebSearch、Codex CLI 和 Claude Code CLI。确定性领域模块保持无网络、无当前时间隐式依赖。
- 应用不接收、读取、保存或注入模型厂商 API key。数据源密钥只存在于仓库外本机 `0600` 配置，并不得进入日志、浏览器、报告或 AI 上下文。
- 不受信 Origin 不能追加命令。外部响应、认证头、完整提示上下文和内部密钥不进入运行状态页面。

### 运行、刷新与恢复

- 手动完整运行是 V1 主路径。可选自动盘后默认关闭；启用后的初始北京时间计划点为 18:30，P0 最迟等待截止点为 21:00。
- Web 启动、浏览器打开、项目重启或 Worker 重启只展示遗漏与中断，不自动补跑、检索或调用 AI。
- 一个持久父运行由全局单 Worker 租约串行执行。租约心跳为 30 秒，120 秒失效；重复命令按冻结幂等身份合并。
- 完整运行阶段为：`queued → preflight → refreshing_evidence → validating_evidence → evaluating_core_readiness → deriving_states → building_projection → publishing_projection → generating_report → completed`。
- Worker 在运行开始时冻结目标交易日、证据/规则截止点和模型版本。全部必需只读投影共享同一投影身份、系统截止点、快照和模型版本。
- P0 缺失、陈旧或冲突时运行进入 `action_required`，不切换当前分析投影，不生成正式长报告。用户可以继续运行或显式创建确定性缺口说明。
- P1/P2 失败允许新投影以 `degraded` 发布，并在页面与报告中列出缺口。
- 关闭浏览器不停止 Worker。进程或 WSL 中断后，租约到期使运行变为 `interrupted`；用户必须显式继续。已验证检查点可复用，部分下载、未验证投影和 AI 部分输出必须重做。
- 取消不回滚已经原子发布的投影；可能出现投影有效但无报告的合法结果。

### 分析投影与 Web 契约

- 周期总览、核心资产、宏观、库存、发布日历和阶段历史是分域只读数据集，共同组成不可变分析投影集。
- Worker 只有在完成清单与跨数据集校验全部通过后才原子切换当前指针；构建、恢复和报告生成期间继续提供上一套完整投影。
- 报告、任务和检索状态属于独立运行读模型，可以持续更新，但必须关联目标或产出的投影身份，且其更新时间不能冒充分析数据截止时间。
- 当前页面公共包络至少包含投影身份、投影版本、系统截止点、数据快照、模型版本、趋势规则版本、120 日证据窗口、生成时间、刷新状态、完整度和全局警告。
- 顶栏紧凑显示 `system_as_of`、`projection_set_id` 和完整度；数据快照、模型、趋势规则和证据窗口放入投影详情抽屉。
- 采用八页导航：周期判断下包含首页、核心资产、宏观证据、库存特征、阶段历史；运行与追溯下包含发布日历、报告、运行状态。证据追溯由内容入口打开，不成为一级导航。
- 首页保持总览优先顺序：正式阶段、三核心资产、转折观察、宏观事后确认、数据与报告状态。不得重构为资产优先工作台、常驻检查器或独立证据工作台。
- 核心资产详情使用共同骨架加资产专属确认模块；图表序列和状态全部由投影提供，浏览器不派生事实。
- 宏观页面固定为政策方向、过热程度、物价压力和 P2 国际环境四个独立分区；库存页面固定为四象限解释和七张无总分特征卡。
- 阶段历史必须展示正式区间、非典型/不可用空档、每日三资产状态、候选事件和关联模型版本。
- 发布日历必须并列预计窗口、实际发布事件和系统首次可用时间。运行状态必须展示任务、来源、预算、负缓存、失败分类和合法下一动作。

### 视觉与交互决策

- 已确认的单文件 HTML 原型是信息架构、页面结构、导航、卡片组合、证据抽屉、报告工作区、密度和呈现方式的视觉来源；后续实现只在该结构上微调。
- 默认主题为明亮主题，参考当前原型基调；保留暗色主题并记住用户显式选择。
- 中国市场语义色固定为红色表示上涨、偏多和支持，绿色表示下跌、偏空和矛盾，黄色表示候选状态和运行警告。运行成功、资产类别和行情方向使用分离的视觉语义。
- 字号层级固定为：元数据 12px、紧凑标签 13px、次要信息 14px、正文和关键解释 16px；标题可以更大，不使用低于 12px 的可读文本。
- 保留英文 eyebrow 和技术字段名，页面标题、正文和关键解释使用中文。
- 桌面是设计与验收目标。不做移动端设计或移动端验收；保留窄窗口下导航、卡片、表格和报告布局不破版的基本能力。
- 主题切换、页面导航、证据抽屉、报告标签页、报告生成演示状态和键盘焦点必须具有可观察的交互状态；减少动态效果设置必须被尊重。

### AI 报告

- Worker 先生成确定性事实骨架和冻结证据包，再调用 CLI 报告适配器。AI 只解释事实，不分类、不搜索、不提出资产配置或交易建议。
- Codex CLI 和 Claude Code CLI 消费同一输入与共同 Schema，并由同一本地后置校验器检查正式阶段不变量、引用白名单、工具事件和结构完整性。
- 首选适配器可配置且默认 Codex；首选失败后调用 Claude。一次报告运行中每个适配器最多调用一次。
- 单适配器硬超时 300 秒，终止宽限 5 秒，双适配器总进程预算约 610 秒。部分、超时、工具调用、取消或校验失败输出不形成报告快照。
- 两个 CLI 都失败时生成不可变的 `completed_degraded` 确定性简版。报告失败不回滚分析投影。
- 报告页面保留生成、历史、阅读三个工作区。每次生成创建新版本，不覆盖历史；历史正文与证据身份不可因打开页面而重算。

### 模型版本、保留与切换

- 模型版本是趋势规则、阶段映射、指标定义、来源认证与选源规则及派生公式的原子不可变清单。任何可能改变选值或分析结果的规则变化都创建候选版本。
- 候选版本只在其可认证回放区间并行运行，经数据质量、稳定性、回归和人工确认后才原子成为唯一生效版本。
- 发布历史、旧派生结果和报告快照永不覆盖。后来认证的历史不能反向制造认证前正式版本回放。
- 从新模型首次正式发布投影的目标交易日起，上一生效模型按中国交易日历含首日保证 30 个交易日可直接逻辑回退。回退只切换生效指针，不恢复数据库或删除新结果。
- V1 不备份 SQLite、证据制品、报告、密钥或升级前状态，RPO/RTO 不保证。GitHub 只恢复源码与静态定义，数据丢失后需要重新初始化。
- 未验证外部响应保留 7 天且上限 1GiB，日志保留 14 天且上限 200MiB，报告正文保留 30 天，孤立制品保留 7 天；被引用证据、结构化血缘、投影清单和模型版本长期保留。
- WSL/Windows 承载卷在剩余空间 20/10/5GiB 时分别警告、限制非核心大任务、停止 Worker 写入；不得自动删除权威状态。
- 实施顺序固定为七个逐步可运行里程碑：工程与领域骨架、点时证据与确定性核心、真实 P0 与首个候选模型、完整 P1 证据层、本地产品运行面、报告与运维降级、最终验证与直接切换。
- 系统不设置生产影子期或双写期。所有硬门通过并经用户显式确认后直接切换；切换后旧系统只读保留作故障证据，不再运行或提供降级。

## Testing Decisions

- 最高层验收缝只有一个：统一、离线、无凭据的验收命令通过公开 CLI，在临时 SQLite 和固定内容寻址制品目录中完成证据摄取、点时快照、核心状态、正式阶段、原子投影、运行恢复和确定性报告的端到端行为。测试观察稳定输出与持久状态，不读取内部函数、私有表结构或中间文件。
- 该最高层缝已经由已确认实施计划规定，不新增测试专用服务。FastAPI/Dash 页面、CLI 和 Worker 共享正式应用接口，避免为测试创建第二套编排路径。
- 好测试只验证外部行为和领域不变量：同一输入规范化结果一致、错误分类稳定、状态转换合法、投影原子可见、历史不可变、AI 不能越权。测试不固定内部调用顺序、SQL 语句、私有类或视觉实现细节。
- 确定性领域模块使用表驱动与属性测试覆盖趋势冲突、持续性、滞回、严格六阶段映射、非典型组合、阶段跳跃/回退、库存象限和宏观角色边界。
- 点时证据模块使用临时 SQLite 覆盖发布前不可见、公开/系统可用分离、同期多 vintage、修订不改历史、来源冲突、合法值状态、派生输入血缘和 120 日多频窗口。
- 外部适配器全部具有离线契约夹具，覆盖成功、空响应、认证失败、权限不足、限频、尚未发布、身份错配、日期错配、单位错配、冲突和解析失败。
- 真实来源仅通过独立、脱敏、可审计的烟雾测试验收。烟雾结果只保留来源身份、字段、时间、数量、哈希和结论，不保存 token、认证头或未获许可正文。
- P1 真实源按独立适配器、端点或解析 Schema 族抽样。独特身份、单位、时点或解析逻辑必须单独抽样；一个抽样失败阻塞对应适配器或 Schema 族，不允许降为 P2 绕过。
- 检索链测试复用既有预算逻辑原型的场景，覆盖联合发布合并、Tavily 配额切 Exa、P1 全失败、P2 停在 Exa、尚未发布不搜索、负缓存和报告 AI 越权拦截。
- 运行编排测试覆盖重复命令、全局租约、陈旧心跳、关闭浏览器、Worker 中断、显式恢复、检查点复用、取消、P0 `action_required`、P1/P2 `degraded` 和投影先于报告完成。
- 分析投影契约测试验证所有必需数据集具有同一投影身份、系统截止点、数据快照和模型版本；任一数据集失败时当前指针保持上一完整投影。
- Web 行为测试覆盖八页导航、公共投影包络、证据抽屉、报告三个标签页、主题默认与持久化、键盘焦点、减少动态效果和窄窗口不破版。
- 视觉契约测试至少验证默认明亮主题、暗色主题保留、红涨绿跌、状态色与资产类别色分离，以及 12/13/14/16px 字号层级；桌面浏览器进行一次真实渲染验收，不设置移动端截图门。
- AI 报告测试复用既有共同协议探针，分别让 Codex 和 Claude 消费同一固定证据包，验证工具事件为零、正式阶段不变、引用白名单、Schema、超时、替代、取消和双失败确定性简版。
- 35 个已提取 `REG-*` 行为回归必须全部映射到规格条款、ADR、实现里程碑和自动化测试，旧报告及旧阶段结果不作为 golden。
- 冻结的 2018-06-01 至 2026-08-19 校准夹具必须复现 21 次资产方向转换、11 次正式阶段变化、20 个交易日内快速资产/阶段反转为 0、确认延迟中位数 23 个交易日。任何调参都必须创建新候选并重跑全部门。
- 故障注入必须覆盖事务中断、重复命令、陈旧租约、磁盘容量降级、外部源失败、P0 冲突、双 CLI 失败和升级失败进入 `reinitialize_required`。
- 性能硬门为：当前投影 REST 本地 p95 不超过 500ms；Dashboard 首次有意义内容不超过 3 秒；命令提交并返回持久身份不超过 1 秒；Web 与 Worker 冷启动不超过 15 秒；纯本地证据生成单日完整确定性投影不超过 60 秒；2018 年以来离线回放不超过 15 分钟；全部无网络自动化测试不超过 10 分钟；Web 与 Worker 合计空闲 RSS 不超过 1.5GiB；单次完整回放峰值 RSS 不超过 4GiB。
- 最终切换前必须在最新完整目标交易日完成一次真实端到端演练，并用 fixture 完成一次 Worker 中断与显式恢复演练。真实演练是验收产物，不进入正式发布历史。

## Out of Scope

- 登录、权限、账号、多租户、公网部署或局域网访问。
- 移动端产品设计、移动端专项交互和移动端验收；仅保留窄窗口不破版。
- Redis、Celery、WebSocket、Node.js、Docker、第二 Web 服务、多 Worker 或多机协调。
- 资产配置权重、买卖建议、目标价、收益承诺或任何自动交易能力。
- 让 AI、宏观评分、新闻情绪、确认指标或相似代理改变正式阶段。
- 生产影子期、双写择优、切换后回退旧系统或把旧项目作为运行时数据源。
- 把旧报告、旧阶段或人工标签作为新系统正确答案。
- 来源认证前历史的正式版本回放，以及后来认证数据对已发布历史的回写。
- 十年全市场广度回填；V1 只输出最近 120 个交易日的广度历史并保留必要预热。
- 冻结指标目录之外的临时新增指标；新增指标进入后续模型版本。
- 未经认证的国际指标代理、VIX 替代品、SOX 替代品或停止维护的数据源。
- 运行数据备份、升级前快照、云端备份、异地备份以及任何 RPO/RTO 保证。
- 无人值守必达、开机自动追赶全部遗漏日期或中断后自动恢复外部调用。
- 永久维护所有历史模型的可运行环境；直接逻辑回退只保证上一生效模型 30 个中国交易日。
- 重构已经确认的总览优先页面为资产优先工作台、常驻检查器或独立证据工作台。
