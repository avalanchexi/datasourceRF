# 24 — 完整回归与性能硬门

**What to build:** 让维护者通过一个统一、无网络、无凭据的验收命令证明 V1 的35个历史故障不会复发，确定性、原子性、恢复、报告边界、性能和资源预算全部满足切换要求。

**Blocked by:** 22 — 模型升级、并行回放与30交易日回退；23 — 桌面视觉与无障碍验收

**Status:** ready-for-agent

- [ ] 35个 `REG-*` 全部映射到规格、ADR、负责票和自动化测试，旧报告、旧阶段和旧golden不作为oracle。
- [ ] 统一验收命令通过公开CLI与临时SQLite完成证据、点时查询、趋势、阶段、投影、运行恢复和确定性报告端到端路径。
- [ ] 固定证据、日历、模型和截止点的离线重放规范化结果一致且不联网。
- [ ] 故障注入覆盖事务中断、重复命令、陈旧租约、P0失败、外部源失败、双CLI失败、容量降级和升级失败。
- [ ] 当前投影REST本地p95不超过500ms，Dashboard首次有意义内容不超过3秒，命令持久化响应不超过1秒。
