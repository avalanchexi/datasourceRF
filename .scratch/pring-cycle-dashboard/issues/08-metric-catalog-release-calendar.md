# 08 — 版本化指标目录与发布日历

**What to build:** 让用户从版本化指标目录看到 V1 冻结指标的身份、证据角色、P0/P1/P2、来源认证和发布规则，并贯通一条官方发布事件从检查、摄取、时效判断到发布日历展示的完整路径。

**Blocked by:** 07 — 首个候选模型校准与生效

**Status:** ready-for-human

- [x] 冻结指标定义全部进入模型版本，包含规范身份、单位、频率、维度、证据角色、优先级、来源候选和认证状态。
- [x] 指标目录禁止同义 key 静默合并和运行时临时新增；变更必须创建新候选模型。
- [x] 发布事件区分预计窗口、实际发布时间、公开可用时间和系统首次可用时间。
- [x] 尚未到预计窗口时沿用上一期并标记 `awaiting_release`，不触发检索或伪造当期日期。
- [x] 超过宽限、源失败、冲突、合法未披露和来源待认证产生不同状态及业务影响。
- [x] 发布日历显示事件族、统计期、时区、上一期沿用、最近获取、下一检查和关联观测数量。
- [x] 至少一条认证官方来源在离线契约、脱敏真实烟雾、证据仓库、REST 和页面上端到端通过。
- [x] 未知发布配置对 P0 fail-closed，预计日历不能证明数据已经发布。
