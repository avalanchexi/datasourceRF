# 20 — 报告生成、历史与阅读工作区

**What to build:** 让用户在报告页发起新版本、观察当前报告任务、浏览不可变历史并阅读正文与证据引用；浏览器重启后可以只读恢复最近完整报告状态，数据投影与报告状态始终分开。

**Blocked by:** 19 — 证据约束报告适配器

**Status:** ready-for-agent

- [ ] 报告页面具有生成、历史、阅读三个可访问工作区，并复用确认原型的交互结构。
- [ ] 生成命令绑定目标投影与冻结证据包，重复命令幂等；每次成功或确定性降级生成新版本，不覆盖同日旧报告。
- [ ] 生成状态显示排队、运行、完成、降级、失败和取消，并与分析投影刷新状态分离。
- [ ] 历史列表显示业务日、截止点、快照、状态、适配器、耗时、证据包哈希、模型/提示/Schema版本和正文保留状态。
- [ ] 阅读页显示报告身份、正式阶段依据、三核心、转折观察、政策/库存/物价解释、变化原因、数据缺口和绑定引用。
- [ ] 打开历史报告只读取原快照，不使用当前数据或当前模型重算正文。
- [ ] 浏览器或Web重启后从持久账本只读识别最近完整 attempt，不新增记录、不自动继续失败报告。
- [ ] 报告取消或失败后结构化驾驶舱保持可读；已发布投影可以合法地没有报告。
- [ ] 正文过期时保留结构化身份、状态、摘要和证据清单，并明确正文已不在保留期。
- [ ] 页面和测试禁止暴露提示全文、推理内容、认证信息和未脱敏外部响应。
