# 12 — 过热程度

**What to build:** 让用户基于订单、生产、工业增加值、产能、利润和信用看到独立的过热程度，并在证据分裂或不足时查看冲突而不是被一个平均分掩盖。

**Blocked by:** 11 — 信用响应

**Status:** ready-for-human

- [x] PMI制造业、生产、新订单和采购量通过发布事件与点时证据进入状态计算。
- [x] 工业增加值、产能利用率、工业利润、营业收入和成本保持官方口径、频率及同比/环比身份。
- [x] 信用证据通过已完成的信用响应投影引用，不复制成新的经济观测或重复计票。
- [x] 过热程度只允许升温、过热、降温或数据不足，并列出支持、反证、待发布、陈旧和冲突。
- [x] 宏观证据只形成转折观察或宏观事后确认，不能投票、否决或改写正式阶段。
- [x] 页面展示每个证据族的最新有效时点和来源，低频值不按日复制。
- [x] P1 失败使过热状态降级但不阻止 P0 投影；未知空值和未分类错误禁止发布。
- [x] 独特官方适配器和派生公式通过离线契约、真实抽样及固定状态测试。
