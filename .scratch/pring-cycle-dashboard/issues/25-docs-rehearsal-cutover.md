# 25 — 运行文档、真实演练与直接切换

**What to build:** 让用户在干净 WSL 环境按文档完成安装、运行、恢复、报告和模型操作，使用最新完整目标交易日完成真实验收演练，并在机器校验全部证据后显式把新系统直接切换为唯一受支持路径。

**Blocked by:** 24 — 完整回归与性能硬门

**Status:** ready-for-agent

- [ ] 文档实测安装、初始化、启动、停止、状态、`doctor`、无回显密钥迁移和仓库外运行目录。
- [ ] 文档实测手动完整运行、定向刷新、手动深搜、报告生成、取消、显式恢复和可选自动盘后。
- [ ] 文档解释正式阶段、上一确认阶段、转折观察、宏观事后确认、P0/P1/P2、点时、模型版本和证据追溯。
- [ ] 文档明确无运行数据备份、容量水位、升级失败、重新初始化及不保证RPO/RTO。
- [ ] 最新完整目标交易日完成一次真实P0、按Schema族抽样P1、原子投影、Dashboard及AI成功或确定性降级演练。
- [ ] 独立fixture完成一次Worker中断与用户显式恢复演练；两次演练均标记为验收产物而非正式发布历史。
- [ ] 不可变切换清单固定代码与依赖、数据库/配置版本、指标/来源/模型、回归、质量、性能、文档和演练哈希。
- [ ] 统一CLI机器校验切换清单且无强制绕过；只有全部通过并经用户显式确认才记录切换。
- [ ] 切换后旧系统保持只读、停止运行且不提供降级；首次故障只在新系统内修复、显式恢复或重新初始化。
- [ ] 新系统内部30交易日模型回退不被误解为回退旧系统。
