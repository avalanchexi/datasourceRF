# 16 — 完整原子分析投影集

**What to build:** 让用户一次读取同一截止点下的周期总览、核心资产、宏观、库存、发布日历和阶段历史；任何必需数据集构建或校验失败时仍继续提供上一套完整版本，不拼接半成品。

**Blocked by:** 10 — 政策行动与市场传导；12 — 过热程度；13 — 物价压力传导；14 — 库存四象限与七张特征卡；15 — P2 国际环境

**Status:** ready-for-agent

- [ ] 六个分域只读数据集共享同一投影身份、系统截止点、数据快照、模型版本、趋势规则版本和证据窗口。
- [ ] Worker 构建完成清单并做跨数据集身份、不变量和引用校验，全部通过后才原子切换当前指针。
- [ ] 任一必需数据集失败、事务中断或恢复时，当前 REST 和页面继续返回上一完整投影。
- [ ] P1/P2缺口允许整套投影标记 `degraded` 并列出全局/局部警告；P0失败不得发布新投影。
- [ ] 报告、任务和检索状态作为独立运行读模型关联目标/产出投影，不冒充分析数据截止时间。
- [ ] 公共包络包含投影身份、系统截止点、快照、模型、趋势规则、证据窗口、生成时间、刷新状态、完整度和警告。
- [ ] 版本化 REST 不混用不同投影数据，浏览器只读取和筛选，不重新计算领域事实。
- [ ] 固定 fixture 的完整投影规范化结果可重复，事务故障注入证明部分结果不可见。
