# 03 — 三核心 fixture 生成正式阶段

**What to build:** 让用户把一组三核心价格 fixture 送入正式离线命令，得到债券、股票、商品的 120 日稳定状态、30 日资产候选状态、12 个月公开代理、严格 Stage I–VI 映射以及可在首页读取的首套原子最小投影。

**Blocked by:** 02 — 双点时证据摄取与追溯

**Status:** ready-for-human

- [x] 趋势计算是无网络确定性模块，输入冻结日历、证据和规则版本后规范化输出完全一致。
- [x] 120 日正式轨道实现位置、MA120 的 20 日斜率、噪声带、持续性、滞回和冲突保持语义。
- [x] 30 日轨道只形成资产候选状态和转折观察；12 个月代理独立展示且不参与投票。
- [x] 六个规范牛熊组合逐一映射 Stage I–VI，阶段允许非相邻跳跃与回退。
- [x] 固定三资产状态时，宏观、库存、政策或报告输入变化不能改变正式阶段。
- [x] 最小分析投影共享投影身份、系统截止点、数据快照、模型和趋势规则版本，全部验证后才原子成为当前版本。
- [x] 首页按正式阶段、三核心资产、转折观察顺序展示，浏览器不重新计算趋势或阶段。
- [x] `REG-TREND-003..004`、`REG-STAGE-001..005,007` 与 `REG-RUN-004` 通过。
