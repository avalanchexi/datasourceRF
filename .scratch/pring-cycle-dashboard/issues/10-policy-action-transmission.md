# 10 — 政策行动与市场传导

**What to build:** 让用户在宏观页面分别查看央行政策行动和资金市场传导，理解操作利率、净投放、准备金事件、DR007、Shibor及利差的方向、时效、来源和冲突，而不会生成政策总分或改写正式阶段。

**Blocked by:** 09 — 成本受控证据检索

**Status:** ready-for-human

- [x] 政策行动支持操作利率、操作量/到期量/净投放、准备金公告与生效时间及正式政策事件。
- [x] 市场传导支持 DR007、DR007 与政策利率利差、Shibor 和债券价格/收益率方向说明。
- [ ] 每个输入通过版本化目录、认证来源、点时仓库、时效和冲突规则进入投影。
- [x] 政策行动、市场传导分别输出方向、最新变化、事件/统计时间、时效、冲突和来源。
- [x] 政策方向只允许宽松、收紧、中性、传导冲突或数据不足，不合成分数。
- [x] 固定三核心资产时，穷举政策方向不改变正式阶段，只改变转折观察或宏观事后确认。
- [x] 页面展示证据入口与未发布/陈旧/来源失败状态，不用新闻描述或估算值冒充正式政策行动。
- [ ] 独特来源/Schema 族具有离线契约和脱敏真实烟雾；任一抽样失败阻塞对应族。
