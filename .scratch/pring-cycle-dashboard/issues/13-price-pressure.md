# 13 — 物价压力传导

**What to build:** 让用户沿商品/原油、PMI价格、PPI生产资料、PPI生活资料、CPI和核心CPI逐层查看物价压力从上游到消费端的传导、回落与数据缺口。

**Blocked by:** 09 — 成本受控证据检索

**Status:** ready-for-human

- [ ] NHII/NHCI、EIA Brent/WTI、PMI购进/出厂价格、PPI分项、CPI和核心CPI使用规范身份与认证来源。
- [ ] PPI、CPI和核心CPI的环比、同比及累计平均保持独立标量和真实发布时间。
- [x] 物价压力只输出上游压力、生产端扩散、消费端扩散、回落或数据不足，并列支持与反证。
- [x] 能源只解释广义 CPI、PPI、投入成本和政策压力，不被描述为核心CPI直接组成。
- [x] 国际原油是 P2/背景或传导输入，不替换 NHII 商品核心。
- [x] 未认证来源、停更接口和搜索代理保持明确缺口，不使用相似序列补值。
- [x] 页面按固定传导链展示时点、时效、冲突和证据入口，不合成宏观总分。
- [x] P1/P2失败产生局部降级而不改变正式阶段或阻塞其他已完成分区。
