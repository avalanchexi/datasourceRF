# 09 — 成本受控证据检索

**What to build:** 让用户针对应该已经发布但仍缺失的证据运行固定降级链，看到每一级命中、失败、预算、负缓存和下一动作，并可显式对单个指标发起可审计的手动深搜。

**Blocked by:** 08 — 版本化指标目录与发布日历

**Status:** ready-for-human

- [ ] 检索严格按有效本地证据、TuShare、认证官方直连、Tavily、Exa、受限 AI WebSearch 串行执行。
- [ ] 同一实际发布事件内的多个指标合并查询后拆分观测，不重复消耗事件预算。
- [ ] 单事件预算为 1/1/1，单运行预算为 8/4/1，每日预算为 16/8/2；预算耗尽有稳定结果。
- [ ] P2 到 Exa 为止，禁止进入受限 AI WebSearch；报告 AI 不能调用任何证据检索工具。
- [ ] 尚未发布和有效负缓存不发起外部调用，Tavily 与 Exa 不对同一缺口默认并行。
- [ ] 只有短暂传输错误最多额外重试 2 次；认证、权限、额度、未发布和语义校验失败不重试。
- [ ] 未知网站只形成候选来源，未认证结果不能写入正式证据或清除原任务缺口。
- [ ] 运行状态页显示逐级延迟、失败分类、预算余量、缓存命中和下一动作，但不显示密钥、认证头或完整响应。
- [ ] 手动深搜只作用于显式指定指标，记录预算豁免、渠道和结果，定时任务不能自动触发。
- [ ] 既有检索预算原型的联合发布、配额切换、P1全失败、P2止步、未发布、负缓存和越权场景全部进入正式测试。
