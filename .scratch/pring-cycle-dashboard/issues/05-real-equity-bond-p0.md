# 05 — 股票与债券真实 P0

**What to build:** 让用户针对一个目标交易日取得并认证中证全指和上证国债指数，生成真实股票、债券核心状态，并在共同资产详情页查看核心序列、趋势条件、候选持续、确认指标和质量；收益率与 ETF 永远不能替代债券价格。

**Blocked by:** 04 — P0 硬门与历史空档

**Status:** ready-for-agent

- [ ] 中国交易日历、中证全指和上证国债指数适配器绑定规范指标身份、单位、来源、统计日和认证状态。
- [ ] 股票和债券最近 120 个中国交易日及必要预热不存在未解释缺口、重复、日期错配或单位错配。
- [ ] 债券价格上涨映射债券牛、价格下跌映射债券熊；可信收益率只作反向确认。
- [ ] 收益率缺失或与价格冲突只改变确认说明，不替换、冻结或反转债券核心状态。
- [ ] ETF 点位、收益率代理和错误指数身份在适配器边界被拒绝，不产生百分比或 bp 灾难。
- [ ] 资产详情由只读投影提供 120 日、30 日、12M、变化记录、来源和质量，浏览器不派生指标。
- [ ] 真实来源烟雾结果只保存身份、字段、时间、数量、哈希和结论，不保存 token 或原始响应正文。
- [ ] `REG-BOND-001..004` 与股票/债券部分 `REG-CORE-002..003` 通过。
