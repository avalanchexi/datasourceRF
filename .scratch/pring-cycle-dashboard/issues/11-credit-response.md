**Blocked by:** 09 — 成本受控证据检索

**Status:** ready-for-human

- [x] LPR 1年/5年以上、M1/M2、社融增量/累计/存量、社融结构和贷款结构按规范标量身份存储。
- [x] 同一发布的环比、同比、累计和结构分项保持独立标量，通过发布事件关联而不混成宽表观测。
- [x] 信用脉冲作为版本化派生观测保存公式、确切输入 vintage 和计算截止点。
- [x] 月频值只在真实公开/系统可用时点后进入查询，上一期沿用保留原统计期和年龄。
- [x] 信用响应与政策行动、市场传导分开展示，不能冒充央行即时政策或正式阶段票。
- [x] 来源冲突、未发布、陈旧、失败和合法未披露具有明确输出，不使用 0 或估算补齐。
- [x] 页面可以从信用状态进入证据追溯，并看到修订链与派生血缘。
- [x] 各独特适配器/Schema 族通过离线契约与脱敏真实烟雾。
