# 14 — 库存四象限与七张特征卡

**What to build:** 让用户结合需求、生产、价格、利润、信用和可信库存证据判断主动/被动去库存或补库存，并通过七张独立特征卡查看一致、冲突、待发布和缺失，而不是获得不可追溯的库存总分。

**Blocked by:** 12 — 过热程度；13 — 物价压力传导

**Status:** ready-for-agent

- [ ] 四象限规则明确区分需求、生产/采购、库存/库销的方向，证据不足或冲突时不强行分类。
- [ ] 七张特征卡覆盖订单－库存差、原料－产成品、实际库存、库销周转、价格－利润、产能、信用与实物库存。
- [ ] 名义产成品库存与 PPI 近似调整结果并列，公式版本和输入 vintage 可追溯。
- [ ] PMI库存明确标记为扩散指数；注册仓单明确不代表产业总库存。
- [ ] 信用、过热和物价输入引用既有规范观测，不复制或重复计票。
- [ ] 每张卡只输出支持、冲突、尚未发布、陈旧或缺失，不生成库存总分。
- [ ] 库存解释只能形成转折观察或宏观事后确认，固定三核心状态时正式阶段不变。
- [ ] 页面展示四象限、七卡、证据一致性、时效和追溯入口，P1缺口产生局部降级。
