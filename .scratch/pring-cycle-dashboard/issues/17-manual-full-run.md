# 17 — 手动完整运行

**What to build:** 让用户从 CLI 或页面针对一个中国目标交易日显式发起完整运行，并在运行状态中观察持久父运行依次刷新、校验、推导、原子发布投影和进入报告阶段；重复操作只对应一个权威运行。

**Blocked by:** 16 — 完整原子分析投影集

**Status:** ready-for-agent

- [ ] 命令提交在 1 秒内持久化并返回运行身份，CLI 和页面使用同一正式命令接口。
- [ ] 父运行冻结目标交易日、证据/规则截止点、模型版本和幂等身份。
- [ ] 运行按已确认阶段序列推进，并为当前步骤、开始/完成时间、错误分类、可恢复性和下一动作提供运行读模型。
- [ ] 全局单 Worker 租约采用 30 秒心跳和 120 秒失效；活动 owner 不可被另一个运行接管。
- [ ] 同一逻辑运行重复点击或重提只增加可审计尝试，不产生两个权威投影或重复外部消费。
- [ ] P0失败进入 `action_required`，不发布新投影、不自动生成长报告；P1/P2失败允许 `degraded` 投影。
- [ ] 浏览器打开、Web启动和普通页面读取不创建运行、不联网、不检索、不调用AI。
- [ ] 关闭浏览器不停止 Worker，页面通过活动30秒、空闲5分钟轮询观察状态。
- [ ] `REG-RUN-002,006` 通过，运行状态不暴露密钥、认证头或完整外部响应。
