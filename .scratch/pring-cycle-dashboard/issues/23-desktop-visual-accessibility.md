# 23 — 桌面视觉与无障碍验收

**What to build:** 让用户在完整八页驾驶舱中获得与确认原型一致的总览优先结构、主题、中文市场颜色、字号层级、证据抽屉和报告交互，并在桌面与窄窗口中保持可读、可操作和不破版。

**Blocked by:** 21 — 保留、容量降级与重新初始化

**Status:** ready-for-agent

- [ ] 八页导航固定为首页、核心资产、宏观证据、库存特征、阶段历史、发布日历、报告和运行状态；证据追溯不是一级导航。
- [ ] 首页保持正式阶段第一、转折观察第二、宏观事后确认第三，不重构为资产优先或独立证据工作台。
- [ ] 默认明亮主题参考确认原型，暗色主题保留并记住用户显式选择。
- [ ] 红色表示上涨/偏多/支持，绿色表示下跌/偏空/矛盾，黄色表示候选/运行警告；资产类别色与状态色分离。
- [ ] 元数据12px、紧凑标签13px、次要信息14px、正文和关键解释16px，任何可读文本不低于12px。
- [ ] 顶栏紧凑展示系统截止点、投影身份和完整度，其他快照/模型/证据窗口信息位于投影详情抽屉。
- [ ] 英文 eyebrow 与技术字段保留，标题、正文和关键解释使用中文领域词汇。
- [ ] 导航、主题、标签页、抽屉、命令和错误状态支持键盘焦点，颜色不是唯一状态表达，并尊重减少动态效果设置。
- [ ] 桌面真实浏览器完成像素与交互验收；不设置移动端设计门，但窄窗口下导航、卡片、表格和报告不破版。
- [ ] 视觉契约自动验证主题、状态色、字号和关键结构，演示 fixture 不被当作正式数据真值。
