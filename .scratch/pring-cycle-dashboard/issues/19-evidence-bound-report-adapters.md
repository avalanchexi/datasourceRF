# 19 — 证据约束报告适配器

**What to build:** 让系统在分析投影发布后冻结一份可审计证据包和确定性事实骨架，先后尝试本机 Codex CLI 与 Claude Code CLI 生成中文解释；任何 AI 越权或失败都不能改变结构化事实，并在双失败时发布确定性简版。

**Blocked by:** 18 — 中断恢复、取消与可选调度

**Status:** ready-for-human

- [x] 报告预检验证目标投影身份、截止点、模型、核心状态、正式阶段、证据引用和数据缺口；输入不一致时不调用 CLI。
- [x] 冻结证据包包含确定性事实骨架、引用白名单、支持与反证、治理缺口、Schema和提示版本及内容哈希。
- [x] Codex 与 Claude 适配器只调用已登录的本机 CLI 子进程；应用不读取、保存或注入模型 API key，也不提供直接 API 回退。
- [x] 默认 Codex、失败后 Claude；一次报告运行中每个适配器最多一次，单适配器硬超时300秒、终止宽限5秒、总进程预算约610秒。
- [x] 后置校验拒绝工具事件、自由搜索事实、非法引用、Schema错误、正式阶段改写、交易建议及部分输出。
- [x] 每个 attempt 记录输入制品身份、适配器/CLI/模型版本、开始完成时间、结果分类、安全遥测和输出哈希，不记录推理内容或敏感上下文。
- [x] 双 CLI 失败生成 `completed_degraded` 不可变确定性简版；报告失败不回滚分析投影。
- [x] 主动取消、超时和校验失败不形成正式自然语言快照，但保留可审计 outcome。
- [x] 旧项目的输入身份/日期预检、attempt/outcome、降级发布和安全遥测行为被保留；Stage 文件、整体完整率放行、直接模型 API 与报告内重新分类明确不迁移。
- [x] `REG-STAGE-006`、`REG-RUN-005` 及两个 CLI 的共同协议 fixture 通过。
