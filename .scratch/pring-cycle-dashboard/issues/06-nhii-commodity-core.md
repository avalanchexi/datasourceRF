# 06 — NHII 商品核心

**What to build:** 让用户取得并认证南华工业品指数作为唯一 V1 商品核心，与股票和债券一起形成真实三资产判断，并在商品详情中查看连续收益、认证、外部宽基确认和无生猪审计，运行时不切换临时代理。

**Blocked by:** 05 — 股票与债券真实 P0

**Status:** ready-for-agent

- [ ] NHII 适配器绑定官方指数身份、价格/收益口径、统计日、连续性和认证状态。
- [ ] 最近 120 个中国交易日及必要预热通过身份、日期、重复、缺口、调整和连续收益质量检查。
- [ ] 官方成分与方法证据证明认证区间无生猪；生猪及已排除燃料品种不进入核心、确认、解释、页面或报告。
- [ ] NHCI 和外盘商品只作独立确认/P2 背景，方向冲突不能改变 NHII 核心状态。
- [ ] 去生猪七袖套篮子保持预认证模型级后备或不投票确认数据，单日故障不得触发运行时切换。
- [ ] 商品详情展示核心身份、120 日/30 日/12M、状态变化、认证和确认冲突，不自我重复投票。
- [ ] 通用前月缺少合约月、结算、换月事件或调整因子时不得进入可认证趋势。
- [ ] `REG-TREND-001..002` 与 `REG-FUT-001..004` 通过。
