# 04: 上下文公式的期次、维度与预热父输入验证

**Parent:** [固定窗口、预热证据与目录迁移规格](../spec.md)；[已批准拆分记录](../ticket-breakdown-proposal.md)。

**What to build:** 每个冻结公式从输入需求到派生/预检查询可追溯父输入，缺失时指出指标、期次、维度及受影响结果。

**Blocked by:** [01 — 固定新窗口并从公开预检读回交易日范围](01-fixed-window-calendar.md)

## Scope

本轮目标固定 2026-09-22，正式窗口为 2026-04-01 至 2026-09-22，含首尾 120 个中国交易日。执行跨日不移动末端；必要预热按冻结公式另定，来源缺件不导致缩窗。

覆盖自然日回看、月季频、事件和比较基线；复用已有信用脉冲及利差实现，补齐其余正式公式的诊断。未知/未来预热、缺中间期次、不兼容修订、最新必需父项损坏均不被旧值或初始化历史掩盖；不把所有公式套成 259 交易日。

**规格覆盖：** User Stories 6、7、8、9、10、11、23；本票同时继承规格中的版本、证据与验收边界。

## Acceptance criteria

- [ ] 对冻结目录实际启用的每个公式列明父指标、维度、统计期、比较基线、回看单位和消费 cutoff；自然日/月季频/事件需求不转为每日 120 条或统一 259 日。
- [ ] 经公开输入选择、派生和预检查询，完整材料的输出与独立核对值相符，具有全部实际父输入版本血缘。
- [ ] 每个公式的必要父输入缺失时给出具体期次/维度和受影响结果；复用信用脉冲与利差既有反例，补尚未覆盖公式，不仅输出笼统公式失败。
- [ ] 未知/未来预热、中间期次缺失、不兼容修订及最新必需父项损坏均不能通过；不得沿用旧窗口值或初始化历史掩盖。
- [ ] 必需与可选公式缺口按实际目录分类，修订生成新版本而不回写历史，公式本身保持冻结。

## Testing decisions

沿用已批准的公开任务命令/API → 持久任务 → 单次 Worker → 投影/运行/证据/报告读取边界；必要时使用 PUBLIC/SYSTEM 选值或趋势/阶段的公开领域接口。只替换外部传输、时钟或 CLI，解析、选择、仓库与投影保持真实。先复用有效反例和交付，仅为实际缺口补行为验证；相关重型及同版本全套按[项目测试规则](../../../docs/agents/testing.md)执行，记录实际终态与身份，不为每票重复整套。
