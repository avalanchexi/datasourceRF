# 01: 固定新窗口并从公开预检读回交易日范围

**Parent:** [固定窗口、预热证据与目录迁移规格](../spec.md)；[已批准拆分记录](../ticket-breakdown-proposal.md)。

**What to build:** 命令请求、持久范围绑定及预检读取一致指向 04-01 至 09-22 的 120 日，能核对新增 17 日和重叠 103 日。

**Blocked by:** None (can start immediately)。无票前置不表示外部材料已经齐备。

## Scope

本轮目标固定 2026-09-22，正式窗口为 2026-04-01 至 2026-09-22，含首尾 120 个中国交易日。执行跨日不移动末端；必要预热按冻结公式另定，来源缺件不导致缩窗。

绑定合法日历及有序日期哈希；端点缺失、重复、119 日、行政补班星期日计入必须拒收。复用现有日期参数和日历软件；核对原件资格及 PUBLIC/SYSTEM 截止语义。旧日期夹具、来源 URL 和历史结果保持原用途。

**规格覆盖：** User Stories 1、2、3、4、5、25；本票同时继承规格中的版本、证据与验收边界。

## Acceptance criteria

- [x] 经现有公开日期参数提交后，持久请求及预检结果均为 2026-04-01 至 2026-09-22，含首尾恰好 120 个中国交易日，输出日期清单与哈希。
- [x] 从经认可的日历证据验证范围和原件资格；与旧窗口逐项对账为新增 17 日、重叠 103 日，并明确移出展示的日期仍可能是计算预热。
- [x] 端点缺失、重复日期、仅 119 日或将 2026-09-20 星期日计入均不能通过；行政补班不改变交易日属性。
- [x] 分别核对目标日、实际执行时刻、PUBLIC 和 SYSTEM 截止语义；执行跨日不移动末端，历史夹具、来源 URL 与已发布结果不批量改日期。
- [x] 经公开读取保留成功与失败结果及绑定材料；复用已有日历守卫，不重复实现已交付行为。
