# 17: 新目标与同组真实缺口的配对检索测量

**Parent:** [固定窗口、预热证据与目录迁移规格](../spec.md)；[已批准拆分记录](../ticket-breakdown-proposal.md)。

## Scope

本轮目标固定 2026-09-22，正式窗口为 2026-04-01 至 2026-09-22，含首尾 120 个中国交易日。执行跨日不移动末端；必要预热按冻结公式另定，来源缺件不导致缩窗。

继承旧 #20；每家单次测量不超过既有授权的 20 次真实检索，保留原日预算与停止条件。分层分母、零样本 N/A、失败和实际消耗如实记录；不承诺预设命中率，不等待 16，不写正式当前指针。

**规格覆盖：** User Stories 34；本票同时继承规格中的版本、证据与验收边界。

## Acceptance criteria

- [ ] 请求前冻结目标 2026-09-22、模型/定义、as-of、分层真实缺口、样本、逻辑/物理请求及日预算和停止条件。
- [ ] Tavily 与 Exa 使用同组初始缺口和独立实验标识/起点，前者写入不污染后者；生产仍遵循既定串行降级，不写正式当前指针。
- [ ] 走真实适配器和认证/解析/采纳链，保存响应、原件、拒绝原因、声明及模型采纳证据；每家单次测量不超过既有授权 20 次真实检索。
- [ ] 分别对账 HTTP 成功、有效原文、字段有效、模型可用缺口补齐与实际采纳，披露分层分母、零样本 N/A、失败、耗时及实际消耗；未知费用保持未知。
- [ ] 不混用旧探针或挑成功样本，不承诺预设命中率；预算/凭据不足按停止条件留证，新增 vintage 交给最终验收核对影响。
