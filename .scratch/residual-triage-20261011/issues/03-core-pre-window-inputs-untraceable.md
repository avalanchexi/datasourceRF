# 03：核心窗口前输入追溯断链（120 个编号追不到原始声明）

## 现象
体检第二层显示，每个投影的核心冻结输入中有 120 个编号（窗口前用于均线、斜率和持续确认的输入）追不到来源声明，原因是三核心窗口前的价格声明按留存规则在运行末尾清理（ADR-0035 的例外不含三核心价格）。体检票 04 只能改从回执原件补读，并标为“未核验”。模型规则票 01（回看约 260 点）落地后，这类编号会增加到约 140 个。

## 待分流确认
是否扩大留存例外、让投影引用的三核心窗口前声明随投影保留；代价（库大小）以及与 ADR-0022、0035、0040 的关系。这需要用户决定。
