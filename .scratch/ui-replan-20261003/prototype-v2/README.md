# 报告式首页原型 v2（静态页面，真实数据）

界面重规划第二轮访谈（[decisions.md](../decisions.md) "首页报告化"）定下的报告式长页原型：① 周期识别结论 → ② 三核心与同类资产 → ③ 海外与汇率 → ④ 宏观事后确认 → ⑤ 库存周期 → ⑥ 阶段历史 → ⑦ 数据说明与 AI 解读；二级页面"数据链路"（取数桑基图、检索降级链、证据链）与"运行状态"。只出一个视觉版本。

页面是单文件 `index.html`：模板 `proto-template.html` 里的 `/*__DATA__*/` 被替换成 `window.PROTO = {...}`，所有数值都来自运行库里的一个真实投影集及其加工批次，不放模拟数据。

## 刷新数据

在 WSL 内运行（只读打开运行库，不写）：

```bash
bash .scratch/ui-replan-20261003/prototype-v2/refresh.sh            # 当前投影
bash .scratch/ui-replan-20261003/prototype-v2/refresh.sh projection-xxxx   # 指定投影
```

流水线：`dump_projection.py`（导出该投影的数据集、运行行、报告、目录版本）→ `extract2.py`（确认度紧凑表、缺口、阶段色带、运行与取数计数、两条证据链）→ `extract3.py`（走势序列）→ `build_proto.py`（组装并注入模板）。中间产物在 `/tmp/pring-proto-<日期>/`。`summarize.py` 只用于人工阅读导出的 JSON，不参与构建。

元信息（投影号、运行号、目标日、模型、完整度、请求数、失败数、预算、耗时、目录版本）与各段说明文字（拒收、降级链、候选校验、请求按来源、最终计划缺期）都由数据生成；顶部身份栏标明页面生成时间。

## 已知的原型简化

- 数据链路页"门禁与未取到的期"表的"归因"列是手工对照验收记录写的映射（`REASON`），不在映射里的指标显示"计划未完成，见降级链"。生产页面应由 Worker 在最终计划里写入每期的门禁原因。
- 筛选控件为静态示意；"查看原文"按钮不打开原件。
- 阶段色带每个交易日取最后一次评估；首次初始化回填的历史日为"核心数据待处理"，随日常运行累积才会填满。
