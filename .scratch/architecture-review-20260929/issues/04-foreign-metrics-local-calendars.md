# 04: 外盘指标按当地交易日历判断应有期

**What to build:** 交易日历模块加入美股与美国国债市场两个市场；VIX、SOX 按美股日历，美债 2Y、10Y 及 2s10s 利差按美国国债市场日历判断应有期与宽限，不再套用上交所日历。

**Blocked by:** 02

**勿并行：** 03、09、16、18、19、20、21、24、27、28（同改：缺口清单与时效；交易日历模块；逐区明细见 [README](../README.md)「串行约束」）

**Status:** ready-for-agent

来源：[架构评审](../README.md) 候选 1 访谈，用户补充规则"外盘指标按当地交易日历"（已写入 `CONTEXT.md` 交易日历条目）。 规格：[spec.md](../spec.md)「二、交易日历模块」。

## 已定决定

| 指标 | 日历 |
|---|---|
| `CBOE_VIX_INDEX`、`NASDAQ_SOX_INDEX` | 美股 |
| `UST10Y_NOMINAL_YIELD`、`UST2Y_NOMINAL_YIELD`、`UST_2S10S_SPREAD` | 美国国债市场：美股假日＋哥伦布日、退伍军人节（债市休、股市开） |
| `CN_USDCNY_ECB_REFERENCE_CROSS` | **不改**，仍按上交所日历（用户：欧洲暂不重点考虑） |
| `EIA_BRENT_RBRTE`、`EIA_WTI_RWTC` | 周频，不用日历 |
| 中间价、16:30 收盘价 | 中国，不算外盘 |

- **来源：在项目内自写规则**，不引入 `pandas_market_calendars`（5.4.0 虽覆盖 NYSE/Cboe 与 SIFMA US，但不含 TARGET，且会引入 pandas、numpy、exchange_calendars，项目目前都不依赖）。
- 美股规则：元旦、马丁·路德·金纪念日、总统日、耶稣受难日、阵亡将士纪念日、六月节、独立日、劳动节、感恩节、圣诞节，含周末顺延规则（NYSE 元旦落在周六时不在前一周五休市）。实施时以 NYSE 与 SIFMA 官方假日页为准逐条核对，不凭记忆。
- 美国国债市场：按 SIFMA 建议的**全日休市**；提前收市日照常视为开市。
- 规则写不到的临时休市（如 2025-01-09 美国全国哀悼日）靠现有宽限期吸收，不追加特例。
- 运行期间日历槽改为按市场提供日历，时效判断按指标所属市场取日历；发布时点 `lag` 与更新时刻（上海时间）的含义在新日历下逐条复核。
