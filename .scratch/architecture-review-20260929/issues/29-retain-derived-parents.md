# 29: 留存保留派生观测引用的父声明（低优先级）

**What to build:** 留存清理时，保留仍在留存期内的派生观测所引用的父来源声明（及其原件关联），使派生血缘可回读；这是 ADR-0028 现行基准之外的第二个留存例外。

**Blocked by:** 无

**勿并行：** 08、16、17（同改：证据仓库；逐区明细见 [README](../README.md)「串行约束」）
