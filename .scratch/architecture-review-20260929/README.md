- **术语**：`CONTEXT.md` 新增"交易日历"。中国指标以上交所完整日历为准（只认核心口径、开市休市都列出）；**外盘指标按当地交易日历判断应有期**（用户补充，2026-09-29）。
- **删掉日历来源声明路径**：`CN_TRADE_CALENDAR` 来源声明生产从未写入（真实库 0 条），只有测试夹具写。交易日历只从回执读，相关测试改为造回执。
- **读和取都归日历模块**：取（`core_history.py:91`、`freshness.py:662`）与读（三处）集中，"写入用哪个口径、读取认哪个口径"只在一处；TuShare 作为适配器传入，测试用假适配器。
- **降级由调用方写明**：模块如实回答知道哪些日子、覆盖到哪、够不够窗口；提交运行的工作日推定、完整运行的严格要求、郑商所只取目标日，都留在各调用方显式表达。
- **统一截止时间**：模块接受一个截止时间，默认当前时间；完整运行传入冻结截止时间。
- **测试提速小票**：单独开 [01](issues/01-test-speed-existing-seams.md)，与候选互不依赖。（/to-tickets 核对：01 与 02 同改 `seed_core_history` 夹具，02 改为依赖 01。）
- **先重构、后加外盘**：候选 1 只做上交所日历的纯重构（行为不变）；外盘日历另开票，届时给模块加第二、第三个市场，此前不预留"市场"参数。
- **外盘指标跟随的日历**：VIX、SOX → 美股；美债 2Y/10Y 与 2s10s → 美国国债市场（哥伦布日、退伍军人节债市休、股市开）；欧洲央行参考汇率折算 → TARGET 假日；EIA 周频不用日历；中间价与 16:30 收盘价属中国。
- **日历修订按数据版本处理**：同一来源（TuShare）前后日历不一致取最新一次、变化记入运行记录，不阻断；原"日历冲突阻断运行"依赖测试里造的第二来源，随声明路径一并删除。
- **银行间调休周六**：DR007、SHIBOR、中间价仍按上交所日历判断应有期，不另建银行间日历。
- **外盘日历来源**：不引入 `pandas_market_calendars`（5.4.0 覆盖美股 NYSE/Cboe 与美债 SIFMA US，但不含 TARGET，且会引入 pandas、numpy、exchange_calendars）。美股、美债在项目内自写规则（美债＝美股假日＋哥伦布日、退伍军人节），临时休市靠宽限期吸收。**欧洲暂不重点考虑**：欧洲央行参考汇率折算维持现状。
- **广度改用日历模块**：广度不再自己请求只含开市日的 600 天日历，改向日历模块要上交所交易日；会改变 TuShare 请求，放在纯重构之后单独做。
- **运行期间日历槽迁入日历模块**（`use_run_calendar` / `current_calendar`），工作日推定行为不变。
- **测试迁移**：日历规则迁到模块接口（提交定目标日 3 例、今天两条回归、郑商所窗口 2 例、完整运行窗口缺核心日、新增日历修订取最新）；保留 `test_worker_calendar_gate.py` 与一例完整运行正路径；删除 `test_conflicting_calendar_cannot_claim_complete_window`；造 `CN_TRADE_CALENDAR` 声明的夹具改造核心日历回执。

## 候选 2 访谈记录：来源声明 → 可采用声明

勘察：[codex-survey-c2.md](codex-survey-c2.md)（两侧家族对照、口径差异、调用方与现有测试）。

- **术语**：`CONTEXT.md` 新增"可采用声明"。已验证证据管写入门槛，可采用声明管读取时点（原件、命中原话或注册契约三者之一复核一致，且成员齐全）。
- **先纯重构、后统一口径**：两侧现有口径原样收进一个模块，行为不变；勘察出的差异逐条列出，另开票逐一统一。
- **只收复核、不收选值**：模块输入已选好的序列、输出可采用结果；选值（`metric_series` 与目标日重选）留在证据仓库与目标日包装层。仓单（最新完整交付）与降准（整份公告）的选择与复核本在一个函数里，原样作为家族挂入。
- **位置**：新建 `src/pring_cycle/claim_adoption.py`，传入 `EvidenceRepository`；不挂到 `evidence.py`（1845 行，且各家族核对函数依赖它，会循环导入）。
- **差异定性（全部判为遗漏，纯重构后另开票）**：
  1. 投影不复核融资余额、指数行情、估值的原件 → 投影走同一家族表。
  2. 仓单某品种缺成员时投影把当天所有品种判不完整 → 改为逐品种，与检索侧及 ADR-0032 一致。
  3. 投影目标日重选（`_selected_among`）忽略认证状态，资讯／媒体（`not_applicable`）声明参与排序与冲突比较 → 复用仓库的选值排序与冲突范围（属选值，不进本模块）。
  4. `source_failed` 覆盖 `conflicted`，冲突从缺口清单消失 → 清单两者都列（低优先级）；顺带查时效未检查 `selection_status`。
  5. 时效与完整运行需求不看可采用 → **维持现状**：时效只记录取到哪一期，可否采用由投影与缺口清单表达。
- ECB 投影侧少一层 `BUILTIN` 判断：底层已豁免，无行为差异，重构时顺手对齐。
- **接口形状**：输入定义版本与"指标 → 待复核的点"批量映射，复核范围由调用方决定（检索传 adoptable 统计期内的点，投影传可见窗口整条序列）；输出按指标给可采用 ID、不可采用 ID、缺失成员（仓单按期＋品种、降准按公告）。纯重构不加原因码。逐成员期望、事件类"最新过期不退回"、`material_checks` 留在检索侧。
- **核心 P0 作为家族纳入**：来源身份检查＋原件重解析；检索、Worker 核心就绪（`worker.py:1146`、`:1183`）、投影 OMO 到期推算（`context_projection.py:898`）三处改走模块。核心就绪的落后期数、沿用规则仍在 Worker。
- **投影内派生输入也改走模块**：OMO 金额、政策利差、贷款结构、PMI／国债最新合格期、信用脉冲父声明六处。
- **内置目录豁免收进模块一处判断**，不趁机删除内置目录（42 个测试文件在用，另议）。
- **测试**：每个家族至少一例"原件／原话损坏即不可采用"，加降准整份公告缺成员、仓单缺仓库只缺该品种（现行为）、内置目录豁免；补 `CoreInputValidator`、`news_claims_matching_quotes`、`select_published_rrr_events`、`treasury_claims_matching_acquisitions` 的直接测试；`test_gap_source_repairs` 国债取值断言移到模块接口。穿过选值器／投影的现有用例保留，作为行为不变的回归网；纯重构期间只增不删。
