# 规格：目录全部口径的真正缺失归零，及验收遗留修正（2026-10-14）

来源：[反复出现的输入缺口](../recurring-input-gaps-20261013/goal.md) 票 05 收尾验收（[acceptance-20261014.md](../recurring-input-gaps-20261013/acceptance-20261014.md)），以及用户 2026-10-14 对遗留的决定。本规格覆盖本目录的票 [01](issues/01-usdcny-close-previous-day.md)、[02](issues/02-sox-source.md)、[05](issues/05-audit-new-cutoff-effective-time.md)、[06](issues/06-rrr-lookback-cutoff-readability.md)；票 03、04 并入收尾验收，票 07 不在范围内。

## Problem Statement

T+1 自动运行 `run-25ac18e4…` 已做到“仅模型用到”口径的真正缺失为 0，但用户要求**目录全部**口径也为 0，眼下还差两项：

- **SOX**（`NASDAQ_SOX_INDEX`）：ADR-0029 把它定为受限授权 P2，没有取数路径，每次体检都在目录全部口径计 1 项真正缺失。缺口每次都在，真正的新缺失会被它淹没。
- **人民币 16:30 收盘价**（`CN_USDCNY_CLOSE_1630`）：来源是中国外汇交易中心的盘中图表文件，只给当前交易时段。调度改到 09:30 以后，运行时当天的 16:30 还没到，前一交易日的收盘价又已不在文件里。所以自动运行从此取不到它：10-13 还能按“落后 1 期”算完整，从下一次运行起就会落后 2 期以上，进入目录全部口径的真正缺失。

另有两处验收遗留，会让体检误报，或让回溯悄悄用了截止时读不到的东西：

- **体检**：从 `run-25ac18e4…` 起，目标日投影会用次晨公开的数据。体检派生层仍按“该日结束”读，读到新投影时可能误报“库中期次晚于独立判断”。
- **官方降准回溯**：找到一条声明就停，没有复核该声明在运行截止时是否可读。

## Solution

- **16:30 收盘价**：09:30 的计划运行能持有**上一交易日**的 16:30 收盘价（T+1）。用户的要求是“取到上一日数据即可”，不必追求当天。
- **SOX**：接入真实取数路径。先用 TuShare；TuShare 取不到时，以**可信网站发布的信息**为标准口径；**不用 ETF 代理**（如 SOXX）。接入后，体检对 SOX 照常按应有格核对，不再列为授权缺口。
- **体检**：内置新口径的生效时刻。此前的运行按旧口径读，此后的按新口径读，不再误报。
- **降准回溯**：只停在运行截止时可读的声明上；读不到的，继续往前找。

收尾验收用一次不休眠的 09:30 计划运行，确认以下几点：

- 目录全部口径的真正缺失为 0；
- 16:30 收盘价持有上一交易日；
- SOX 持有目标日或按其时效规则应有的期次；
- 顺带复测有效运行耗时（票 03），并取得 09:30 准点提交的样本（票 04）。

## User Stories

1. 作为研究者，我希望每天 09:30 的自动运行都持有上一交易日的人民币 16:30 收盘价，这样汇率背景不会一天天落后。
2. 作为研究者，我希望 16:30 收盘价按 ADR-0029 的时效规则计算：目标日 T 持有 T-1 就算现行。这样体检不会因为当天还没收盘就报缺。
3. 作为研究者，我希望取 16:30 收盘价时仍不误取 03:00 的夜盘收盘，这样数值的口径不变。
4. 作为研究者，我希望 16:30 收盘价的取数仍在运行的证据刷新里串行完成，不新增一轮每天的独立运行，这样外部调用和报告不会翻倍（ADR-0041 否决过“当晚和次晨各跑一次”）。
5. 作为研究者，我希望文件里只有当前交易时段时，运行记“来源为空”，不报错，这样回执能说明原因。
6. 作为研究者，我希望 16:30 收盘价缺了几天时，运行能补回窗口内缺的上一交易日（如果来源能按日期取），这样休眠或停机后不会长期缺数。
7. 作为研究者，我希望 SOX 有真实的取数路径，这样目录全部口径不再永久计它一项真正缺失。
8. 作为研究者，我希望 SOX 优先从 TuShare 取，这样它和其他行情共用一套凭据、限流和回执。
9. 作为研究者，我希望 TuShare 没有 SOX 时，以可信网站发布的数值为标准口径，这样来源可以追溯、可以核对。
10. 作为研究者，我希望 SOX 绝不用 ETF（如 SOXX）代替，这样指标的定义不会被悄悄换掉。
11. 作为研究者，我希望 SOX 接入后仍是 P2 参考指标、不进模型，这样模型输入不变。
12. 作为研究者，我希望 SOX 的期次、单位与美股交易日历（NYSE 假日表）一致，这样体检按 US_EQUITY 日历核对时口径相同。
13. 作为研究者，我希望 SOX 的每次取数都留回执和原件，解析失败按来源失败记录原因码，这样事后能追溯。
14. 作为研究者，我希望改变 SOX 的处理时有 ADR 记录（补写 ADR-0029 或新增一条），写明选了哪个来源、为什么可信，这样以后不会被当作未经批准的改动。
15. 作为研究者，我希望体检在 SOX 有取数路径后把它移出“无取数路径”的内置表，说明文档也同步更新，这样体检不再无条件地列出它。
16. 作为研究者，我希望在新口径生效时刻之前受理的运行，体检仍按旧口径（目标日结束）读，这样旧运行的体检结论不变。
17. 作为研究者，我希望新口径生效之后的运行，体检派生层按运行截止读次晨公开的数据，这样不会误报“库中期次晚于独立判断”。
18. 作为研究者，我希望新口径生效时刻是一个写死的时点，取 `run-25ac18e4…` 的受理时刻 `2026-10-14T03:40:33Z`，做法与现有的 ADR-0036 生效时刻一致，这样体检行为可以复现。
19. 作为研究者，我希望体检改动仍守体检线规程：只用标准库、不导入生产代码、运行库只读、规则只依据文档。这样体检能独立判断生产代码是否出错。
20. 作为研究者，我希望降准回溯只认在运行截止时已可读的声明，这样目标日的判断不用截止之后才公开的信息。
21. 作为研究者，我希望回溯遇到截止时读不到的声明，继续往更早的期刊找，而不是停下记 `found`，这样结果仍是截止时最新可读的降准。
22. 作为研究者，我希望声明解析失败时回溯照旧停止，这样不会拿更早的一次降准顶替读不出的那次。
23. 作为研究者，我希望没有降准声明时，回溯照旧报 `none_stated`，这样监测的语义不变。
24. 作为运维者，我希望收尾验收用一次 09:30 准点的计划运行，这样“准点提交”第一次有真实样本。
25. 作为运维者，我希望收尾验收前有提醒：调整 Windows 电源设置，让机器在 09:30 前后不休眠。这样准点样本不会又变成补交路径。
26. 作为运维者，我希望收尾验收记录有效运行耗时，并和 `run-0a8dabc2…`、`run-25ac18e4…` 对比，这样能判断票 03 的变慢是否复现。
27. 作为运维者，我希望全套测试、真实运行前都跑时钟检查，退出码为 0 才开跑，这样时钟回拨不会污染结果。
28. 作为运维者，我希望 SOX 和 16:30 收盘价的外部调用一律串行，这样不触发来源的限流或反爬。
29. 作为研究者，我希望收尾体检里目录全部口径和仅模型用到口径的真正缺失都为 0，或者每一项都有已定性的原因（如上游未发布），这样真正的新异常一眼就能看出来。

## Implementation Decisions

- **16:30 收盘价：先调查，再选做法**。两种候选：
  - **首选**：中国外汇交易中心官方、能按日期查询历史 16:30 收盘价的接口（只读调查，外部调用串行）。找到就作为新的 P2 行情来源登记，替换现行的盘中图表文件，按窗口补齐缺的日子。
  - **退路**：保留盘中图表文件，Worker 在 16:30 之后、当天 P0 截止前取一次当天收盘价。这只是对单个来源的一次取数，不是一次完整运行，不生成评估或报告。
  - 无论哪种，都不放宽现行解析规则：只认 16:30 收盘点，不取 03:00 夜盘收盘，盘中快照与收盘值必须一致。
- **16:30 收盘价的时效规则不变**：滞后一个交易日即现行（ADR-0029）。
- **SOX：先调查，再登记**。
  - 先确认 TuShare 是否有 SOX（如全球指数类接口的覆盖范围），结论写入票 02。
  - TuShare 有：走现有 TuShare 行情适配器，登记为 SOX 的取数路径。
  - TuShare 没有：从“可信网站发布的信息”中选一个能按日期取收盘值的来源，作为新的 P2 行情来源登记。可信的依据要写入 ADR。不用 ETF 代理，不用任何近似指数。
- **SOX 的取数路径登记**：从“受限授权、不检索、无取数路径”改为“有注册来源、不检索”。
  - 目录中对 VIX、SOX 的特殊处理（不检索）保留；
  - 目录版本是否要升，按现行目录版本规则由实施方判定；
  - SOX 不进模型。
- **ADR**：补写 ADR-0029 的 SOX 一条，或新增 ADR 部分取代它。写明来源、可信依据、用户 2026-10-14 的决定（先 TuShare，否则可信网站，不用 ETF）。
- **体检的 SOX 处置**：SOX 有取数路径后，从体检的“无取数路径”内置表移出；体检口径文档里“SOX 的授权缺口”“永久缺口”两段相应改写。生效前的运行仍按当时的口径解释。
- **体检的新口径生效时刻**：
  - 在体检派生层内置常量 `2026-10-14T03:40:33Z`，做法同现有的 ADR-0036 生效时刻：以运行受理时刻判断新旧口径。
  - 生效后的运行，派生层对目标日按运行截止读，与 ADR-0041 2026-10-13 补写一致；生效前的运行仍按该日结束读。
  - 体检口径文档同步写明。
- **降准回溯**：回溯在某期刊里找到降准声明后，复核该声明按其公开时间在运行截止（`public_as_of`；未给时为目标日结束）时是否可读。
  - 读不到：不收这条，继续往更早的期刊找；
  - 解析失败：照旧停止；
  - 没有声明：照旧 `none_stated`。
  - 栏目列表日期与正文发布时间的关系，按票 06 已定的口径处理：期刊按栏目日期次日公开。
- **外部调用**：本批全部的调查和实跑都串行，不高并发。

## Testing Decisions

- **好的测试**：只测外部行为，即给定来源应答，库里持有什么、回执与检索尝试记成什么；不测内部步骤。外部请求一律用夹具顶替，不发真实请求。
- **16:30 收盘价与 SOX**：
  - 都在“单个 P2 行情来源刷新一次”这个现有接缝上测（`refresh_quote_source`）。参照 `tests/adapters/test_quote_sources.py`，以及 `tests/integration/test_retrieval_p2_lenient.py`、`tests/integration/test_gap_source_repairs.py` 中涉及 16:30 收盘价的用例。
  - 若 SOX 改走 TuShare，就在现有 TuShare 行情适配器的接缝上测，参照同类 TuShare 行情的适配器测试。
  - 要覆盖：上一交易日能持有；只有当前交易时段时记“来源为空”；夜盘收盘不被取；解析失败记来源失败与原因码；SOX 按日期取到收盘值且不用 ETF。
- **降准回溯**：在现有 `backtrack_rrr_chronicle` 接缝上测，参照 `tests/integration/test_rrr_backtrack.py` 与 `tests/adapters/test_rrr_context.py`。
  - 新增用例：较新的期刊含降准声明，但在截止时读不到，回溯跳过它，取到更早的、可读的那条。
  - 原有“解析失败即停”“无声明”用例保持通过。
- **体检**：体检线不写单元测试，按体检线规程以实跑对账为准。
  - 对 `run-0a8dabc2…`（生效前）重跑，结论与已存报告一致；
  - 对 `run-25ac18e4…` 及收尾运行（生效后）重跑，派生层不再出现“库中期次晚于独立判断”的误报。
- **测试执行**：按 `docs/agents/testing.md`（ADR-0025）选受影响测试。切片收尾跑冒烟，终点前跑全套；重型测试在 `flock /tmp/pring-heavy.lock` 下跑。
- **收尾验收**：一次不休眠的 09:30 计划运行。
  - 体检中目录全部、仅模型用到两个口径的真正缺失都为 0（或逐项已定性）；
  - 16:30 收盘价持有上一交易日；SOX 持有应有期次；
  - 记录准点提交的证据与有效运行耗时（票 03、04）。

## Out of Scope

- 票 07 的观察项（心跳 `database is locked`、调度日历 SSL EOF）：先观察，不处理。
- 有效运行耗时变长的剖析：本批只复测；复测仍慢，再按票 03 另行剖析。
- 上一批遗留 [model-rules-residuals-20261013](../model-rules-residuals-20261013/README.md) 的 8 张票，仍待分流。
- 16:30 收盘价当天取到（T+0）。用户只要上一交易日。
- SOX 进入模型或参与确认规则。
- 不属于本规格的其他 P2 指标来源变更（VIX、UST、中间价、ECB 交叉汇率），包括 Nasdaq 官网未公开行情接口：除非调查认定它就是“可信网站发布的信息”，而且有 ADR 记录。
- 集成分支 `recurring-input-gaps` 是否并入 main：由票 05 收尾后用户决定，与本规格无关。本批的基线分支在实施前另定。

## Further Notes

- 用户 2026-10-14 的原话：16:30 收盘价“这个问题不用在意，获取上一日数据即可”；SOX“如 tushare 无法获取，可以通过可信网站发布的信息为标准口径。不使用 etf 代理。”
- 按项目规程，耗 token 的只读调查（中国外汇交易中心历史接口、TuShare 的 SOX 覆盖、可信网站候选）交给 `codex exec -s read-only … < /dev/null`；涉及外部访问的核实一律串行。
- 收尾前要用户调好 Windows 电源设置（票 04，`ready-for-human`），否则准点样本仍会落空。
- 体检的生效时刻取的是受理时刻，不是冻结截止，这与 ADR-0036 生效时刻的取法一致。
