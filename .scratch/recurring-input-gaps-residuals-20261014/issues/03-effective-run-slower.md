# 03：有效运行耗时变长，根因未明

## 现象

`run-25ac18e4…` 扣除休眠后约 2014 秒（33.6 分），对照运行 `run-0a8dabc2…` 755 秒（12.6 分）。增量约 95% 在取证据阶段：直接上下文刷新 259→529 秒；直接上下文结束到新闻开始的间隔 70→432 秒；仓单补缺四次检索 latency 合计 84.5→473.5 秒（其中 07-21 一次 304.8 秒是复用本轮空应答，未发外部请求）。休眠前的阶段（11:40–11:58）也比对照慢，不能全部归因于唤醒。

## 建议

在下一次不休眠的计划运行上复测；仍然慢，再剖析（系统资源、数据库访问、本地扫描）。
