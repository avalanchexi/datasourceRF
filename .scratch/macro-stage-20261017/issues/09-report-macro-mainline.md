## Comments

### 2026-10-19 实施（ticket-ms09，分支 ms-09）

- **契约**：投影带 `cycle_overview.macro_judgement` 时报告走新契约 `report-schema-v0006`／`report-prompt-v0011`（`reports.py` `MACRO_*`）；无宏观块的旧输入（v0008／v0009／非典型 v0010）原样不变。
- **输入**：`conclusions` 增 `macro_stage`、`macro_confidence`（AI 须原样回显，输出 schema 以 const 锁定）；`results.macro_judgement` 只放报告需要的字段：标题、滞回保持句、兜底句（均取 `macro_board` 的页面写法）、主结论、原始判断（含并列与兜底摘要）、滞回状态（仅标量）、得分、五维（方向、高低位、吻合、整句、各指标投向）、信号（分组、转换、成熟度、分化重判的阶段与把握程度、整句）、价格验证（含只差一项的比较与整句）；无证据或观测 ID。有宏观块时不再放 `noncanonical_basis`，非典型日改由价格验证承载（"价格偏离宏观判断"）。
- **提示词**：`macro_reading_contract` 规定 `宏观判断与五维依据 → 转折信号 → 价格验证与偏离` 的顺序，倾向／弱须如实写出，宏观判断与价格阶段分称；取代旧非典型固定句契约。
- **校验**（`_misstates_macro`、`_leaves_confidence_unstated`）：宏观主结论（"宏观判断为／当前处于第 N 阶段"）、当日原始判断、价格阶段各按其主体比较；带把握程度的阶段只能是主结论、原始判断或分化重判之一；非明确判断不得称明确或"已确定"；倾向／弱全文未写出即拒收。旧 `_stated_stages`（对价格阶段）与非典型固定章节限制只在旧契约下生效。
- **模板**：双 CLI 失败时 `ai_explanation` 为同顺序三段确定性模板，`explanation_source=deterministic_template`；阅读页对宏观模板同样列出结构化事实（`dashboard._report_reader`）。
