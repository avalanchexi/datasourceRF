# 06: 家族查询模板与域名限定

**What to build:** Tavily/Exa 查询按家族发布稿标题模板加中文统计期生成，请求带“官方主机＋媒体白名单”域名限定；Exa 同时请求正文摘要。建立媒体白名单常量。检索记录可见实际查询文字与域名清单。

**Blocked by:** 01

**Status:** done

Spec: [spec.md](../spec.md)

- [x] 每个登记家族（含 LPR、中证核心、三项 P2）有查询模板，不再使用指标 ID 与来源编码
- [x] 经公开入口断言：Tavily 与 Exa 请求携带模板查询与域名限定
- [x] 媒体白名单常量包含规格所列国内外媒体，Wind 不在其中
- [x] 检索记录包含查询文字与域名清单
- [x] 受影响测试经 `check.py quick` 通过；切片收尾两例快速冒烟通过（按 ADR-0025）

## Comments

- 2026-09-24 完成。检索登记处为每个家族（14 个官方家族、LPR、中证核心按指标分题、三项 P2）登记查询模板，`search_query` 以发布稿标题写法加中文统计期生成（如“2026年8月份居民消费价格”“2026年二季度和上半年国内生产总值初步核算结果”“2026年8月贷款市场报价利率（LPR）公告”），不再含指标 ID 与来源编码。新增 `MEDIA_WHITELIST`（国内 12、国外 8 家，按域名及其子域匹配，不含 Wind）与 `media_outlet`、`search_domains`（该家族官方主机在前、媒体白名单在后）。
- Tavily 请求加 `include_domains`；Exa 加 `includeDomains` 与 `contents.text`（1500 字）。检索记录 `retrieval_query` 新增 `domains_json`（迁移 0029，`SCHEMA_HEAD` 同步），快照 `queries[].domains` 可见；取数参数同时记下域名。不属于任何登记家族的范围不再构造搜索适配器。
- 测试：模板与白名单、请求载荷单测；完整运行断言 LPR 查询为模板标题、域名限定以中国货币网开头并含媒体，检索记录的域名与请求一致；Exa 顶替例断言同一标题、域名与正文请求。受影响 312＋2 例全过。
