# 08: TuShare 资讯渠道

**What to build:** 每次完整运行在 TuShare 数据接口之后、官方直连之前统一拉取一次 `major_news`（上次成功运行截止至本次截止，首次取最近 3 天，按 400 条翻页）；各缺口按家族规则本地筛选，命中即补齐，之后各级不再调用（TuShare 优先）。资讯原件 3 天后在成功运行末尾的留存清理中删除，命中原话保留。拉取失败只记批次、不阻断。
