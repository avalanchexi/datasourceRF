# 11: AI WebSearch 适配器

**What to build:** 降级链最后一级由 Codex CLI 联网搜索执行、失败或超时改用 Claude Code，均按固定结构返回候选（网址、原话、数值、统计期、发布日期）；每个候选校验白名单主机、家族规则命中且取值一致、统计期、发布日期后补齐缺口并留存命中原话。每缺口每次运行一次、单次 300 秒、每次运行合计 60 分钟；不注入任何模型 API key。

**Blocked by:** 06, 07

**Status:** ready-for-agent

Spec: [spec.md](../spec.md)

- [ ] 经公开入口断言（假 CLI 可执行文件）：Codex 返回合规候选时补齐 P1 缺口
- [ ] Codex 超时后由 Claude 补齐
- [ ] 非白名单网址、原话与数值不符、统计期不符的候选被拒并记原因
- [ ] 累计时长到 60 分钟后剩余缺口记“AI 时长已用尽”不再调用
- [ ] 检索记录含适配器、耗时与逐候选结果
- [ ] 受影响测试经 `check.py quick` 通过；切片收尾两例快速冒烟通过（按 ADR-0025）
