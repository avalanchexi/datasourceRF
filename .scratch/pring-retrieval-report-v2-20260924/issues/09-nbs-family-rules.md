# 09: 国家统计局家族的资讯解析规则

**What to build:** 为国家统计局各家族（PMI、工业增加值、工业企业效益、产能利用率、GDP，及 CPI/PPI 以外的核心 CPI 成员）登记资讯解析规则，使这些 P1/P2 缺口可经资讯、媒体与 AI 途径补齐。

**Blocked by:** 07

**Status:** ready-for-agent

Spec: [spec.md](../spec.md)

- [ ] 每个国家统计局家族的每个指标/维度成员都有规则
- [ ] 每条规则有真实资讯或媒体样本测试（命中与不命中各至少一例）
- [ ] 经公开入口断言：至少一个 PMI 缺口经资讯补齐
- [ ] 受影响测试经 `check.py quick` 通过；切片收尾两例快速冒烟通过（按 ADR-0025）
