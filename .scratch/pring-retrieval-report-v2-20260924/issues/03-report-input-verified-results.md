# 03: 精简报告输入：只交已验证结果

**What to build:** AI 报告只接收已验证结果（正式阶段或空阶段原因、三核心状态与变化原因、宏观与库存结论、核心沿用、缺口概况；每项附结果值、来源、是否有异常），不再附证据链、不再逐段引用证据；生成后只校验结论未被改写与结构合规（ADR-0027）。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

Spec: [spec.md](../spec.md)

- [ ] 经公开入口断言（假 CLI 可执行文件）：报告输入不含证据编号、逐条证据行与观测序列，体积显著小于首次真实运行的 14.6 万字节
- [ ] AI 输出改写正式阶段、核心状态或宏观/库存结论时被拒收并降级
- [ ] 段落结构不再含证据与治理引用字段，禁用词检查保留
- [ ] 两路失败时确定性报告照常生成且不含证据引用
- [ ] 新快照记录新的输入与提示版本，旧快照照常可读
- [ ] 受影响测试经 `check.py quick` 通过；切片收尾两例快速冒烟通过（按 ADR-0025）
