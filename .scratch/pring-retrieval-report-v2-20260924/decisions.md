# 检索与报告二期：访谈决定（2026-09-24）

来源：首次真实完整运行（pring-fast-refactor-20260923 票 28）暴露的三项遗留，经 `/grill-with-docs` 访谈逐题确认。术语见 [CONTEXT.md](../../CONTEXT.md)，取舍见 [ADR-0026](../../docs/adr/0026-news-and-media-values-by-family-extraction-rules.md)、[ADR-0027](../../docs/adr/0027-report-input-is-verified-results-without-evidence-chain.md)。

## 事实依据（真实运行）

- 16 次 Tavily 查询由“指标 ID + 中文名（多数即 ID）+ 来源编码 + 统计期 + 官方 发布”拼成，43 个候选中 42 个不在白名单，13 个是 TuShare 文档页；搜索预算大半花在网页上根本不存在的派生指标上。
- TuShare `news` 无权限，`major_news` 可用：发布后几分钟内即有带数值的资讯（如 9-09 CPI，新华网与华尔街见闻 9:47–9:53），无关键词参数，只能按时间段拉取，每次 400 条。
- 报告证据包 14.6 万字节（结构化上下文 11.6 万，允许引用 ID 清单 2.8 万）；Codex 与 Claude 各 300 秒超时、零输出。
- 本机 `codex exec --search` 与 `claude -p` 的 WebSearch 工具都可联网，并各有结构化输出参数。

## 一、搜索与取数

1. **可检索缺口**：只对属于登记解析器家族或登记了宽松主机的缺口搜索；由 TuShare 计算的派生指标、NHII 等没有网页来源的缺口不搜，TuShare 重试后直接列缺口，原因“无可检索来源”。
2. **域名限定**：调用 Tavily/Exa 时把该家族的官方主机加媒体白名单作为域名限定传入（`include_domains` / `includeDomains`）。
3. **查询模板**：每个家族一条代码常量模板，按发布机构发布稿标题的写法，加中文格式统计期（如“2026年8月份居民消费价格”）。
4. **媒体白名单**（代码常量，随版本变化）：
   - 国内：财联社、新华网、人民网、中国政府网、中国证券报、上海证券报、证券时报、第一财经、财新、华尔街见闻、新浪财经、东方财富。
   - 国外：路透、彭博、CNBC、MarketWatch、华尔街日报、金融时报、雅虎财经、Investing.com。
   - Wind 没有公开新闻网页，不列入。
5. **TuShare 资讯**：接入 `major_news`，位于降级链 TuShare 数据接口之后、注册官方直连之前。每次运行统一拉取“上次运行至本次截止”的全部资讯，各缺口本地筛选。原件只保留 2–3 天，解析后即删除。
6. **TuShare 优先**：TuShare（数据接口或资讯）取到值后，不再去官方或媒体页面。
7. **取值范围**：TuShare 资讯、白名单媒体网页与 AI WebSearch 的数值，P1/P2 可用，但须命中该家族登记的资讯解析规则（只认规则句式，不做通用抽取）；P0 只认 TuShare 与注册官方来源。
8. **追溯**：被采用的明细保存命中原话、标题、来源、发布时间和正文哈希，与明细同样留存 120 个交易日。

## 二、AI WebSearch

1. **工具**：Codex CLI 与 Claude Code 自带的联网搜索，Codex 先、Claude 备（与报告一致）。
2. **返回结构**：固定结构，含网址、原话、数值、统计期、发布日期。网址须在官方或媒体白名单内；采用范围与追溯方式同“一”的第 7、8 条。
3. **限制**（业务上没有上线压力，系统层面只设宽松上限）：每个缺口每次运行至多一次，单次调用 300 秒，每次运行总时长 60 分钟。

## 三、AI 报告

1. **报告输入**：只交已验证结果，每项三样：结果值、数据来源、是否有异常（核心沿用、缺口、落后、冲突）。不含上下文证据、逐条证据行、观测序列与证据编号。
2. **不引用证据链**：报告不逐段引用证据或反证，追溯由投影与批次承担。
3. **后置校验**：只查两点：AI 没有改写正式阶段、核心状态和宏观/库存结论；输出符合固定结构。
4. **超时**：单适配器保持 300 秒，双适配器降级与确定性回落不变。
