# 规格：核心历史覆盖、T+1 调度与体检补全（2026-10-11）

依据：[访谈记录](interview.md)、ADR-0040、ADR-0041。

## 1. 核心价格历史（ADR-0040）
- 每次运行三核心价格固定回看约 260 个交易日（120 日窗口加 140 点测量门槛），窗口内每个交易日都有核心状态；“历史不足”只可能出现在上游历史本身就不够的时候。
- 当前没有有效正式阶段、而现有历史中找不到上一确认阶段时，按年向前取三核心价格，找到即停，最长 5 年。回溯的历史只用于计算核心状态和阶段历史，不进入宏观确认度，不改变留存。页面和报告标明“回溯得出”。
- 外部调用串行，三核心各用区间请求。

## 2. 自动盘后运行（ADR-0041）
- 每个上交所交易日上午 9:00 发起，目标交易日为上一交易日。日历的覆盖检查、补取与暂缓沿用票 14 的做法，判定对象改为“今天、上一交易日”。
- 上游未发布的最新一期，暂用上一期数据并标注（现行做法，写入文档即可）。

## 3. 规则文档化（供体检独立核对）
在 `docs/development/data-quality-audit.md` 或独立的规则文档中，按现行做法写明以下规则，并注明出处是本次访谈：
- A5 核心沿用的计算方式；
- 商品篮子分项广度：121 日跨度、首日作锚、分项贡献求和、篮子按分项贡献合计复利、持平单列；
- 库存象限三条线的主、辅成员与方向比较。

## 4. 体检补全
- 体检第一层的派生部分：商品篮子分项广度改为按第 3 节的规则独立重算；
- 体检第三层：独立核对库存象限三条线的主、辅成员比较与分化识别；
- 体检报告的已知局限中写明：确认度在典型组合下尚无真实数据验证。

## 不做
- 历史回放；
- 改动 A4、A5、A6 的计算语义；
- 新增留存例外。
