## 角色

- **主 agent（`/goal` 会话）只做调度与核验**：派票、核验提交与票面、执行 `git merge --ff-only`、清理 worktree、记进度、把问题转给用户。不亲手写实现代码，不亲手跑重型测试。
- **每张实施票派一个新的命名子代理**（Agent 工具，后台运行），从零上下文开始，相当于每张票之间执行一次 `/clear`；票之间并行时用 `isolation: "worktree"`。子代理完成并核验后，立即发出关闭请求。
- **只读调查、分流取证、两轴审查**一律用 `codex exec -s read-only`（见 `docs/agents/codex-delegation.md`），不开 Claude 子代理。
- 子代理的长任务（全套测试、真实运行、重型用例、Codex 审查）**必须在前台轮询守到结束**，不能交给后台等待器后转入空闲。主 agent 发现子代理空闲而票未完成时，发消息叫醒。

## 何时停下来问用户

- 预设决定之外的领域选择：攒成一批再问，不要逐条打断。
- 某张票经过两轮审查后，仍有不属于“修复确认”的阻断。
- 出现与本批无关的测试失败，且无法判断是不是原有问题。
- C 盘余量低于 20G；真实运行失败，修一次后仍然失败；大面积网络故障（成片的 URLError），这种情况停下回报，不要连续重跑。

除此之外不要停顿，按依赖关系一直推进到终点。会话中断后重启：先查看 worktree、未提交改动、日志和审查输出里已有的进度，再派新代理接手，提示词里写明断点。
