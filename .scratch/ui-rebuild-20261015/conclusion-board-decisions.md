# 结论板对齐决定（2026-10-16）

用户要求阶段 0 先按 Claude Artifact（`https://claude.ai/artifact/6smcdW6qb81iyN3Syz7j4s`，"周期驾驶舱原型 v2"）的布局调整前端，核心诉求是把 Pring 周期识别正确展示出来。两轮访谈共 13 问，用户全部确认。本文件收束决定，供票 14 引用。Artifact 的 HTML 已保存于会话工具结果，① 段渲染逻辑见其 `window.PROTO` 之后的脚本 `s1` 部分。

## 检查结论

新站 01 段内容项齐全，但识别结论的表达弱于 Artifact ①：

1. "原因"没有写出三资产组合，读者要翻到表格才知道债 / 股 / 商各是什么方向。
2. 用词偏离词汇表：界面用"偏多 / 偏空"，词汇表定义核心资产状态为稳定牛市或熊市；标题"当前阶段暂不判定"暗示未判，词汇表说条件不成立时为空。
3. 结构是卡片加散落段落与折叠块，Artifact 是一张结论板（左栏标签 / 值五行，右栏确认度五维加四行，下接三核心表与事实行）。
4. 三核心表十列，30 日候选方向与资产候选状态分两列（分法正确，Artifact 把两者合并成"牛市 · 0 天"是错的）。
5. 板底缺事实行与 AI 解读首句。
6. 顶栏身份字段只有目标交易日、分析截止、投影。

## 决定

1. **范围**：本次只做 01 段"周期识别结论"与顶栏身份字段；②～⑦ 段布局差异另开票。
2. **状态用词**：核心资产状态全站统一"牛市 / 熊市"，替换"偏多 / 偏空"（`dashboard.py` 的 `_state_label` 与方向映射一处改动，看板、历史页、报告页一起变）。30 日候选方向与资产候选状态同样用牛市 / 熊市。
3. **无阶段标题**：当前阶段为空时大标题"暂无正式阶段"，替换"当前阶段暂不判定"。
4. **原因行写明组合**：固定写出三资产当前状态与规则结论。非典型："非典型组合：债券牛市 · 股票熊市 · 商品牛市，不在六个典型组合内；不创建 Stage VII/VIII"。有正式阶段："典型组合：债券牛市 · 股票牛市 · 商品熊市 → Stage II"。
5. **其他无阶段原因**：核心数据待处理、核心状态不可用、P0 未过门禁时同样写出三资产，可用的写状态、受阻的写阻因（来自核心沿用与缺口清单），例如"核心数据待处理：债券牛市 · 股票（落后 2 期，沿用 09-30）· 商品牛市"。
6. **左栏五行**：原因、上次确认、转折观察、核心沿用、判法。上次确认保留回溯说明（ADR-0040），不照抄 Artifact 样例的"无"。
7. **判法行从冻结规则生成**：读投影所冻结模型版本的趋势规则参数生成文案，例如"MA120 + 20 日斜率定稳定牛熊，噪声带 1.5×20 日波动，持续 8 日确认，30 日候选只作转折观察；宏观与库存只做事后确认，不改写阶段 · model-v0015"。不写死数字。
8. **右栏**：确认度标题（可评估 / 不适用，关键指标项数，规则版本）、五维小格（每格写"N 项"与支 / 反 / 观 / 未计数），其下四行内联展示：价格一致性、库存象限、债券归因、数据边界（缺口项数、历史期未取到数，链到 ⑦ 与数据链路）。去掉现有折叠块。
9. **三核心表九列**：三核心、状态、最新、距 MA120、20 日斜率、候选、近 5 日、近 120 日、120 日走势。"候选"一列两行，标签用词汇表术语："30 日候选方向 牛市"与"资产候选状态 无 / 熊市 · 持续 3 日 / 门槛 8 日"。不合并为"牛市 · 0 天"。
10. **板底事实行**：第一行 AI 解读，按报告状态区分：有 AI 解读写首句加"全文"链接；确定性模板写"本次报告为确定性模板，无 AI 解读"并注明适配器失败原因；生成中写"报告生成中"；无报告写"报告尚未生成"并链到 ⑦ 段生成按钮。第二行目标交易日、模型版本、外部请求数与失败数、检索预算用量、耗时，取已持久化的运行摘要；旧运行无摘要时显示"口径不可用"，不补造。
11. **顶栏七项**：目标交易日、模型版本、投影、完整度、分析截止、运行、页面生成；时间一律北京时间，不照抄 Artifact 的 UTC。
12. **段头**：沿用 Artifact 的副标题"正式阶段 · 三核心 · 确认度 · 一致性 · 库存 · 归因，一板看完"。
13. **推进方式**：作为本批次票 14 直接实施，不重开规格；规格第 102 行已覆盖内容项。验收标准：同一真实投影下 01 段截图与 Artifact ① 并排对照，由用户确认。
