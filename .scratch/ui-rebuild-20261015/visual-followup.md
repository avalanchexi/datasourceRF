- 真实运行总耗时 1733.02 秒、138 次请求。分布为背景指标 73、补缺 54、资讯 5、三核心 4、日历 2；按唯一请求 ID 计数，同一请求关联多个指标不会重复累加。重试的独立请求仍计入，缓存复用不计入。
- 未记录耗时显示“未记录”；真实零值显示 0.00 秒。新增反例先失败后通过，覆盖缺失耗时和共享请求去重。
- 390 CSS 像素下，看板、数据链路、运行页的文档可用宽度和滚动宽度均为 371，剩余为滚动条；没有整页水平溢出。宽表和目录可在自身区域滚动。900 和 1440 CSS 像素看板分别为 881/881、1421/1421。
- 内置浏览器有缩放，工具的视口参数不等于 CSS 像素；上述值以 `innerWidth`、`clientWidth`、`scrollWidth` 实测。测试结束已重置视口。
