## 按现行规则修正的样例差异

1. **候选方向**：样例把“30 日候选”写成“牛市／熊市 · 0 天”。现行决定区分即时 `candidate_30d` 和趋势切换 `candidate_state`／`candidate_days`；实施必须拆开，门槛取投影规则。
2. **120 日收益**：样例首段债／股／商为 `+2.04% / -6.18% / +1.71%`，第二段及价格一致性为 `+2.08% / -6.79% / +1.98%`。这是页面中直接可见的差异，不据此推断浏览器源码算法；正式版统一使用相隔 120 个交易日的端点，图上 120 个展示点不替代 121 点比较跨度。
3. **历史状态**：样例说明“首次初始化历史不足”，并固定描述 106 天待处理、14 天非典型。按 ADR-0040 读取当前历史和更正版本，不把旧样本的缺口写成持续有效规则。
4. **非典型解读**：样例只复述三核心及阶段为空，多个段落重复相同解释。采用已实现的新报告契约：完整列出全部差一项对照，标明 AI 或确定性模板；首段和历史段以摘要／链接通向末段，不复制多份全文。
5. **获取与缺失**：链路页自己标明筛选是静态示意、归因是手工对照验收记录。正式版读取实际执行原因，区分未发布、来源未交付、拒收、失败、跳过、终止和原因未记录；不复制这些指标名对应的旧原因。
6. **降级链**：页面文案将 Tavily、Exa 连写为顺序层级。现行规则是 Tavily 月度限额耗尽后由 Exa 顶替；呈现真实条件路径。主流向按请求数，降级链按实际缺口路径，声明／候选／缺期另列单位。
7. **SOX 与目录状态**：样例仍显示 SOX 受限授权且未检索，ADR-0042 已规定当前项目条件下的注册取数方式。正式版读取所选投影／运行对应的真实状态；不改写旧投影，也不固定复制旧样例的授权标签与缺口数量。
8. **身份、时区和计数**：参考页标 UTC，且样本日期、指标数、请求数、缺期数固定在该版本。生产页以真实包络和运行身份驱动，默认北京时间；确认度仍是计数、非概率，无正式阶段时不适用。
