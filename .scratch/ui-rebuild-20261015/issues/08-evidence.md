# 08: 完整证据追溯

**What to build:** 用户从数值或指标检索逐层追到实际公式输入、来源声明、获取回执和留存原件。

**Blocked by:** 01：单个核心指标贯通

**Status:** ready-for-human

- [x] 检索包含指标、维度、统计期与投影/截止上下文；选中、其他来源、冲突、修订和同定义跨目录归并可辨。
- [x] 派生树按实际输入版本递归按需展开；重复节点可引用，异常环及缺失父节点明确显示，不重选最新值。

- [x] 深链刷新、前进后退与返回保留原投影及筛选；通过真实 HTTP、浏览器和切片验证。
