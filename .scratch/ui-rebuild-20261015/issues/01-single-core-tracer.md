**What to build:** 用户在方案的身份栏、目录与结论板中查看债券核心的冻结事实，沿图点进入对应证据后返回原位置。

**Blocked by:** None (can start immediately)

**Status:** done

- [x] 单日汇总生成债券核心最近 120 个交易日价格、可得 MA120、5/120 日变化、单位、两端日期和观测/选中版本引用；不按窗口首点回退、不虚构缺日或沿用价格。
