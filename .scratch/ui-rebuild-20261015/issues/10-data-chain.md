# 10: 取数流向与缺期诊断

**What to build:** 用户沿取数流向、降级链、未完成期和时效定位数据问题，首页同时显示两种完整度口径。

**Blocked by:** 01：单个核心指标贯通；09：运行健康摘要

**Status:** ready-for-human

- [x] Worker 最终计划逐指标/维度/统计期记录未发布、已持有/采用、未交付、拒收、请求失败、门禁跳过、预算/流程终止或原因未记录。
- [x] 数据链路按运行筛选/关键数、取数流向、降级链、未完成期、证据追溯、候选校验与时效组织；所选运行与分析投影身份分开。
- [x] 主桑基图按请求数唯一归属且守恒；重试算不同请求，缓存和未发请求缺期不算外部请求；声明/候选/缺期明确单位。
- [x] 降级链展示实际层级、跳过/停止原因及渠道结果，Exa 为 Tavily 月限额备用；如用缺口流图，按唯一缺口及真实路径计数。
- [x] 来源/环节/结果/指标筛选真实联动图表和明细，计数由读模型提供，清空与无匹配可用。
- [x] 首页和链路分别显示仅模型用到/目录全部真正缺失及等待发布等状态；零失败不表示完整，不按指标名手写归因。
- [x] 用一请求多声明、零行、未请求、拒收、取消、条件降级等反例验证 Worker/HTTP/浏览器，并完成切片验证。
