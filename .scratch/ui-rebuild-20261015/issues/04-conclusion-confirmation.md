# 04: 周期结论与宏观确认

**What to build:** 用户从集中结论板进入五维指标表，理解正式阶段、无阶段原因及每条宏观事实的确认关系。

**Blocked by:** 01：单个核心指标贯通

**Status:** ready-for-human

- [x] 结论板包含阶段/原因、上一确认阶段、转折观察、核心沿用、五维摘要、价格一致性、库存、债券归因和数据边界入口，读取既有冻结结果。
- [x] 覆盖典型、两类非典型、核心不足/冲突、待定方向与首次空库；上一确认阶段不顶替当前阶段。
- [x] Worker 汇总现有关键指标关系；支持/反证/仅观察/未确认可逐项核对，五维只分组，库存只计一项，派生与同源价格不重复计数。
- [x] 宏观表展示时序、最新值/期、模型实际读取期、水平/动量/斜率、主辅一致或分化、缺什么、支持命题、成熟度与宽限；读取期不伪造日频。
- [x] 无正式阶段时确认度不适用且事实仍可读；未知不作中性/支持，不引入支持率、概率或评分。
- [x] 通过单日汇总、HTTP/页面行为及切片冒烟；表内展开和主题/窄屏可用。
