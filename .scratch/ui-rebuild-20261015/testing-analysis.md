# 前端重构：测试边界分析（2026-10-15）

用户要求先分析测试边界，再写入规格。本文件记录分析结论，不表示已经执行这些测试，也不把用户的“需要分析一下”记作批准。

## 结论

以“已发布投影与运行读模型 → 用户看到的页面/API”为主要验收边界。新增投影事实通过已有单日汇总入口验证，运行生命周期通过少量完整 Worker 用例验证；浏览器负责真实交互与布局。复用已有入口，不为每个计算函数或组件新开测试入口。

不能把所有用例都做成“完整 Worker → 浏览器”：这样把来源替身、运行历史、报告适配器、Web 启动和页面交互绑在一起，失败难定位，且重复支付整轮获取与补算成本。也不能只给页面塞手写 JSON：它证明不了页面展示的字段确实由 Worker 按冻结口径生成。采用分工后，保留少量贯通两端的冒烟，证明各段确实接上。

## 核对出的具体风险

| 风险 | 代码事实 | 应如何验证 |
|---|---|---|
| 图表与结论不是同一批数据 | 原型 `extract3.py` 直接选来源声明，按可用时间覆盖每期，未通过投影冻结的选值链 | 准备截止点前后两份修订，通过单日汇总发布，再检查图点、最新值、证据引用；旧投影不能读到后来修订 |
| “120 日”名同实异 | 原型 `build_proto.py` 用窗口第一点作基线；正式价格内部一致性使用 121 个交易日端点算 120 日收益 | 用明确端点与可手算数据检查 5/120 日变化；不足点数、缺交易日、核心沿用均不能退用任意首点 |
| 页面显示正确，HTTP 实际不可用 | 现有投影 API 测试直接调用路由函数；深链测试只比较 endpoint 对象 | 在应用 HTTP 边界验证状态码、参数、Host/Origin 与深链；浏览器实际打开并刷新深链 |
| 原型只覆盖非典型组合 | 原型部分“确认度不适用”文案固定写在模板中 | 用典型、两类非典型、核心待处理和首次空库四类状态检查文案与空值，不能只回归 10-14 样本 |
| 图表统计看似合理但单位混淆 | 一次请求可产生多条声明，缺期也可能没有请求 | Worker 摘要按请求唯一归属，节点守恒；声明、候选、缺期另列单位；验证未发请求的缺期不变成失败请求 |
| 原件已过期被误说成数据缺失 | 仓库已有过期异常，HTTP 目前仅暴露异常类名 | 验证原件可用、留存过期、未留存、校验失败各自响应和页面解释，不能归为同一“无数据” |

代码位置与现有测试见文末。以上为只读核对，未访问正式运行库。

## 复用三个已有边界

| 边界 | 负责验证 | 不在此重复验证 |
|---|---|---|
| 单日汇总 → 已发布分析投影 | 新走势点列、比较端点与单位、MA120、冻结选值、时间边界、确认度汇总字段、历史字段兼容 | 不穷举报告 CLI、Web 路由、运行恢复；已有模型规则用例保持原归属 |
| 完整运行公开入口 → 投影与运行读模型 | 健康摘要落盘、逐期未完成原因、原子发布、报告绑定、取消/失败/恢复、留存 | 不为每个指标、每个颜色、每个筛选组合跑完整获取与补算 |
| Web 应用公开 HTTP/页面 → 用户可见结果 | 七段内容、状态标签、同投影身份、筛选、证据树、原件错误语义、旧链接、命令与访问配置 | 不在页面测试重新实现趋势和阶段算法 |

浏览器是在第三个边界上的验收方式，不另建业务计算入口。沿用少量有价值的页面渲染测试做快速反馈；改写绑定旧八页导航的断言，保留其保护的业务行为。新增测试不依赖组件嵌套层数、CSS 字符串或内部私有函数名。

## 测试预期值必须独立

- 数值预期用小型可手算数据和明确日期、单位、选中声明构造，不能调用生产中的同一计算函数生成 expected。
- 修订与冲突场景故意提供多个合法候选，以及截止点之后更“新”的值，验证不能按最后入库者取值。
- 端点一致性不仅比较页面字符串，还比较序列、期次、来源引用与包络；典型反例是当前指针在两次请求间切换。
- 非典型场景核对“当前阶段为空”“确认度不适用”“全部差一项对照”，以及 AI/确定性模板的来源标记。测试适配器输出为离线替身；不依赖真实 AI 随机生成固定正文。
- 自动回归用合成数据是为了构造边界，不违背生产页面与最终视觉验收使用真实数据的要求。真实投影截图不能替代上述反例。

## 少量贯通用例与浏览器验收

1. 一个正常发布场景：离线 Worker 产生完整投影和健康摘要，HTTP 读取身份，浏览器打开首页、跳入证据、返回原位置。
2. 一个非典型且 AI 失败场景：新投影生成确定性模板；首页与报告均匹配同一投影，不能把旧报告拼进来。复用已有非典型运行冒烟，避免重复构建整轮数据。
3. 一个运行异常场景：未成功发布新投影时保留上次完整分析，运行状态明确显示失败/取消及下一步；不把上次分析误标为本次成功。

浏览器用上述少量准备好的数据覆盖桌面/窄屏、明/暗主题、键盘焦点与返回、真实筛选、图表悬停、原件打开、深链刷新。截图辅助核对密度与层级，不做随数据变化大面积失效的像素快照门禁。

最终关口 C 还需本机以新代码、新投影显示真实数据，用户逐段验收。数据质量体检继续验证取数和模型结论；它与 UI 回归互补，不能以页面正常替代体检，也不能以测试证明模型能预测市场。

## 执行成本与时点

### Claude 方案采纳后的补充检查（2026-10-15）

以下来自本轮已读取的方案页面，完整观察与限制见[方案核对记录](visual-reference.md)。它们细化现有三个测试边界，不新增测试接缝：

- 同一核心在首段表格／小图、资产段图注和价格一致性中的同口径收益、序列与证据身份一致；用独立可手算端点验证，不能只检查三个错误值恰好相等。
- 30 日即时方向不携带趋势候选天数；趋势候选和模型门槛另列。覆盖方向相同、不同及无候选，避免复制样例的“30 日候选 · 0 天”。
- 宏观“模型读到的期”对应实际冻结输入，区别于最新值统计期；低频单期和多期分别显示，不伪造日频点列。
- 阶段及三核心四条状态带共享日期轴，缺日保留位置，同截止更正按被替代关系取值；类别天数与所示窗口一致。
- 数据链路中请求、声明、候选与检索缺口的单位分开；额外覆盖 Tavily 正常与月度限额耗尽后的 Exa 替代路径，不以固定线性通道顺序冒充实际调用。
- 当前与历史样本分别验证来源和授权状态；不把参考页中 SOX 的旧标签或示例缺口数写死到新页面。
- 浏览器验收逐项核对集中结论板、紧凑表列、段内图、章节展开及真实筛选。配色、字号、间距、窄屏、暗色和运行页尚未在参考页完成实测，应在实施时对照，不记为本轮已通过。

### 既定执行规则

遵循 ADR-0025、ADR-0034 与项目测试说明：实施时按变更选择具体受影响文件/节点；每个切片跑既定两例冒烟；触及 Worker 编排再补完整目录正例与三核心沿用/阻断反例。只在终点真实完整运行前跑一次全套，遵守时钟、锁和磁盘检查。普通回归离线、每例独立可变库，不用正式运行库作为测试夹具。

本轮只产出规格，不运行软件回归或正式 Worker。不存在“前端已测试通过”的结论。
