# 02: 降准：资讯监测、现行基准与追溯发现

**What to build:**
1. 登记降准资讯规则（`news_rules.py`，家族 `pbc_rrr_notice`）：句中须写明生效日期；必取按适用范围的调整幅度（下调记负、上调记正），按生效日记期；句中出现时顺带取调整后加权平均准备金率与释放资金。口径与 `official_context._parse_rrr_notice` 一致。
2. 每轮完整运行在本轮资讯里监测降准：命中即记新事件；未命中记“本轮资讯未见降准公告”，沿用现行基准，不算缺失，不再走官网、Tavily、AI。
3. 现行基准：`CN_RRR_EVENT` 生效至变更，去掉 730 天有效期（`metric_contracts.evidence_max_age_days`）。
4. 追溯发现：从未持有时，以央行官网降准公告栏目为主（补 `official_listing` 列表识别），从目标月起往回翻，找到第一条即停，不设上限；官网取数失败时以 AI WebSearch 兜底（问截至目标日最近一次降准，候选须命中降准规则并带原话）。不用 Tavily，也不用 TuShare 资讯回拉。查完没有记“查过、没有”；来源出错或没查完才列检索未通过。
