# 06: 官网 403 只拦同一 URL

**What to build:** 官方渠道遇到 403（`forbidden_unknown`，未知原因的拒绝）时，负缓存只拦同一 URL，不再按整个主机拦到次日；401、402、429、432、433 这类明确的认证、限额错误仍按主机拦（2026-09-25 用户选择 Q12=A）。起因：9/24 一次央行栏目页 nginx 403，使下一轮央行全部官网页（社融、货币、贷款、OMO 公告）被拦（见票 13 遗留④）。
