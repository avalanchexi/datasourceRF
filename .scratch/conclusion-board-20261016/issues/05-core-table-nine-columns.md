# 05: 三核心表九列与候选两行

**What to build:** 01 段的三核心表收成九列：三核心、状态、最新、距 MA120、20 日斜率、候选、近 5 日、近 120 日、120 日走势。状态是带颜色的牛市 / 熊市标签；最新值仍可点进固定版本证据；候选一列两行分别写"30 日候选方向 {牛市/熊市/无}"与"资产候选状态 无"或"{牛市/熊市} · 持续 N 日 / 门槛 M 日"。读者不会把即时方向误读成持续天数。

**Blocked by:** 01：用词统一

**Status:** done

- [x] 表为九列，列名与顺序如上；状态列用牛市 / 熊市颜色标签；最新列含日期并链到固定版本证据（链接含投影号与版本）。
- [x] 候选列两行用词汇表术语；门槛取投影资产文档的持续门槛，缺失写"未提供"；不合并成"牛市 · 0 天"。
- [x] 列标题里的均线窗口与斜率窗口数字来自投影冻结模型版本的趋势规则参数（自行读取同一参数，不依赖票 03）；读不到时列名退为"距均线""斜率"。
- [x] 反例：30 日候选方向与资产候选状态相同、不同、无候选三例；门槛缺失一例；旧投影无展示点列时表仍可读。
- [x] 表在自身容器内横向滚动，390 像素下整页不横向溢出。
- [x] 受影响的 Web 切片与两项必跑冒烟通过；修改范围 ruff、mypy 通过。
- [x] 规格：[spec.md](../spec.md) 实现决定"三核心表九列"。
