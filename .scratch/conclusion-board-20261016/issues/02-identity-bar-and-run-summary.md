## Comments

### 2026-10-16 实施

**改了什么**

- `run_health.ProducerRun(run_id, summary)`：产出本投影的完整运行及其持久化健康摘要（`RunHealth.latest`；运行未结束或旧运行无摘要时 `summary=None`，不调用 `observe` 补算）。
- `web._producer_run`：沿用前端重建批次的关联方式并抽成一处，首页与数据链路 / 运行页共用。先按投影的 `batch_id`（含补算日）找，再回退到运行自身关联的投影；只认 `manual_full` / `scheduled_full`，找不到返回空，不拿其他运行顶替。
- 渲染入口：`dashboard_page(..., producer_run=...)` → `report_board(..., producer_run=...)`，均为关键字参数，默认 `None`。本票只传入、不渲染，留给票 06 做板底运行事实行。
- 顶栏 `cockpit.identity_strip(projection, *, producer, rendered_at)` 输出七项：目标交易日、模型版本、投影、完整度（完整 / 降级）、分析截止（北京时间）、运行（产出运行号，无则"未提供"）、页面生成（渲染时刻，北京时间）。空库时七个标签照常显示，值写"尚无 / 等待首次完整运行 / 未提供"。原顶栏折叠块里的证据快照、证据窗口、分析生成时间不再放在顶栏。
- 刷新：视图指纹加入产出运行及其摘要，摘要晚于首屏落盘时首页会重绘；指纹未变时顶栏也返回 `no_update`，因此"页面生成"始终是该页实际渲染的时刻。
- 样式：`report.css` 中七项自适应排布，长标识换行而不截断；560px 以下排成两列。
