# 结论板对齐 Claude 方案：周期识别正确展示（2026-10-16）

Status: ready-for-agent

来源：[访谈决定](decisions.md)（13 项，用户全部确认）；参考方案为 Claude Artifact "周期驾驶舱原型 v2"（`https://claude.ai/artifact/6smcdW6qb81iyN3Syz7j4s`）的 ① 段与顶栏。前置批次 [前端重建](../ui-rebuild-20261015/spec.md) 的规格与 [测试边界](../ui-rebuild-20261015/testing-analysis.md) 继续有效，本规格只覆盖其 01 段与顶栏。

## Problem Statement

用户打开驾驶舱首页，想在第一屏就确认系统对 Pring 周期的识别是否正确。现在 01 段"周期识别结论"虽然内容项齐全，但识别结论的表达不够直接：

- 无正式阶段时只写"当前三资产组合不属于六个规范阶段"，没有写出债、股、商各自的状态，读者要翻到下方表格自己拼出组合，才能核对"为什么没有阶段"。
- 用词与词汇表不一致：界面写"偏多 / 偏空"，词汇表定义核心资产状态是稳定的牛市或熊市；标题"当前阶段暂不判定"暗示系统还没判，实际是判了、结果为空。
- 旁证（价格一致性、库存象限、债券归因、数据边界）散落在折叠块和段落里，不能与结论一眼对照。
- 三核心表十列，候选相关的两列标签不是词汇表术语，占位宽而读法不清。
- 板底没有 AI 解读首句和运行事实行，顶栏缺模型版本、完整度、运行与页面生成时间，读者不知道这份结论基于哪个模型、哪次运行、完整度如何。

## Solution

把 01 段改成 Claude 方案那样的一张结论板，顶栏补齐身份字段，让"识别出什么、依据什么、旁证如何、基于哪次运行"在一屏内读完：

- 左栏：大标题（正式阶段或"暂无正式阶段"），其下五行标签 / 值：原因（写明三资产组合与规则结论）、上次确认（含回溯说明）、转折观察、核心沿用、判法（从冻结模型规则生成）。
- 右栏：确认度标题（可评估 / 不适用、关键指标项数、规则版本）、五维小格（每格 N 项与支 / 反 / 观 / 未计数），其下四行内联：价格一致性、库存象限、债券归因、数据边界。
- 下接三核心表九列，候选一列两行用词汇表术语分别写 30 日候选方向与资产候选状态。
- 板底两行事实：AI 解读（按报告状态四分）与运行事实（目标交易日、模型版本、外部请求与失败数、检索预算用量、耗时）。
- 顶栏七项：目标交易日、模型版本、投影、完整度、分析截止、运行、页面生成，一律北京时间。
- 状态用词全站统一为牛市 / 熊市。

语义与计算不变：正式阶段、上一确认阶段、确认度、候选仍由 Worker 按冻结口径产出，页面只读投影与运行读模型。

## User Stories

1. 作为驾驶舱读者，我想在 01 段大标题下直接看到"非典型组合：债券牛市 · 股票熊市 · 商品牛市，不在六个典型组合内；不创建 Stage VII/VIII"，以便不翻表格就能核对无阶段的原因。
2. 作为驾驶舱读者，我想在有正式阶段时看到"典型组合：债券牛市 · 股票牛市 · 商品熊市 → Stage II"，以便核对阶段映射是否与三资产状态一致。
3. 作为驾驶舱读者，我想在核心数据待处理、核心状态不可用或 P0 未过门禁时也看到三资产逐项说明（可用的写状态，受阻的写阻因与沿用期），以便知道是哪一个核心把阶段卡住了。
4. 作为驾驶舱读者，我想在当前阶段为空时看到标题"暂无正式阶段"而不是"暂不判定"，以便明白这是判定结果为空，不是系统尚未判定。
5. 作为驾驶舱读者，我想全站看到"牛市 / 熊市"而不是"偏多 / 偏空"，以便与词汇表、报告与 ADR 的说法对上。
6. 作为驾驶舱读者，我想在"上次确认"一行看到上一确认阶段及其回溯说明（回溯得出时的日期，或回溯范围内无正式阶段），以便知道这个历史上下文从哪来。
7. 作为驾驶舱读者，我想在"转折观察"一行看到各资产候选方向，没有时明确写"无"及原因（30 日候选均与当前状态同向），以便知道是没有候选而不是没有数据。
8. 作为驾驶舱读者，我想在"核心沿用"一行看到被沿用的核心及沿用期，没有时写"无"，以便判断本次结论是否建立在旧价格上。
9. 作为驾驶舱读者，我想在"判法"一行读到本投影所冻结模型版本的趋势规则参数（均线窗口、斜率窗口、噪声带倍数与波动窗口、持续门槛、候选窗口）和模型版本号，以便理解表里"距均线为正却仍是熊市"之类的读数。
10. 作为驾驶舱读者，我想右栏确认度标题写明"可评估 / 不适用"、关键指标项数与规则版本，以便知道计数的范围与口径。
11. 作为驾驶舱读者，我想五维小格每格写"N 项"与支持 / 反证 / 仅观察 / 未确认计数，非典型时写"不适用"，以便一眼看出各维度有多少关键指标以及它们的确认关系。
12. 作为驾驶舱读者，我想"价格一致性"一行内联写相对动量、股市广度与商品篮子广度的摘要，以便不展开折叠块就能对照。
13. 作为驾驶舱读者，我想"库存象限"一行写象限、统计期与三线读法（或未分类原因），以便与 ⑤ 段对照。
14. 作为驾驶舱读者，我想"债券归因"一行写推动力结论与各轴读法，并标明"附注，不计数"，以便知道它不进确认度。
15. 作为驾驶舱读者，我想"数据边界"一行写缺口项数与历史期未取到数，并能点到 ⑦ 段与数据链路，以便评估结论的数据基础。
16. 作为驾驶舱读者，我想三核心表收成九列（三核心、状态、最新、距 MA120、20 日斜率、候选、近 5 日、近 120 日、120 日走势），以便在一行内读完一个核心。
17. 作为驾驶舱读者，我想"候选"一列分两行写"30 日候选方向 牛市"与"资产候选状态 无"或"熊市 · 持续 3 日 / 门槛 8 日"，以便不把即时方向误读成持续天数。
18. 作为驾驶舱读者，我想三核心表的状态用带颜色的标签区分牛市与熊市，以便快速扫读。
19. 作为驾驶舱读者，我想三核心表的最新值仍能点进固定版本的证据，以便从结论追到原件。
20. 作为驾驶舱读者，我想板底第一行看到 AI 解读首句与"全文"链接，以便决定是否读全文。
21. 作为驾驶舱读者，我想报告为确定性模板时板底写"本次报告为确定性模板，无 AI 解读"并注明适配器失败原因，以便不把模板当成 AI 输出。
22. 作为驾驶舱读者，我想报告生成中时板底写"报告生成中"，以便知道稍后会有解读。
23. 作为驾驶舱读者，我想无报告时板底写"报告尚未生成"并链到 ⑦ 段的生成按钮，以便直接发起生成。
24. 作为驾驶舱读者，我想板底第二行看到目标交易日、模型版本、外部请求数与失败数、检索预算用量、耗时，以便知道这份结论花了多少取数成本。
25. 作为驾驶舱读者，我想旧运行没有持久化摘要时板底写"口径不可用"而不是 0，以便不被编造的数字误导。
26. 作为驾驶舱读者，我想顶栏看到目标交易日、模型版本、投影、完整度、分析截止、运行、页面生成七项，以便确认这份结论的身份。
27. 作为驾驶舱读者，我想顶栏与板底所有时间都是北京时间并标明，以便与运行页一致。
28. 作为驾驶舱读者，我想 01 段段头有副标题"正式阶段 · 三核心 · 确认度 · 一致性 · 库存 · 归因，一板看完"，以便知道这一板包含什么。
29. 作为驾驶舱读者，我想切换到历史投影时结论板全部字段随所选投影变化、不混入当前指针的内容，以便核对历史结论。
30. 作为驾驶舱读者，我想首次空库时结论板仍可读（"等待首次完整运行"），不出现编造的价格或阶段，以便知道系统状态。
31. 作为驾驶舱读者，我想结论板在窄屏下左右两栏上下堆叠、表格自行横向滚动、整页不横向溢出，以便在手机上阅读。
32. 作为驾驶舱读者，我想明暗主题下结论板的状态颜色与现有配色一致，以便切换主题不丢信息。
33. 作为驾驶舱读者，我想旧书签与 `#conclusion` 锚点仍定位到 01 段，以便已有链接不失效。
34. 作为验收者，我想用同一真实投影截图与 Claude 方案 ① 段并排对照，以便逐项确认布局与内容。
35. 作为维护者，我想状态用词、阶段标题文案只在一处映射里维护，以便看板、阶段史页、报告页一起变。
36. 作为维护者，我想判法行的参数来自冻结模型规则而不是写死的句子，以便模型换版本时文案不漂。

## Implementation Decisions

- **范围**：只改 01 段"周期识别结论"与顶栏身份区，以及全站共用的状态 / 阶段文案映射。②～⑦ 段布局差异另开批次。
- **语义不变**：正式阶段、上一确认阶段、确认度、候选、缺口的值与计算全部沿用投影读模型；页面不重算趋势、不重算阶段映射、不插值。
- **状态用词映射**：核心资产状态、30 日候选方向、资产候选状态的 bull / bear 显示为"牛市 / 熊市"；不可用仍为"不可用"。映射只在一处维护，看板、阶段史页、报告页共用。
- **阶段标题映射**：当前阶段为空时标题"暂无正式阶段"；有阶段时沿用"第 N 阶段 · Stage N"。同一映射供阶段史页与报告页使用。
- **原因行生成规则**：按投影的阶段原因分四类生成一句话。
  - 典型组合：`典型组合：债券{状态} · 股票{状态} · 商品{状态} → Stage N`。
  - 非典型组合：`非典型组合：债券{状态} · 股票{状态} · 商品{状态}，不在六个典型组合内；不创建 Stage VII/VIII`。
  - 核心数据待处理 / 核心状态不可用 / P0 未过门禁：`{原因标签}：` 后逐资产列出，可用的写状态；受阻的写阻因与沿用期，阻因取自核心沿用记录与缺口清单中该核心的条目（落后期数、沿用期）。
  - 其余未知原因：沿用现有"等待三类 P0 核心资产形成同一截止点的可用组合"。
- **左栏五行**：原因、上次确认（沿用现有回溯文案，ADR-0040）、转折观察（无候选时写"无（三核心 30 日候选均与当前状态同向）"）、核心沿用（无时写"无"）、判法。
- **判法行**：由投影所冻结模型版本的趋势规则参数生成：`MA{窗口} + {斜率窗口} 日斜率定稳定牛熊，噪声带 {倍数}×{波动窗口} 日波动，持续 {门槛} 日确认，{候选窗口} 日候选只作转折观察；宏观与库存只做事后确认，不改写阶段 · {模型版本}`。参数从模型仓库按投影的模型版本号读取；读不到时写"该模型版本未提供趋势规则参数"，不写默认值。页面渲染入口因此多接收一项"趋势规则参数"，由 Web 层从模型仓库取得，与 Worker 读取的是同一份清单。
- **右栏**：确认度标题从确认汇总读"可评估 / 不适用"、总项数与规则版本；五维小格每格写"N 项"及支持 / 反证 / 仅观察 / 未确认计数，非典型时每格加"不适用"。其下四行内联（价格一致性、库存象限、债券归因、数据边界）从已有价格内部一致性、库存、债券归因、缺口清单与覆盖汇总读摘要；现有折叠块移除，详情仍在 ②④⑤⑦ 段。数据边界行的"历史期未取到数"取覆盖汇总中最终计划口径的缺失期数；覆盖汇总不可用时写"该版本未提供"。
- **三核心表九列**：三核心（资产名加核心指标号）、状态（带颜色标签）、最新（可点进固定版本证据，含日期）、距 MA120、20 日斜率、候选、近 5 日、近 120 日、120 日走势小图。候选列两行：`30 日候选方向 {牛市/熊市/无}` 与 `资产候选状态 无` 或 `{牛市/熊市} · 持续 {N} 日 / 门槛 {M} 日`；门槛取投影资产文档里的持续门槛，没有时写"未提供"。列标题中的"距 MA120""20 日斜率"的数字同样来自趋势规则参数，不写死。
- **板底事实行**：
  - 第一行按报告状态四分：有 AI 解读取首段首句加"全文"链接到 ⑦ 段；适配器为确定性模板时写"本次报告为确定性模板，无 AI 解读"并附适配器失败原因；报告任务排队或运行中写"报告生成中"；无报告写"报告尚未生成"并链到 ⑦ 段生成按钮。报告必须与当前展示的投影同身份，同投影取最新版本。
  - 第二行取产出本投影的运行的持久化健康摘要：目标交易日、模型版本、外部请求数与失败数、检索预算用量、耗时（秒）。摘要缺失时相应项写"口径不可用"。页面渲染入口因此多接收一项"产出运行摘要"，由 Web 层按投影的批次关联实际生产运行读取（沿用前端重建批次已修正的关联方式），与运行页读的是同一份摘要。
- **顶栏七项**：目标交易日、模型版本、投影、完整度（显示"完整 / 降级"）、分析截止、运行（产出本投影的运行号）、页面生成（渲染时刻）；时间全部北京时间并标注。
- **段头副标题**：固定文案"正式阶段 · 三核心 · 确认度 · 一致性 · 库存 · 归因，一板看完"。
- **布局**：结论板为一张卡片，左右两栏在窄屏堆叠；表格在自身容器内横向滚动；复用现有主题变量与状态颜色，不新增配色。锚点与旧书签不变。
- **不回填**：旧投影缺字段（无回溯记录、无持续门槛、无健康摘要、无覆盖汇总）按"未提供 / 口径不可用"显示，不补造、不回填。

## Testing Decisions

- **什么是好测试**：只断言用户可见的文本、链接与顺序，不断言组件嵌套、CSS 类名或私有函数；预期值用小型可手算数据与明确日期构造，不调用生产中的同一函数生成 expected。
- **唯一测试缝**：沿用前端重建批次的第三个边界"已发布投影与运行读模型 → 页面"，入口是首页渲染函数（投影、运行、报告、运行摘要、趋势规则参数 → 页面），以渲染后的文本与链接断言。不新开计算函数级入口。
- **投影构造**：两种已有方式都用。手写 `ProjectionSet` 构造典型组合、非典型组合、核心数据待处理、首次空库四类状态；用集成测试的运行时与单日汇总入口生成真实结构的投影，验证字段确实由 Worker 口径产出。
- **必覆盖的反例**：
  - 原因行四类文案各一例；核心数据待处理时阻因来自沿用记录而非编造。
  - 候选列：30 日方向与资产候选状态相同、不同、无候选三例；门槛缺失写"未提供"。
  - 判法行：两个不同趋势规则参数集渲染出不同数字；规则缺失写"该模型版本未提供趋势规则参数"。
  - 板底解读行四种报告状态各一例；报告身份不匹配当前投影时不显示旧报告。
  - 运行事实行：有摘要与无摘要各一例，无摘要写"口径不可用"。
  - 用词：页面不再出现"偏多 / 偏空 / 暂不判定 / 30 日即时方向 / 趋势切换候选"。
  - 历史投影固定后结论板字段不混入当前指针（沿用现有固定投影 HTTP 用例）。
- **需改写的既有断言**：首页契约测试中对"当前阶段暂不判定""偏多""30 日即时方向"的断言改为新用词，保留其保护的业务行为（阶段为空、状态来自投影、候选两概念分列）。
- **先例**：看板测试（七段顺序与证据链接）、首页契约测试（投影状态渲染为领域文案而非原始 JSON）、HTTP 测试（固定投影不混入当前指针、报告命令钉住投影）。
- **浏览器验收**：用隔离副本上的真实投影打开首页，截图与 Claude 方案 ① 段并排对照，覆盖明暗主题与 390 像素窄屏；由用户确认，自动检查不代填。
