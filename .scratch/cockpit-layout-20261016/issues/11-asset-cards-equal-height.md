# 11: ② 三张资产卡等高对齐

**What to build:** 用户验收（2026-10-17）："02 3 个容器高度应当一致和谐"。现状（`screenshots/1015-home-assets-light-1440.jpg`）：债券卡同类观察只有 2 行，卡高约 380px；股票、商品卡同类观察限高 320px，卡高约 600px，三卡底边参差。改为宽屏（≥1000px）三卡等高、内部各段横向对齐：

- 三卡同高，底边齐平；卡内各段（卡头、指标两行、30 日候选与资产候选、近 5 日/近 120 日、"逐日数值与证据"按钮、小图、同类观察）在三卡间横向对齐。推荐 CSS `grid-template-rows: subgrid`，不支持时退为 flex 列＋`align-items: stretch`。
- 同类观察区三卡一律固定高 320px（行少时留白在框内，行多时框内滚动），不再随行数伸缩。
- 名称过长的行（如"纺织（棉花与 PTA 合计）"）单行省略、悬停全称，不把行撑高。
- 三卡下方：价格内部一致性卡与债券归因并排两列、等高（债券归因改为同风格卡片，去英文小标题，正文保留核心一行，其余进抽屉）；<1000px 时堆叠。
- 窄屏（<1000px）三卡堆叠，不强制等高。
