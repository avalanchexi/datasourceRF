# 01: 右侧抽屉与 ③ 海外卡片

**What to build:** 读者在 ③ 海外与汇率段看到卡片网格（宽屏每行 4 张），每张只写名称、最新值与单位、统计期、方向箭头、近 5 日；点卡片在右侧抽屉看该指标全部字段。本票同时交付全站共用的右侧抽屉骨架，后续各段复用。见 [规格](../spec.md) 用户故事 3–11、38–43，实现决定"抽屉""③ 分组"。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 全站一个右侧抽屉：宽 min(520px, 40vw)，<760px 全屏覆盖；Esc 与遮罩关闭；打开时 URL 带可分享锚点、浏览器后退关闭；一次只开一个，新触发器替换内容；明暗主题配色一致
