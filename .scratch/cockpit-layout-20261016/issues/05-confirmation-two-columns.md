# 05: ④ 两列维度卡与非典型读法

**What to build:** 读者在 ④ 段宽屏看到五张维度卡每行两张；每卡头写维度名与计数，卡内每个关键指标一行。非典型组合时每行改写该指标主成员自身读法（最新值与单位、读取期、方向）并标"不计数"；详情在抽屉，GDP 抽屉含原本混在 ③ 的分产业细项。见 [规格](../spec.md) 用户故事 44–51，实现决定"非典型组合读法"。

**Blocked by:** 01, 02

**Status:** ready-for-agent

- [ ] 五维度卡宽屏每行两张、窄屏单列；卡头维度名与支持 / 反证 / 仅观察 / 未确认计数（全称）
- [ ] 有正式阶段：每行指标名、确认关系、读取期
- [ ] 非典型：每行主成员 `value / period / direction`（缺失读 `latest_source`）加"不计数"标签，不显示确认关系；抽屉写"非典型组合不判定命题与成熟度"
