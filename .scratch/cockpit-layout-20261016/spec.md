# 驾驶舱布局精简：核心常显、明细限量、详情进抽屉（2026-10-16）

Status: ready-for-agent

来源：[访谈决定](decisions.md)（四轮 24 项，用户全部确认）；事实依据为 Codex 只读调查（名称来源与重名、`international_context` 分组口径、非典型结构化字段、桑基取值全集），摘要已写入决定第三轮。前置批次 [结论板对齐](../conclusion-board-20261016/spec.md) 与 [前端重建](../ui-rebuild-20261015/spec.md) 的规格、[测试边界](../ui-rebuild-20261015/testing-analysis.md) 继续有效；本规格覆盖首页七段的信息分层与布局、全站显示名、非典型组合的展示读法与数据链路页桑基图。

## Problem Statement

用户在驾驶舱首页想快速读懂周期结论与依据，现在却很难：

- 首页 1440 宽下总高约 22,500 像素：② 段三资产上下排列、同类观察表全量铺开约 5,000 像素；⑥ 段逐日列出一百多条更正事件约 8,000 像素；⑤ 段同一批库存成员重复出现三次；⑦ 段缺口清单出现两次，报告身份字段整列铺开。
- 详情（逐日数值与证据、主辅成员、走势与比较端点）在页面原地展开，打开后把后续内容推得更远。
- 指标大多只显示英文代号（`UST10Y_NOMINAL_YIELD`、`CN_GDP`），同类观察里多行同名（"市场广度：涨跌家数"5 行、"估值"9 行、"商品篮子分项贡献"7 行），"融资买入额"被标成"融资余额"，用户无法辨认。
- ③ 段"海外与汇率"混入国内 GDP 8 行与中债 030，且以十几列宽表呈现。
- 当前三核心为非典型组合（债券牛市 · 股票熊市 · 商品牛市），正式阶段为空、确认度不适用；④ 段 17 行全写"不适用"，结论板五小格也全是"不适用"，用户读到的是"系统没给结论"，而不是"组合非典型、离哪几个典型阶段只差一项、各指标自身读法如何"。
- 转折观察把"30 日候选方向无"也列入，读起来像有转折信号。
- 数据链路页桑基图连线浅灰几乎不可见，节点同色，标签带"来源:""结果:"前缀与原始码（`official`、`candidate_source`）。

## Solution

按"核心信息常显、明细选择性展示、更多详情进右侧抽屉"三层重排首页，并统一中文名为主：

- 全站一个右侧抽屉，页面内所有原地展开改为打开抽屉。
- ① 只留结论板；非典型时写出"只差一项"的三个典型阶段，五小格收成一行。
- ② 三核心卡宽屏三列并排，卡头承接原三核心表，同类观察限高滚动。
- ③ 只留海外与汇率，以卡片网格呈现。
- ④ 五维度卡每行两张；非典型时每行写指标自身读法并标"不计数"。
- ⑤ 象限卡加三条线小卡，成员只出现一次，仓单进抽屉。
- ⑥ 色带加区间列表；⑦ 只留完整度、缺口前 5 条与解读摘要。
- 所有资产与指标中文名为主、代号为辅；桑基图分色、中文化、带计数。

语义与计算不变：正式阶段、上一确认阶段、确认度、候选、非典型比较、缺口全部由 Worker 按冻结口径产出，页面只读投影与运行读模型。

## User Stories

### 全局：抽屉与信息分层

1. 作为驾驶舱读者，我想页面只常显每段的核心信息，以便一屏内看懂结论而不被明细淹没。
2. 作为驾驶舱读者，我想明细以限高滚动或"前 N 条 + 查看全部"呈现，以便需要时就近浏览、不需要时不占篇幅。
3. 作为驾驶舱读者，我想点任何"详情"都在右侧抽屉打开，而不是原地展开，以便阅读位置不跳动。
4. 作为驾驶舱读者，我想抽屉宽度不超过 520 像素且不超过视口 40%，以便抽屉打开时仍能看到主页面。
5. 作为手机读者，我想屏宽小于 760 像素时抽屉全屏覆盖，以便详情可读。
6. 作为驾驶舱读者，我想按 Esc 或点遮罩关闭抽屉，以便快速返回。
7. 作为驾驶舱读者，我想打开抽屉时地址栏带上可分享的锚点、浏览器后退能关闭抽屉，以便把某条详情发给别人或用后退返回。
8. 作为驾驶舱读者，我想抽屉标题同时写中文名与代号，以便确认是哪条序列。
9. 作为驾驶舱读者，我想一次只开一个抽屉，打开新的详情时替换旧内容，以便不堆叠。
10. 作为驾驶舱读者，我想抽屉在明暗主题下都与页面配色一致，以便切换主题不丢信息。
11. 作为驾驶舱读者，我想固定历史投影时抽屉内容也来自所选投影，以便不混入当前指针。

### 全局：中文名为主

12. 作为驾驶舱读者，我想所有资产与指标第一行写中文名、第二行用小号灰色写代号，以便一眼认出又能精确核对。
13. 作为驾驶舱读者，我想在桑基节点、表格单元、色带标签这类紧凑位置只看中文名、悬停看代号，以便不挤。
14. 作为驾驶舱读者，我想同一指标的不同成员各有能区分的中文名（如"上涨家数""下跌家数""沪深 300 市净率""铜"），以便不再看到多行同名。
15. 作为驾驶舱读者，我想"融资买入额"不再被标成"融资余额"，以便不误读。
16. 作为驾驶舱读者，我想缺中文名的指标仍显示代号，并在抽屉里注明"未提供中文名"，以便知道是缺映射而不是页面编造。
17. 作为维护者，我想显示名只在一处维护，首页、数据链路页、桑基图共用，以便改一处全站生效。

### ① 周期识别结论

18. 作为驾驶舱读者，我想 ① 段只保留结论板（左栏、右栏、板底两行），三核心表移到 ②，以便结论一屏读完。

## Implementation Decisions

- **范围**：首页七段的信息分层与布局、全站显示名、数据链路页桑基图与请求表。运行状态页布局不动（只随显示名生效）。Worker、投影结构、模型规则不动。
- **信息三层**：每段按下表划分；"选择性展示"指限高滚动或前 N 条加"查看全部 →"打开抽屉。

  | 段 | 核心常显 | 明细选择性展示 | 右侧抽屉 |
  |---|---|---|---|
  | ① | 阶段标题、原因、只差一项（非典型时）、上次确认、确认度标题 | 转折观察、核心沿用、判法、四行旁证、板底两行 | 数据边界的缺口全文 |
  | ② | 三张资产卡卡头与 120 日小图 | 同类观察四列，限高约 320px | 同类观察每行全部字段；逐日数值与证据；噪声带说明；价格一致性明细 |
  | ③ | 卡片：名、值、期、方向、近 5 日 | — | 全部字段与来源 |
  | ④ | 维度卡头计数；每指标一行 | — | 主辅成员、派生、依据与缺口、命题与成熟度、GDP 分产业 |
  | ⑤ | 象限卡；三条线小卡 | 仓单一行摘要 | 辅指标、仓单分品种表、实际库存近似 |
  | ⑥ | 四条色带；天数汇总 | 区间列表 | 区间内逐日与更正版本；交易日等价表格 |
  | ⑦ | 完整度两行；解读摘要 | 缺口前 5 条 | 报告详情、全部缺口、发布日历 |

## Testing Decisions

- **好测试**：只断言用户可见的文本、链接与顺序，以及抽屉触发器与其抽屉内容；不断言组件嵌套、CSS 类名、样式或私有函数。预期值用小型可手算数据与明确日期构造，不调用生产中的同一函数生成 expected。
- **测试缝（用户确认）**：沿用两个既有渲染入口，不新开计算函数级入口。
  - 首页渲染入口（投影、运行、报告、运行摘要、趋势规则参数 → 页面）：七段顺序与锚点、各段核心常显内容、抽屉触发器及其内容、显示名、非典型读法、转折观察、区间列表、⑦ 缺口唯一。
  - 数据链路页渲染入口：桑基节点中文标签与计数、"其他（N）"合并、结果四色归类、未映射值、请求表指标显示名。
- **投影构造**：手写 `ProjectionSet` 构造典型组合、非典型组合（含 `noncanonical_basis`）、核心数据待处理、首次空库；用集成测试的运行时与单日汇总入口生成真实结构投影，验证 `noncanonical_basis`、成员维度确实由 Worker 口径产出。
- **必覆盖的反例**：
  - 显示名：目录有中文名、对照表命中、两者都无（回退代号并标"未提供中文名"）三例；同一指标多成员显示不同中文名；融资买入额。
  - ③：名单内指标在 ③、中债 030 不在 ③、GDP 行出现在 ④ GDP 抽屉、名单外行进入"其他背景指标"。
  - 非典型：有 `noncanonical_basis` 时出现"只差一项"三项且内容来自字段；无该字段时不出现；右栏一行；④ 行为读法 + "不计数"；有正式阶段时 ④ 显示确认关系、结论板五小格。
  - 转折观察：反向候选列入、同向不列、方向为空不列且资产卡写"无"、全无时的固定文案。
  - ⑥：连续同状态合并为一个区间，状态变化处断开；区间抽屉含逐日与更正说明。
  - ⑦：缺口只出现一次；超过 5 条出现"查看全部"。
  - 抽屉：每类触发器打开的抽屉内容包含该项全部字段；固定历史投影时抽屉内容来自所选投影。
  - 桑基：失败类结果归红、候选归琥珀、未映射归灰；小来源合并。
- **需改写的既有断言**：依赖 ① 三核心表、原地展开 Details、③ 宽表、⑥ 逐日事件全量、"30 日方向为空列入转折观察"的断言，改为新结构下保护同一业务行为（证据往返、固定投影不漂移、候选两概念分列、更正版本可追溯）。
