# 北交所融资浏览器补证：页面打开超时，目标日样本仍缺

研究日期 2026-09-07；固定目标日 **2026-08-28**。本轮按 research 的独立有界子任务，使用 computer-use 技能指导下的现有 CUA 浏览器能力，只读尝试已知[北交所融资融券交易信息页](https://www.bse.cn/disclosure/rzrq_trans_list.html)。

**实际发起 1 次浏览器导航尝试，60 秒后工具超时并重置会话，未返回页面句柄或初始状态。有效目标样本 0；DOM、截图和官方下载原件均为 0。** 这补充了浏览器读取路径当前不可完成的证据，不能证明北交所页面本身显示了登录、验证码、403 或 302，更不能证明数据不存在。票 05 所需官方样本及实际发布时间仍未补齐。

## 1. 既有依据与本轮方法

先复用[此前北交所增量报告](margin-bse-followup.md)、其[逐次 HTTP 回执](evidence-05-bse-followup/receipts.json)与[票 05](issues/05-margin-certification.md)。旧报告已列出本轮使用的融资页面 URL；旧研究中的 HTTP 403、302 自指和早期浏览器未取得内容是历史观察，不能冒充本轮网络状态。旧报告 SHA256 为 `4b6690e908b3a92d71f502e94011f88b2bf634a423dd573cd9ddd9dfe5c58b62`，本轮只读校验其字节摘要。

已阅读 `computer-use/26.901.51231/skills/computer-use/SKILL.md` 及其 guidance、confirmations 文档。技能推荐浏览器交互使用浏览器 API；当前可调用的是 CUA 浏览器能力，原生应用能力禁用。本轮依据工具返回的真实 API 文档使用 `cua.getBrowser`、`Browser.nameSession`、`cua.createBrowserTab`，不调用原生控制或其他未文档化接口。

只按已知目标 URL 选择 Chrome，不枚举现有标签、不读取用户其他页面、账户或凭据。为任务命名后，打开该 URL 一次。此次不是重复直接 HTTP GET，也没有改日期、拼后台接口、重载页面、处理访问挑战或调整网络设置。

## 2. 实际动作、时间与失败边界

完整[动作回执](evidence-05-bse-browser/browser-actions.json)和[工具观察转录](evidence-05-bse-browser/browser-tool-record.txt)保留调用与结果。这两份文件是研究代理根据工具输出记录的观察，**不是官方原文、HTTP 网络日志或渲染快照**。

| 动作 | 可观察结果 | 计数与边界 |
|---|---|---|
| `cua.getBrowser({url: 官方融资页面})` | 返回 Chrome、extension 类型及浏览器 API 文档 | 选择浏览器，不打开标签，不计导航 |
| `Browser.nameSession` | 空输出完成，工具耗时 0.1071 秒 | 仅命名任务，不计导航 |
| `cua.createBrowserTab` 打开官方融资页面 | 设置工具超时 60000 毫秒，实际工具耗时 60.2151 秒；结果为执行超时并 kernel reset | 计 1 次导航尝试；不等于已证实 1 次 HTTP GET 或一次成功页面读取 |
| 失败后读取 UTC 时钟 | `2026-09-07T15:16:01Z` | 只作为事后记账时钟，不能当导航起止、页面读取或数据公开时间 |

导航前在 CUA 内赋给变量的开始时刻没有随超时结果返回，重置后不可恢复，因此精确开始/结束时刻都保留 `null`。不通过“事后时钟减 60.2151 秒”伪造请求开始时间。没有取得页面，实际页面读取时间亦为 `null`。

工具没有返回 Tab 句柄、初始 AX/DOM、标题、实际地址或截图，无法判断标签是否部分创建、网页是否加载、浏览器内部发生了多少跳转/资源请求。HTTP 状态、跳转链、登录/验证码有无及网站拒绝原因均为未知。没有句柄可供限定读取或关闭；本轮不通过枚举其他标签恢复它，也不宣称已清理可能部分创建的标签。

本任务上限为 2 次导航，实际只用 1 次，剩余 1 次未使用。当前调用没有返回可观察页面或新的官方动作依据，重启后再打开同页将成为重复超时尝试；因此直接收口，没有额外 GET 或第二次导航。该停止条件是本次工具路径中断，不是来源认证通过。
