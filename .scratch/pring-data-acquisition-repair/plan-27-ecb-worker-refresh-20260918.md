# ECB Worker 直接刷新接线

前置提交26a0b84已冻结新模型 SYSTEM 目标日规则。沿用获准公共 seam 与 TDD，先把供 Worker 和候选刷新共同使用的 context refresh 阶段提升为公开函数 `refresh_context_sources`，既有调用同步改名；不增加临时激活、私有 SQL 或内部服务模拟。

首个公开反例从实际候选准入、RunRepository 获取归属、公开刷新函数，走真实 HTTP 边界替身到 Acquisition/EvidenceRepository/ModelInputSelector。新注册目录包含独立ECB身份时，应无需TuShare凭据也执行一次ECB官方历史ZIP请求，结果及失败归属该运行、该指标，原件与时间可追溯。旧目录不请求ECB；仅该P2通道获取/校验失败不会中断其他刷新。

范围使用现有直接日频刷新相同的目标日前220自然日采集上界；它仅是采集范围，不声称等同120中国交易日或回放通过。报告可见范围继续由独立中国交易日历界定，校验全ZIP但只导入范围内有效日期。未来若窗口超过该采集上界，完整检索仍按日历显示缺口，不静默缩小验收。

此切片验证直接刷新阶段及物理获取归属，不冒充 process_pending_run 全生命周期验收。完整已激活隔离候选 Worker、真实认证和回放仍须后续执行。固定真实目标2026-09-11不移动；本阶段取得的无PUBLIC历史数据不能补该日的模型输入。
