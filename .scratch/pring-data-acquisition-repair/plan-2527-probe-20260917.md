# 票25 + 票27 合批探测：请求前冻结（2026-09-17）

**本文件在发出任何请求之前写定。** 与[票13 的有界抓取](plan-13-bounded-fetch-20260917.md)同一套纪律——那一轮我编造过 URL 吃了两个 404，停止条件按设计生效。这次先冻结，再探。

## 为什么两票合批

票25 要给 7 项补官方候选 URL，票27 要核实 5 项国际行情的取用方式。两者都是**只读探测、只出报告、不动目录**，且都必须先拿到真实可达的地址才能谈实现。分两批跑没有收益，只多一轮环境往返。

**探测不等于实现**：本批结束时目录、代码、指标定义一律不动。

## 冻结参数

| 项 | 值 |
|---|---|
| 允许域 | `stats.gov.cn`、`pbc.gov.cn`、`cboe.com`、`cdn.cboe.com`、`nasdaq.com`、`indexes.nasdaq.com`、`chinamoney.com.cn`、`tma.org.hk` |
| 请求预算 | 每个目标 ≤2 次，**总计 ≤16 次** |
| 方式 | 只发 GET，串行，间隔 ≥2 秒 |
| 停止条件 | 连续 2 次非 200、或单次响应 >5MB、或达到总预算即停 |
| 落地 | 只记 URL、状态码、字节数、sha256、是否含目标字段的迹象；**原件按内容寻址存盘** |
| 不做 | 不改 `catalog.py`、不改任何指标定义、不写正式运行数据、不认证任何来源 |
