## 1. 已批准口径：集合与金额适用性分别判断

[规则记录第 38 行](business-decisions-draft.md#L38)已决定：同一历史沪深北普通 A 股池，按适用制度计算普通竞价、盘后固定价格、大宗交易等全部交易所成交金额；非交易过户不计。分子为 **08 已判为上涨的成员**的同范围金额，分母为 **全池**同范围金额。必需金额未知、无法排除重复覆盖或总额为零时不可用。以下是该规则的直接工程含义，不是新增产品选项。

设 `U_T` 是 08 已核验有效身份区间内的历史普通 A 股集合，`A_T` 是其中状态为 `advance` 的成员；每个成员的 `M_i` 是全部适用且覆盖关系已证的成交金额：

```text
N_T = Σ M_i, i ∈ A_T
D_T = Σ M_i, i ∈ U_T
share_T = 100 × N_T / D_T，只在必要输入完整且 D_T > 0 时可用
```

| 08 身份／状态 | 进入金额分母的成员集合 | 进入金额分子 | 金额应怎样检查 |
|---|---|---|---|
| 已核验普通 A 股，`advance` | 是 | 是，计该成员全部适用交易方式 | 各分量同日同身份、单位统一且无重复覆盖 |
| `decline`、`flat` | 是 | 否 | 它们缺一个必需分量，同样会使全池分母不完整 |
| 合法排除状态：`full_day_suspension`、`no_legal_trade`、`first_day_reference_unproven`、`reference_price_missing`、`close_price_missing` | 仍属 `U_T` 时是 | 否；保留其排除原因，不能称为下跌或平盘 | 不能由不参加涨跌推导全部交易方式金额为零。已证零记零；制度不适用记不适用；其余未知仍阻断完整金额 |
| B 股／CDR 等非普通 A 股；目标日未上市或已经摘牌 | 否 | 否 | 保留原件和排除身份；不把这些股票的金额加入全池普通 A 股总额 |

## 3. 最小完整软件正例及独立手算

下面的 A/B/C、价格、金额、适用性和互斥覆盖都是**隔离软件输入假设**，不是新取得的官方证券数据或认证结论。实现时映射到现有合法合成历史成员，沿现有审查协议绑定原件、有效日期及 PUBLIC；不用这些假设给真实 `daily.amount` 授权映射成纯竞价。

假设同一交易日 `U={A,B,C}`，三个成员均是有效历史普通 A 股，所有成交方式都已被此 fixture 的已审范围完整列举。输入审查明确本例“竞价／盘后／大宗”互斥、无其他适用方式；各栏以**千元**计，显示的零均有明确零事实证据：

| 成员 | 08 的合法结果 | 竞价 | 盘后固定价格 | 大宗 | 完整成员总額 | 分子采用 |
|---|---|---:|---:|---:|---:|---:|
| A | `advance`，同日参考价 10、收盘 11、实际成交 | 100 | 10 | 20 | 130 | 130 |
| B | `decline`，同日参考价 10、收盘 9、实际成交 | 200 | 0（已证） | 30 | 230 | 0 |
| C | 首日有成交但官方参考价未证，08 状态 `first_day_reference_unproven` | 40 | 0（已证） | 0（已证） | 40 | 0，保留排除原因 |

独立手算：

```text
竞价分子/分母 = 100 / (100 + 200 + 40) = 100 / 340 千元
盘后分子/分母 = 10 / (10 + 0 + 0)     = 10 / 10 千元
大宗分子/分母 = 20 / (20 + 30 + 0)    = 20 / 50 千元
完整分子 N = 100 + 10 + 20 = 130 千元 = 130000 元
完整分母 D = 340 + 10 + 50 = 400 千元 = 400000 元
上涨金额占比 = 100 × 130/400 = 32.5%
```

此例故意让非参与成员 C 有 40 千元金额。若错误地采用 08 `participants={A,B}` 为分母，得到 `100×130/360 = 36.111…%`；只算竞价得到 `100×100/340 = 29.411…%`，均与 32.5% 不同。也可加入已摘牌成员或 CDR 的任意金额，正确结果仍不变，证明使用了同一历史普通 A 股池，而非 transport 返回的全部行。

隔离完整正例的先决条件是每一必要金额及其覆盖关系已证明，不是“HTTP 有 3 行”。逐项账需要能读回成员身份、业务日、方式范围、适用性、原字段／单位、值、发布证据、来源原件和纳入分子／分母原因；这些可以利用现有审查输入包和采集制品表示，不要求新建独立服务或平行股票池。

## 4. 从同一正例变一个事实的反例

| 改动 | 期望可观察结果 | 不允许的捷径 |
|---|---|---|
| A 盘后 10 改成“适用但未知” | 整体不可用；缺件精确到 A／日期／盘后方式，分子分母不能标完整，保留已得其他金额 | 把未知改 0 或只算竞价 |
| C 的一个必需金额改成未知，即使 C 不参加涨跌 | 同样不可用，证明检查了整个 `U` | 因 C 不在 `participants` 而漏检分母输入 |
| B 或 C 原来明确 0 的方式改为“制度不适用”，且另有覆盖目标日的合法适用性原件 | 不要求该方式数值，保持不适用状态及依据；本例数值可仍为 32.5% | 没有制度依据就把 null 标不适用；把原始 null 改写成观测 0 |
| 删掉上述“不适用”的证明，或使规则生效日迟于目标日 | 保持适用性未知／证据不足，不能完成金额范围 | 用当前规则回填整个历史；从字段上线日期推交易制度不适用 |
| A 另输入全方式汇总 130，同时保留竞价 100／盘后 10／大宗 20，未给合法采用或互斥覆盖依据 | 指出范围重叠／无法唯一确定覆盖，整体不可用；不能累加两套 | 错误双算会成为 `100×260/530≈49.0566%`。数值相同或不同来源 ID 都不能证明交易互斥 |
| 同一方式同一成交事实重复交付，或同日大宗列表分页缺失 | 原件留存，按已证事实身份识别重复／不完整；无法确定唯一事实集合时不可用 | 用值相同直接去重，或因一页非空就声明当日完整 |
| 全池各适用方式都是有证据的 0，并相应提供合法无成交／停牌状态 | `D=0`，不可用，原因可追溯；不发生除零，不生成有效 0% | 构造价格正且有成交量但金额全零的自相矛盾 fixture；或把无法取数的空表当零总额 |
| 保持 `D>0`，所有有效涨跌成员都为下跌／平盘 | `N=0`，可以是有效 0%，与上一行区分 | 沿用“0 代表缺失”的判断 |
| 所采用金额／适用性证明的 PUBLIC 从截止前移到截止后，或改成未知 | PUBLIC 不得提前采用；SYSTEM 依真实获取、验证及模型资格独立处理 | 只继承 08 价格的发布时间，遗漏金额或范围证据 |
| A 的真实价格样本换为 000001 除息日 `11.24/10.94`，其金额另用清楚标记的 fixture 值 | 延用 08 同日参考价判断上涨，金额进入分子 | 重算成 `11.24/11.30` 后判下跌，或引入 09 最终复权窗口作为金额前置 |

重复交付同一个已知事实可以按现有身份／不可变版本协议处理；要求是不能重复计算同一成交范围。此处不新增“任何相同内容重取都必须永久拒绝”的业务规则。若输入审查明确选择一套合法、完整且互不重叠的覆盖，其他响应可保留为对照，不能无证据自行选择总额或拆分优先。
