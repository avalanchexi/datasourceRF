# 04: 三核心官方语义与历史公开时间认证

**What to build:** 为债、股、商品三核心形成可复查的身份、历史方法、数值样本与发布时间认证包，并可查询认证生效范围内的候选序列。

**Blocked by:** 02 — 核心采集原件与双点时可追溯.

**Dependency rationale:** 认证必须建立在已修复的原件和双点时采集协议上。

**Status:** superseded（未批准草稿，已发布为正式票，不可领取）

## Acceptance criteria

- [ ] 三核心各自有官方身份、点位/价格含义、单位、历史连续性和实际公开时间的依据；原件哈希可读并与交付值核对。
- [ ] NHII 的成分/方法和认证生效范围遵守现有决定；NHCI 不作为临时替代，后备篮子不逐日择优切换。
- [ ] 覆盖所需 120 交易日窗口及最小预热；历史回填值与当时可知版本分开，未知公开时间不造通过记录。
- [ ] 在修复后的候选数据读取入口演示 PUBLIC 可见与未来证据被排除，SYSTEM 查询能重现取得过程。
- [ ] 缺官方发布时间或其他必要证据时列出具体日期/字段/请求结果并保持认证未完成，不能只交一份研究摘要便勾选通过。

## Testing decisions

以规格中的公开任务/采集/查询边界验证可观察行为，复用真实解析与证据仓库；只替换外部 transport、时钟或 CLI 子进程。来源实测、隔离 fixture 与正式发布分别标识，必要反例先失败再修复，不以实现自身的重复计算替代独立期望。

## Further notes

只采用已有公开或用户现有授权来源，不在本票自动购买历史服务。核心长期校准边界不因补证静默改变。

本票属于“数据获取可信性、检索补缺与 Pring 输出修复”规格。进入新的干净实施会话时先读取完整规格与本票。只实施本票纵向行为，不修改/关闭原父任务或冻结审查。需要的外部原件或最小业务选择仍未满足时，记录具体阻塞并推进其他已解除依赖的票；不能把缺口记录本身当作正向认证通过。
