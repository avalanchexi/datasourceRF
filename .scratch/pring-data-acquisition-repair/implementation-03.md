## 逐路径迁移

| 路径 | 收据、时间与当前边界 |
| --- | --- |
| Worker 的 TuShare 上下文家族 | 每次实际 HTTP 响应保留原始 bytes；完成整个家族的字段、数值、期次及标准化后才完成收据校验；批次失败使未完成请求保持失败。每个标量关联同接口请求，派生家族关联全部实际输入，包括日历和预热。 |
| TuShare 指数、估值、利率、融资及宏观等时间生成路径 | 删除固定 15:30、11:00、00:00、次日 06:00 及抓取时间回填。响应未携带可证发布时间的标量保留 PUBLIC unknown；新请求追加新声明，SYSTEM 从验证完成后可见。 |
| EIA 石油现货 | 真实响应 bytes 先存储，再检查官方响应身份、JSON、单位、系列与期次。两系列声明关联收据；参数排除 API key。历史值没有逐行可靠发布时间，PUBLIC unknown。 |
| 官方上下文 refresh | 请求前登记，保留实际响应，校验官网身份、单位、字段、统计期及页面发布时间；容量超限保留实际收到的有界前缀再拒绝，不能称为完整超限页面。 |
| 官方上下文文件导入、source-history 导入 | 明确记录 document_import；使用当前导入/验证时刻建立 SYSTEM 时间，不把旧文件重新导入说成当年的 HTTP 取得。旧 CAS 引用仍保留。来源历史目标日按上海日期判断，仅日期出版不能在当天通过目标截止。 |
| LPR 导入与 refresh | 两期限共用原件收据。去除必须 09:00 的限制；明确出版元数据支持精确时刻、仅日期及缺失。正文/标题/URL 中的发行日期只用于期次身份，不冒充发布时间；事件加入原件指纹以容纳可靠修订。 |
| 直接传入 ContextScalar/EiaSpotPrice 的旧领域导入 | 保留兼容接口；无实际请求收据时仍是 untraced，不能声称完成真实 HTTP 追溯。真实 Worker 已改走有收据接口。 |

官方日期精度遵守来源本地次日零点规则，未知时间保持空；未来发布日期拒绝。沿用同一旧发布时间却改变数值的原件形成未知修订；重复下载或页面布局改变不会把它重新变成 PUBLIC 合格。后续新原件的可靠发布时间晚于未知修订已取得时间时，可以建立新修订自己的 PUBLIC 时间，旧修订仍保留未知。

证据多对多关联不依赖 source_reference 恰好等于 CAS 引用。共享选择接口在 SQLite 粗略时间过滤后使用完整 datetime 比较与排序，避免毫秒舍入使验证完成前 1 微秒就可见。旧目录、模型、声明及 v3 否定性隔离没有重写或认证升级。

## 实际原件验证

[独立验证脚本](verification-03/official_sample.py) 使用生产 CAS 中只读提取的[国家统计局既有完整页面](verification-03/nbs-cpi-202607.html)，原件 SHA256 为 `1ae383d1e5934bdb3484933c7e359f9ac4b04850d2952be08c627897bf37a7f5`，233,415 字节，登记 URL 为 `https://www.stats.gov.cn/sj/zxfbhjd/202608/t20260809_1965008.html`。本次不重新请求网页；原先接收时间未独立证实，本次只认证 document_import 的实际系统时刻。

人工核对页面表格：总 CPI 环比 -0.1、同比 0.5、累计平均同比 0.9；核心 CPI 分别 0.3、0.9、1.1，单位均为百分比。页面标注 2026/08/09 09:30。真实 parser、仓库和候选上下文读取均通过；6 条声明链接同一原件，PUBLIC 在标注时刻前不可见，SYSTEM 在本次导入前不可见，候选上下文继续显示待来源认证。见[实际结果](verification-03/official-sample-result.json)。该验证没有生产写入、外部新请求、新来源认证或正式模型激活。

未知发布时间、not_applicable/not_disclosed 数值状态、发布窗口尚未到达及 source_failed/validation_failed 保持不同语义；没有用抓取成功替代适用性或来源认证。完整回归继续核对已有相应读模型与失败分流。
