# 08：历史股票池与日涨跌广度的官方补证

研究完成于 2026-09-07（上海时间）。本轮仅取得公开材料、导入已有证据副本并离线核验；没有调用账户接口、读取密钥、建立来源认证、修改运行库、冻结广度规则或切换模型。

**结论：已有 120 日候选输入可逐件复核，新增上市、摘牌、停复牌和代码制度有具体官方锚点；历史 PUBLIC 股票池仍未闭合。** 不能把当前 L/D/P 元数据反推的成员序列直接认定为市场当时可知。尚需明确新股、停牌和零分母等计算决议，并补覆盖全窗口的历史事件与发布时间。

## 1. 证据和核验边界

- [直接 HTTP 收据](evidence-08/receipts.json)保存 27 次公开 GET 的 URL、起止取得时间、响应状态、精确 SHA256、字节数及实际响应文件名；18 次 HTTP 200、4 次北交所 302、5 次 404。200 包含规则目录及交易日历文档等辅助页，不等于 18 份模型可用证据。302/404 均保留失败原件，没有当成映射表、上市公告或旧规则。
- [已有原件导入表](evidence-08/imports.json)包含 12 件只读副本。导入时间只是本轮复制时间；TuShare 原取得时间及请求身份查旧清单的 `receipts`，两份旧官方停牌 PDF 的原取得时刻未在该清单中提供，继续未知。不能用导入时间取代历史获取时间。

- 旧最终清单为 [dfa264f9…](evidence-08/dfa264f956d2c07def24190b0fda8dc8da6160b6c37000fe165c9cde9b834110)。本轮复核仍得到 662,274 个上市成员日 = 660,811 个行情成员日 + 1,463 个全天停牌成员日，盘后金额未知 453,571 个成员日。窗口合计 5,569 个不同证券代码；相邻输入帧记录 81 次进入、19 次退出。完整变更列表在核验结果 `membership_changes`。

这些 81/19 是候选输入的变化清单，不是已经核实的官方事件计数。本轮没有通过抽样把其余变化自动视为已证，也没有把 120/120 结构覆盖改称来源认证通过。复核脚本为 [verify_evidence.py](evidence-08/verify_evidence.py)，0 网络、0 数据库写入；公开采集脚本为 [capture.py](evidence-08/capture.py)。PDF/HTML 的同名 `.txt` 只作阅读辅助，原始字节以 64 位哈希文件为准。

本轮使用的是公开网页研究与直接下载，**未调用 Tavily 或 Exa**；以上 HTTP 数字不能作为票20的供应商命中率、补齐率或费用统计。

### 2.2 停牌、复牌和 ST 是不同维度

继续保留两份原裁决：603159 的 [6月16日发行人公告](evidence-08/f6103823d476d069330acc1080c1df8e245799625146d23fada44605dac87329)明确当日开市继续停牌；002731 的 [7月6日发行人公告](evidence-08/ac25307c061923f16bfc4e5aa63fc06bd995fc25813592ce869b0689aee0106c)明确7月6日继续停牌一个交易日、7月7日复牌并实施退市风险警示。原始地址及精确股票/日期绑定在旧最终清单 `official_suspension_evidence` 中。

002731 的旧 [7月7日日行情原件](evidence-08/f92f341223b2b133e35da43d4ccbe890072927ee83114920c2522db0a9a677c5)有 `close=3.92, pre_close=4.35`，停复牌原件另有 R 记录。这是“仍属上市股票、已被风险警示、当天有交易”的具体例子。ST、暂停上市、全天停牌不能用一个排除标志混用；是否把 ST/退市整理股票纳入广度，仍属于定义选择。

[TuShare 停复牌文档](https://tushare.pro/document/2?doc_id=214)的[原件](evidence-08/671e2b87150f5c52e0147cb05fa613914400a57f168e56afa3fef0d0bdfde90f)说明 `S/R` 和日内停牌时段字段，更新时间为不定期。文档并未保证每条 S/R 永无冲突，也未给出冲突自动裁决优先级。上述两份公告只解决各自股票/日期，不允许推广为“S永远优先R”。

### 2.3 当前官方规则支持价格语义，但窗口内有版本切换

[深交所2026交易规则通知](https://www.szse.cn/lawrules/rule/trade/current/t20260424_620190.html)及[规则PDF原件](evidence-08/9b66f8b0db70f84a25ef1ccb4ee2351001724e408117552d75f6d8993483c586)分别证明发布日4月24日、生效日7月6日；当天废止2023版本。上交所[发布通知原件](evidence-08/f7637a974779077f53de874c1fbb9408c88e70fba2e0410871e0b1d7c376e699)也给出相同切换日期。**规则公布不等于立即生效，2026版本不能直接覆盖3月9日至7月3日。** 本轮按搜索提供的3个2023 PDF路径及1个通知路径下载均404；没有以2023征求意见稿替代生效原件。

已取得深交所2026 PDF中的有关语义：

- 4.2.3：无成交时收盘价承接前收盘价。因而有行情记录或平盘数字本身，不能证明当天实际参加交易。
- 4.3.3—4.3.7：停复牌具体时间以公告为准，日内停牌可以复牌；停牌行情仍可能揭示证券信息，摘牌后不揭示；挂牌、摘牌、停复牌由交易所或发行人公告。
- 4.4.3、5.2.3：除权息日按除权息参考价计算涨跌；IPO首日显示的前收盘价是发行价。原日行情 `pre_close` 不能机械替换成上一行 `close`。
- 4.5.1：风险警示及尚未摘牌的退市整理股票仍有交易制度，不能把名称含 ST 直接解释为退市。

[TuShare daily 文档](https://tushare.pro/document/2?doc_id=27)的[原件](evidence-08/1ae0c04367235ecd343b1e8b89ba88178020f00ac2a974872e08b5536431068b)说明未复权收盘价、除权昨收、普通/盘后金额分别为千元，停牌期间不提供日行情。文档所说每天15—16点入库是渠道通常更新窗口，**不是本项目任一观测的实际 PUBLIC 或 SYSTEM 时间**。[stock_basic 文档原件](evidence-08/44728595a627f48fedc8d5d6a47cbb5327534630c81e1f1e6da436d1b36b5f27)给出当前 L/D/G/P/UN 状态及上市/退市日期，未提供本项目所需的历史公开修订记录。

另一个与票10直接相关的制度变化：[深交所修订说明](evidence-08/3a309bf5b4f7b2ee170b897084397568c7a1db939b398f4ab8999587501c727a)及[技术通知](https://investor.szse.cn/marketServices/technicalservice/notice/t20260424_620199.html)、[上交所修订说明新闻](https://www.sse.com.cn/aboutus/mediacenter/hotandd/c/c_20260424_10816474.shtml)表明盘后固定价格交易适用范围扩大至全部A股，主板风险警示涨跌幅限制从5%改为10%。不能按新制度推定整个120日窗口都有相同盘后范围，也不能仅据制度不适用把渠道历史空字段原地改写为0。

### 2.4 证券类型和换码证据

[深交所2026年3月证券代码区间表](https://www.szse.cn/marketServices/technicalservice/doc/P020260306733846760075.pdf)的[原件](evidence-08/1acbb35917105252edd5502377cc8ccfdd566d7cd62f37fc3838cf11483336c4)区分001001—001199主板存托凭证与001200—001999主板A股，也区分创业板股票与存托凭证。文档明确推荐优先使用数据文件的证券类别定义，号码区间只作细分参考。当前代码前缀识别可与此样本复核，但还需要历史证券类型与各版本有效范围，不能无期限依赖一个当前前缀表。

北交所[2024年代码切换准备通知的巨潮收录副本](https://dataclouds.cninfo.com.cn/sjother/regulatory/2024/20241213/d7cfc96e816541629e69b0e257d98dbe.pdf)，[原件](evidence-08/46535d7c7301514e83a7856968b5ee8e60069c5707fb87d79fcfd07a9974cf59)，是北交所署名文件的公开收录件；本轮没有取得与北交所直连字节相同的认证。该文说明切换不改变主体、投资者权益和行情连续性；重复代码有第四位递进处理，**不能靠旧代码后三位机械拼接920**。它还说明精选层平移公司的行情有其历史起点。该准备通知不等于实际切换已经发生，也没有携带可读的完整映射附件。

后续候选已定位为北交所[实际上线通知](https://www.bse.cn/important_news/200026735.html)与[新旧代码对照表](https://www.bse.cn/service/code_mapping.html)：搜索索引展示2025-10-09启用和对照行，但本轮直接请求都是302短响应，**没有保存到真实通知或映射正文**。同样，族兴新材920078的[2026-03-16上市公告候选](https://www.bse.cn/disclosure/2026/2026-03-16/1773656294_079022.pdf)也只取得302。候选摘要不能补成正式代码映射或上市证据。

## 4. 阻塞条件和120日缺件

1. **历史起始池**：3月9日候选有5,488个成员，但缺绑定可靠公开日期的历史身份/证券类别/上市状态起始证据；当前9月取得的L/D/P只能回溯区间。须按ADR0013完成官方抽样支持的历史交付认证，不新增“每条价格都双来源”的要求。
2. **历史变化与可知时间**：81次进入、19次退出须有可追溯事件交付记录及公开可得性。新增样本只补688781和600636的精确边界；600355仍缺精确摘牌日。别把公开的业务名单调整或限售流通事件误作上市成员变化。
3. **停复牌覆盖**：全窗口现有1,463个全天停牌成员日和S/R输入，只有两个冲突经过指定公告裁决；其余来源语义、历史修订与可靠发布时间仍需认证。两份公告日期精度只到日时，按项目规则PUBLIC最早为下一上海自然日，不能倒填当天开市前；因此“事后知道当日停牌”不等于“该日cutoff已可知”。
4. **换码**：仍缺完整历史映射原件、实际生效通知的可保存正文，以及交付渠道是否将历史代码回写为新代码的声明/样本。当前代码串不等于永恒主体ID。这个缺件同时影响票09预热，不能因切换可能发生在可见窗口前就忽略。
5. **规则版本与计算**：未冻结的票08选择见上表；7月6日前适用的2023交易规则原件本轮路径失效，需在认证包里补正确历史版本或复用已核验旧包。新规则发布日期/生效日和观测发布时间分别存储。
6. **后续窗口/金额**：仍无首个输出日前119个市场交易日的完整输入、历史因子/身份连续链；453,571个盘后金额未知成员日仍未解决。日涨跌原料覆盖不等于这两类派生值可用。

建议下一步在票08把业务选择写成明确决议及成员事件公开契约，复用本轮真例和反例实施候选查询；对外部原件缺失继续保持 `awaiting_source_certification`。该研究交付本身不能勾选票08全部验收，不能解锁新模型120日PUBLIC通过或真实切换。
