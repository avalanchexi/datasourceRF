| 字段/对象 | 实测形状与规范 |
|---|---|
| 唯一CSV渠道 | `https://cdn.cboe.com/api/global/us_indices/daily_prices/VIX_History.csv`；原件472309字节 |
| 表头 | 精确为`DATE,OPEN,HIGH,LOW,CLOSE`；按名称绑定，不能取第2列当收盘 |
| 统计日期 | `DATE`为`MM/DD/YYYY`，按美国来源交易日解释；保存`business_day`、期始=期末，不改成中国报告日 |
| 目标值 | `CLOSE`，原文六位小数；`14.530000`规范为指数点位14.53，保留原始精度与字节 |
| 单位 | 当前项目目录使用`index_points`；它是预期波动率指数点位，不是美元、价格涨跌幅、实现波动率或VIX期货结算价 |
| 辅助字段 | `OPEN,HIGH,LOW`保留原件，供质量诊断；本指标采纳的是`CLOSE` |
| 排序/日期唯一性 | 9266行按来源日升序，无重复、周末行或短行/错列表头 |

指标本身来自SPX期权报价、衡量未来30日预期波动；日内现货指数与衍生品最终结算SOQ计算不同，不能互换。[官方VIX FAQ](https://www.cboe.com/tradable-products/vix/faqs)。本次FAQ回答位于官方HTML自带的页面数据中；只用JSON解码阅读，不执行JavaScript，也不把普通HTML文本提取漏掉回答解释成官方没有说明。

## 3. 日期、时区、更新与修订能证明到哪里

官方历史入口仅证明每日更新，没有逐行发布时间、CSV固定发布时刻或完整假期/半日安排。FAQ给的是现货指数计算时段：GTH为03:15–09:25 ET，RTH为09:30–16:15 ET，并说明日内使用15秒报价快照；到期日RTH开始传播还受成分系列实际开盘影响。这不是CSV日终文件的更新记录。[官方FAQ](https://www.cboe.com/tradable-products/vix/faqs)

| 证据 | 能证明 | 不能赋予 |
|---|---|---|
| CSV`DATE=09/04/2026` | 来源日09-04的日终指数点位 | 09-04中国收盘前已知，或任何精确发布时刻 |
| FAQ的ET时段 | 现货指数计算采用美国东部时间；工程可映射`America/New_York`并处理夏令时 | 每日CSV固定16:15 ET公开、提前休市日仍固定16:15 |
| 历史入口“每日更新” | 更新频率 | 保证无延迟、某个固定时区/时点发布、所有历史值从未修订 |
| CSV HTTP Last-Modified=2026-09-05 19:00:50 GMT | 当前文件版本的HTTP修改元数据 | 9266行各自首次公开时间，或把09-04收盘值当09-05才首次公开 |
| 旧CSV接收2026-09-06 17:04:40.473099 UTC | 该次研究已取得此快照 | 项目此前已完成校验，或过去SYSTEM可见 |
| FAQ“最初发布/更新”日期 | 说明文字的文档版本信息 | 行情统计期的逐日公开日期 |

新取得的[DataShop EOD输入产品说明](https://datashop.cboe.com/vix-index-eod-calculation-inputs)写明另一个产品的SFTP交付通常为16:35–19:00美国东部时间，提前收盘日提前3小时，历史从2022-05-09开始。它是VIX最后发布值的**计算输入文件**，有购买/订阅和用途条件，不能把这套交付时段、历史起点或许可直接套到免费`VIX_History.csv`。本次只GET公开说明，没有下单、登录、取SFTP文件或购买样本。

因此本CSV历史每行`release_at`与`public_available_at`仍为null；来源计算时区已知，不代表文件发布日期已知。没有可靠日期时也不能套“次日本地00:00”的保守日期规则。若未来正式取得渠道接入，SYSTEM时间应由该次实际取得且校验完成记录，本研究复制/解析时间不能回填成生产取得时间。

本次只有一个旧CSV快照，没有实际观察到同日CLOSE修订，不能写“已证实未修订”或虚构修订次数。后续新快照若同日值变化，应保留原件和追加版本/冲突记录。历史序列1990年起点也不能证明当时已经以今天的VIX方法实时公开；官方入口明确2003年方法发生变化，不能把历史回算文件当逐日原始发布档案。[历史说明](https://www.cboe.com/tradable_products/vix/vix_historical_data)、[双点时ADR](../../docs/adr/0006-dual-as-of-and-immutable-evidence-vintages.md)
