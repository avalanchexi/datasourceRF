# 最新GDP季度不可计算时退用旧窗：根因与影响

2026-09-11，在本轮生产修复前写入，生产仍为237/238/240所测版本。

[244真实日志](verification-credit-window-tail-red-joint-244.txt)为2失败、2通过、16排除、81.95秒。PUBLIC/SYSTEM的最新2026-Q2累计与Q1相等时，信用脉冲仍available而非missing_certified_inputs；额外未选旧原件损坏的两项控制正确保持可用。[245根核验](verification-credit-tail-red-245.json)确认312输入/4保护、前后环境、原进程结束和卷卸载；未因新失败改写旧16项/20项通过结果。

复现保留原34个父项，另公开导入合成2024-Q1 GDP，形成35份完整获取收据和10个可见GDP累计期次。最新无效场景只改2026-Q2 GDP累计为350000，与Q1相等；所有制品保持完好。反例先验证35份获取与所需字段可见，不是少导入最新值。未选旧坏件控制只损坏额外Q1原件，所需34父项及其采用ID不变。

根因：`_quarter_levels_from_ytd`略过非正季度差分，`_credit_impulse_proxy`之后对剩下的结果取最后8期。数据更长时，最新无效季度被过滤后，仍可取出完整且连续的旧8季度；既有连续性检查与全部选中父项原件检查都可通过，却没有核结果末期仍为本次最新已选累计期次。故返回截至2026-Q1的旧GDP窗口，而上下文目标仍2026-08-28。

影响限于共享GDP累计差分消费路径，内置目录同样使用此路径。它可生成旧窗派生身份及模型采用ID；这不是原件损坏，也不能通过扩大数值容差解决。月度/季度直接值优先、认证/质量过滤导致最新点消失以及社融累计缺口属于接续矩阵，不在本条反例中假称已经验证。

修复：要求可计算季度窗口的末期等于最新已选GDP累计期次；不足8期或末期后退均返回既有missing_certified_inputs和空采用ID，在派生计算/写入前停止。保留未选旧坏件不阻断、同年邻期与正数规则、原件联合核验及公告相容性。随后运行本轮公开边界和既有相关回归、两轴复审；完整信用脉冲及全项目最终验收仍开放。
