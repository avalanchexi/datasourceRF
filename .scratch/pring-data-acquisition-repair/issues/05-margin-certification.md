# 05: 沪深北融资完整采集与认证

**What to build:** 用户可按目标日期查看完整三所融资余额与买入额、官方对账依据和真实历史可得性，缺北交所时明确拒绝全市场认证。

**Blocked by:** 03 — 上下文采集原件与未知公开时间隔离.

**Dependency rationale:** 融资候选使用 03 的时间/原件契约；不依赖估值或其他市场家族。

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 复用现有 120 日三所候选矩阵，核验逐日三所身份、重复/缺行、单位换算与应有标量组合。
- [ ] 取得北交所可对账官方原件并记录实际发布/修订证据；不使用总额减沪深推算北交所官方样本。
- [ ] 沪深已取得的四数对账证据继续可复查，并说明全市场汇总差额的边界。
- [ ] 候选读取可追溯三所组成和源原件；公开日期未知仍为未知，不以披露最晚时限代替实际发布。
- [ ] 形成家族认证包与正负测试，未完成必要外部证据时保持本票受阻及未认证。

## Testing decisions
