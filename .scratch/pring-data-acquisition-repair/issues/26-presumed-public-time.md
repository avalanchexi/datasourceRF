# 26: 无可靠日期时的公开可用时间

**本票 2026-09-17 的第一版实现已整体撤回。** 撤回理由见[标准轴复审核实](../review-26-standards-findings-20260917.md)与[实施记录](../implementation-26-presumed-public-time.md)。简述：

1. `CONTEXT.md` 的术语表**早已定义**「公开可用时间」为"**只有发布日期时从下一本地日开始**，无可靠日期时为空"，并把"推测发布时间"列入 `_Avoid_`。用户定的"保守推定次日 00:00"**就是这条既有定义**，不是新需求。
2. 我写的 `presumed_public_time()` 与同文件 28 行之外的 `publication_times()` 日期分支**逐字节等价**，实测返回值相同。
3. "时刻从哪来"**本来就能从既有两个时间字段推出**，新列冗余；且其默认值会把 `official_context.py:230` / `official_lpr.py:148` 经日期路径写入的既有声明错标为"来源实际发布过"——正是本特性该防止的失真。

## 真正未解决的是另一类

术语表把无可靠日期的情形定为「**为空**」，即不进入 PUBLIC 点时查询、不可采用。票13 的 B 类 3 项正卡在这里：

| 指标 | 卡点 |
|---|---|
| `CN_DR007` | 历史首次公开时间未知，**连可靠发布日期都没有** |
| `CN_SHIBOR_ON_1W_3M` | 同上 |
| `CN_LPR_1Y_5Y` | 使用边界待核（许可核验已由用户[明示豁免](../decision-13-licence-waiver-20260917.md)） |

C 类 2 项情况不同：`CN_RRR_EVENT` 有调整日期（[有界抓取取得的两件人行原件](../implementation-13-daily-acquisition-rule.md)含 2015-04-19 等调整日），**因此已落在既有的"只有日期"分支，本票不需要为它做任何事**。

## 因此本票是领域语言问题，不是实现问题

要让"连可靠日期都没有"的值可用，等于把术语表里的「无可靠日期时为空」改掉。这是**领域定义变更**，须走 `/domain-modeling`，产出修订后的 `CONTEXT.md` 条目或一条 ADR，而不是悄悄加字段。

需要回答的：

- 用什么时点代替"为空"？采集时刻？目标交易日次日？还是仍然不可用、只是允许在报告中列出？
- 这类值**能否进入正式投影**，还是只能作为背景显示？
- 它与 [ADR-0006](../../../docs/adr/0006-dual-as-of-and-immutable-evidence-vintages.md)「无前视校准」的关系：任何非空推定都在声称"当时可见"，而这一点恰恰无从证实。
