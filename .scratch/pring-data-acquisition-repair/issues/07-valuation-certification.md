# 07: 三指数估值定义与维度完整性认证

**What to build:** 用户看到明确口径的三指数 PE/PB/换手率及每期成员完整性，缺 CSI1000 或混合 PE 算法时不会被标为完整。

**Blocked by:** 03 — 上下文采集原件与未知公开时间隔离.

**Dependency rationale:** 复用上下文采集契约；估值不是确认指数票的下游计算，不额外串行。

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 先以既有字段证据收口静态/滚动 PE 的命名和选定定义；此前滚动 PE 样本不能自动替代要求的静态 PE。
- [ ] 对 CSI300/500/1000 的全部要求度量建立应有维度集合，日期和定义版本一致，任一必要成员缺失即不完整。
- [ ] 取得 PE、PB、换手率的官方含义、数值样本、单位及发布时间依据；解释渠道差异而非择小差来源。
- [ ] 通过候选查询展示同一期完整值、缺字段、空响应与口径不匹配；三指数 120 日样本与休市沿用值分开。
- [ ] 输出不可变家族定义和认证包；若需要新增指标或替换定义，记录明确决议及旧指标保留边界，未决不得完成。

## Testing decisions

以规格中的公开任务/采集/查询边界验证可观察行为，复用真实解析与证据仓库；只替换外部 transport、时钟或 CLI 子进程。来源实测、隔离 fixture 与正式发布分别标识，必要反例先失败再修复，不以实现自身的重复计算替代独立期望。

## Further notes

本票包含估值范围内的最小业务决策，不预授权静默新增 TTM 作为替代。

本票属于“数据获取可信性、检索补缺与 Pring 输出修复”规格。进入新的干净实施会话时先读取完整规格与本票。只实施本票纵向行为，不修改/关闭原父任务或冻结审查。需要的外部原件或最小业务选择仍未满足时，记录具体阻塞并推进其他已解除依赖的票；不能把缺口记录本身当作正向认证通过。
