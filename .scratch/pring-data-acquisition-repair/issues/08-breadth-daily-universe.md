# 08: 历史股票池与日涨跌广度可复核

**What to build:** 按历史公开事件重建股票池并产生日涨跌家数/涨跌比候选，用户可解释每个成员的纳入、排除、停复牌与换码处理。

**Blocked by:** 03 — 上下文采集原件与未知公开时间隔离.

**Dependency rationale:** 历史事件时间与原件复用 03；日广度先形成完整可验证行为，再供窗口与金额使用。

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 复用现有 120 日输入与两日官方停牌裁决，补历史上市、摘牌、换码和公开时间依据；当前 L/D/P 上市区间重建仍明确不是 PUBLIC 证明。
- [ ] 收口证券类型、平盘、全日/临时停牌、复牌、新股日统计及零分母的明确规则；将规则选择记录为不可变定义。
- [ ] 成员必须对应合法行情或明确事件，重复、缺行、未知身份和冲突有拒绝例；换码保持主体连续。
- [ ] 候选查询输出日涨/跌/平/参与基数及涨跌比和零分母状态，能够追溯成员原件与选择依据。
- [ ] 无需先完成 MA120 或金额占比即可验证本票；历史可得性或规则尚未闭合时不得宣称该部分来源认证完成。
