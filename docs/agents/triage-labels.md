# Triage Labels

| 标准角色          | 本项目标签          | 含义                 |
| ----------------- | ------------------- | -------------------- |
| `needs-triage`    | `needs-triage`      | 新任务，等待评估     |
| `needs-info`      | `needs-info`        | 信息不足，等待补充   |
| `ready-for-agent` | `ready-for-agent`   | 描述完整，可交给代理 |
| `ready-for-human` | `ready-for-human`   | 需要人工处理         |
| `wontfix`         | `wontfix`           | 决定不处理           |

技能提到某个标准角色时，使用表中对应的本项目标签。
