# 驾驶舱领域语义

## 判断层级

正式阶段只有 Stage I–VI 或空，只由债券、股票、商品三个 P0 核心价格序列的 120 个中国交易日稳定状态机械映射。任一核心缺失、陈旧、冲突、身份不符或初始化不足时，当前正式阶段为空；系统保留上一确认阶段供历史比较，但不会把它冒充当前阶段。

30 日轨道产生资产候选状态和转折观察。它显示方向、持续天数、支持与反证，但不是“候选阶段”，也不能提前切换正式阶段。政策方向、信用响应、过热、物价、库存和 P2 国际环境属于宏观事后确认，只解释已经由价格形成的阶段。

## 优先级与点时

- P0：交易日历、发布可用性和三核心价格。失败会阻止新正式阶段与正式长报告。
- P1：国内解释证据。缺失会降低完整度，但不会用代理补 P0。
- P2：国际背景与低优先上下文。先受预算限制，也不参与正式阶段投票。

`public_as_of` 回答“当时公众能知道什么”；`system_as_of` 回答“本系统当时实际已经采到什么”。统计期、公开时间、抓取时间、系统可用时间和 vintage 分开保存。修订形成新 claim，旧投影和旧报告仍绑定原证据快照。

## 版本与追溯

模型版本冻结指标身份、来源认证、趋势参数、阶段映射和派生公式。候选模型必须先验收、回放并经显式批准才可激活。激活后 30 个交易日内的模型回退只回到新系统内部上一模型版本，不是回退旧系统。

证据追溯不是一级导航。从指标、阶段事件、报告引用或错误状态进入，可查看来源声明、发布时间、系统可用时间、修订链、冲突和派生血缘。搜索结果和 AI 文字不是证据；AI 只能解释冻结证据包，不能分类阶段或引入未验证事实。
