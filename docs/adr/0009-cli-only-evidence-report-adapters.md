# 证据报告采用 CLI-only 可替换适配器与确定性事实骨架

V1 的AI报告只能由Ubuntu/WSL2中已登录的Codex CLI或Claude Code CLI子进程生成；应用不接收、读取、保存或注入模型厂商API key，也不在CLI不可用时改走直接API。两个适配器消费同一冻结证据包和共同Schema，并通过同一本地后置校验；可互换表示输入、结构、不变量和引用语义一致，不要求自然语言逐字一致。

Worker先生成正式阶段、核心状态、指标值、治理缺口和引用组成的确定性事实骨架，AI只生成逐段绑定支持证据与反证的解释。首选适配器可配置且默认Codex；一次报告运行中每个适配器最多调用一次，首选失败后调用Claude。单适配器硬超时300秒，终止宽限5秒，两个适配器总进程预算约610秒。两个CLI均失败时以`completed_degraded`保存确定性简版；主动取消和任何部分、超时、工具调用或校验失败输出只进入运行审计，不产生报告快照。

这一选择用更复杂的Schema兼容层、进程审计和后置校验，换取不让AI改写事实、无API key托管、CLI账号可替换以及失败时驾驶舱仍可读。其代价是自然语言不可字节级复现、CLI升级可能改变能力、长报告耗时波动较大；因此报告快照必须记录CLI/模型/Schema/提示版本和输出哈希，CLI版本升级后必须重跑共同协议探针。
