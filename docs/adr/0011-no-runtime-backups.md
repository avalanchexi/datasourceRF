# V1不为本机运行数据建立备份

Pring周期驾驶舱V1是个人使用的单节点本机应用，用户选择用GitHub管理源码与静态定义，但不为SQLite、内容寻址证据、报告或密钥建立第二份副本，也不创建升级前快照。这个选择以最低运维复杂度为优先，明确接受本机误删、损坏、迁移失败、WSL或磁盘丢失时全部系统点时历史可能不可恢复；RPO和RTO均不保证，从GitHub只能恢复代码后重新初始化，不能重建丢失的历史真值。

## Consequences

主存储在仍然存在时继续遵守不可变vintage、长期结构化血缘和30天报告正文语义，并以容量水位停止写入而不删除被引用证据。数据源密钥只保存在仓库外本机`0600`文件中，不加密、不备份且不得进入GitHub、日志、报告或AI上下文。未来若需要任何日常、升级前、外置盘、云端或异地备份，必须以新ADR重新定义备份范围、凭据处理、RPO/RTO和恢复验收，不能静默添加。
