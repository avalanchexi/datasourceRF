# 分域只读投影组成原子分析投影集

V1 将周期总览、核心资产、宏观、库存、发布日历和阶段历史保存为独立只读数据集，但以共同的 `projection_set_id`、`system_as_of`、数据快照和模型版本组成不可变分析投影集。Worker 只有在全部必需数据集通过校验后才原子切换当前指针；构建或恢复期间继续提供上一套完整投影。浏览器不得重新计算趋势、阶段或宏观状态。

报告、任务和检索状态使用独立运行读模型，可以在分析投影发布前后持续更新，但必须关联目标或产出的 `projection_set_id`。这一拆分避免把长报告或运行状态变化变成全量分析投影发布，同时禁止页面混用不同截止点的数据。

代价是 Worker 必须管理投影集完成清单、原子当前指针和跨数据集验收；运行读模型也必须显式携带关联版本。若未来改为流式、多用户或逐部件实时发布，必须新建 ADR 重新定义一致性边界，不能静默放松原子投影集规则。
