# P1/P2 可从 TuShare 资讯与主流媒体按家族规则取值；搜索只针对可检索缺口

2026-09-24 用户选择（首次真实运行后的检索二期访谈）：

- **降级链**改为 TuShare 数据接口 → TuShare 资讯 → 注册官方直连 → Tavily（Exa 在其月限额耗尽后顶替）→ AI WebSearch。前一级取到值即止，TuShare 取到后不再去官方或媒体页面。
- **搜索范围**：只对可检索缺口搜索，即属于登记解析器家族或登记了宽松主机的指标。由 TuShare 计算的派生指标没有网页来源，不做搜索。
- **查询方式**：查询按家族登记的发布稿标题模板生成，调用搜索接口时按域名限定到官方主机加媒体白名单。
- **TuShare 资讯**：每次运行统一拉取一次，原件只保留 2–3 天。
- **P1/P2 取值**：可采用 TuShare 资讯、白名单媒体网页或 AI WebSearch（Codex 与 Claude CLI 自带的联网搜索，按固定结构返回）中的数值，但须命中该家族登记的资讯解析规则。被采用的明细保存命中原话、标题、来源、发布时间和正文哈希。
- **P0**：三核心仍只认 TuShare 与注册官方来源。

取舍：首次真实运行中，16 次 Tavily 搜索几乎全落在白名单外，其中一半花在网页上根本不存在的派生指标上。“只认官方原文”的严格路径在搜索端几乎不命中；而 TuShare 资讯在官方发布几分钟内就给出准确数字，且不占搜索预算。放宽的边界是按家族登记解析规则，只认规则命中的数，不引入 ADR-0023 拒绝过的通用抽取器；P0 已有 TuShare 与中证官网两条正式通道，不放宽。资讯正文不长期保留，追溯依靠命中原话与正文哈希。

本 ADR 部分取代 [ADR-0023](0023-retrieval-verification-by-registered-parsers.md)：该 ADR 中“P0/P1 只由登记解析器从重抓原文解析、搜索渠道数值不采用”一条，对 P1 改为本 ADR 的资讯解析规则；降级链顺序以本 ADR 为准。其余（白名单、发布日期与统计期要求、预算、Exa 备用、检索未通过）不变。
