# 认证闸的逃生阀开在目录成员资格，不开在闸上

> 已被 [ADR-0021](0021-registered-sources-freshness-replaces-certification.md) 取代（2026-09-23）。

P1 指标与三个核心角色**必须**处于 `certified` 才能进入候选模型；只有 P2 允许带
`awaiting_source_certification` 进来（`candidate_admission.py:203` 与 `:207`）。当某个 P1 的官方原件
长期取不到时，**不放宽这道闸**：既不给 P1 开缺口豁免，也不给 `certification_status` 增加第三个取值。
该指标改为在**目录成员资格**上处置——缩短其已认证历史起点、降级为 P2、或移出目录——每一种都是
显式的、会产生新目录版本的变更。

这样选是因为这道闸就是本产品的全部价值：一个绑定了定义、认证、时间规则与公式的不可变候选，
其可信度完全来自"P1 全部认证过"这个断言。放宽它，"新候选"这个词就不再表示任何东西，而票 19
的三条主验收（逐项汇总 61 项目录、五家族业务规则可读、绑定不可变清单）都建立在闸成立的前提上——
闸一松，它们验的就不再是同一件事。给 P1 加第三种状态同样不可取：票 27 的验收四明确要求
`certification_status` 的取值集合保持两值，加一个取值等于让每个下游消费者重新决定怎么对待它。

已有先例支持这条路线。两项黄金指标（`COMEX_GC_ACTIVE_MONTH_SETTLEMENT_USD_OZT` 与
`LBMA_GOLD_PRICE_PM_USD_OZT`）的历史需要 CME DataMine 付费或 ICE Benchmark Administration 授权，
项目的处置是 `c5b0922` 批准的**删除**，而不是让它们带着缺口留在目录里。本 ADR 把那次个案上升为通则。

代价要说清楚：**目录会因为拿不到原件而变小或变浅**，而这正是意图。一个被移出的指标，其历史声明
按 [ADR-0006](0006-dual-as-of-and-immutable-evidence-vintages.md) 与
[ADR-0012](0012-atomic-model-versions-and-parallel-replay.md) 继续可追溯、不被覆盖；缩短历史起点的
指标则要承担"窗口不足以支撑 120 交易日判定"的风险，那属于该指标自己的可用性结论，不得通过放宽
趋势规则来掩盖（见票 28 的同类约束）。换句话说，代价落在**产品能说什么**上，不落在**产品说的话
可不可信**上。

记在真实来源采用之前，是因为反过来不可逆：一旦让某个未认证 P1 进过一次正式候选，此后所有引用
该候选的判定都失去了"P1 已认证"这个前提，而已发布的投影与历史声明不能改写，只能并存。
