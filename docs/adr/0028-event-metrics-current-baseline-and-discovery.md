# 事件类指标以最近一次事件为现行基准，按事件发现而非按期检索

2026-09-24 用户选择（真实运行后缺失项排查的访谈）。首次真实运行中，公开市场操作利率与降准因“没有持有值就不建检索范围”一直未持有，已持有时也从不复查变化。

- **公开市场操作利率**：每轮完整运行与操作量合为同一检索范围，检索最新已发布交易日的公开市场公告，持有与否都查，查到即记新观测。当天没有操作或未写利率记“未找到”，已持有的利率继续生效；只有从未持有才列缺失。
- **降准**：以 TuShare 资讯为主，登记降准资讯规则（句中须写明生效日期；必取按适用范围的调整幅度，下调记负、上调记正，按生效日记期；顺带取调整后加权平均准备金率与释放资金，与官方解析器口径一致）。每轮在本轮资讯里监测；未命中记“本轮资讯未见降准公告”，沿用现行基准，不算缺失，也不再往后走官网、Tavily 或 AI。
- **现行基准**：两者都以最近一次为现行基准，生效至变更，不设有效期。原 `evidence_max_age_days`（370/730 天）从无调用方、从未生效，已删除；不另写过期判断（2026-09-24 用户选择）。
- **追溯发现**：从未持有降准时，以央行官网降准公告栏目为主，从目标月起往回翻，找到第一条即停，不设上限；官网取数失败时以 AI WebSearch 兜底（问截至目标日最近一次降准，候选须命中降准规则并带原话）。不用 Tavily，也不用 TuShare 资讯回拉。查完没有记“查过、没有”；来源出错或没查完才列检索未通过。

取舍：降准没有固定发布时点，按期检索只能搜一个不存在的“应有期”，既耗搜索预算又必然落空；资讯在央行公告后几分钟内就有原句，且不占预算。往回追溯只在从未持有时发生，实际上只跑一次。TuShare 资讯每天只能调用 40 次，按时间窗往回拉追不了多远，因此追溯走官网栏目。公开市场操作利率每天随操作公告给出，复查几乎不增加成本，却能在利率变动当天反映到 DR007 利差里。

本 ADR 补充 [ADR-0026](0026-news-and-media-values-by-family-extraction-rules.md)：事件类指标不走完整降级链，渠道以本 ADR 为准。
