# 宏观判断阶段为主结论，价格阶段作市场表象验证

2026-10-17 用户验收驾驶舱后提出：周期识别结论应由政策、信用、过热、物价、库存给出判断，因为它们是根本原因；债券、股票、商品、货币只是表象，作次要验证。经 `/grill-with-docs` 确认（决定记录 `.scratch/macro-stage-20261017/decisions.md`）。

决定：

- 新增**宏观判断阶段**：五个维度各由其关键指标汇总出一个方向，与随模型版本冻结的**宏观周期特征表**（六阶段 × 五维度应呈方向）比对，五维等权，最吻合者为宏观判断阶段；并列或证据不足时如实写明，不强行选一个。它是页面主结论。
- 三核心价格映射的阶段改称**价格阶段**（原"正式阶段"），规则不变（ADR-0001 的映射、非典型组合、上一确认阶段均保留），作为宏观判断的市场表象验证；两者不一致时明写偏离。宏观判断阶段不改写价格阶段与价格阶段史。
- 宏观判断阶段从新模型版本生效之日起每日记入阶段史（⑥ 新增一行）；生效前不倒推补算。
- 特征表冻结前，先在隔离副本上用历史宏观数据逐月回测（原型），检查跳变、并列频率与价格阶段的关系，结论写进规格。
- 确认度（ADR-0037）的预期表不用作判定：它为检验已知阶段叙事而设计，各阶段反证格数量不对称（如第五阶段政策、物价几乎无反证格、"无动作"记支持），直接套用会偏向反证格少的阶段；且 17 个关键指标等权计数会使五个维度分别占 5／3／5／3／1 票。

放弃的方案：把预期表对六阶段逐一计数取最高者（偏向反证格少的阶段）；让宏观直接改写价格阶段（B，需重做阶段史与上一确认阶段，且丢失价格周期本身的信息）；只调整展示顺序（C，未给出宏观判断）。

后果：需新模型版本（特征表、维度方向汇总、并列与不足规则）、投影新增宏观判断字段与价格验证关系、结论板与 ④ 改以宏观判断为主、AI 报告输入同步；旧项目审计列出的错误（未知当方向、阶段序号加权、领先信号直接 ±1、重复计入、强制打破并列、未校准百分比）不得重犯。
