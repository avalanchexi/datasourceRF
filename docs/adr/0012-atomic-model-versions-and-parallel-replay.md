# 模型升级采用原子版本、并行回放与限时逻辑回退

> 已被 [ADR-0022](0022-uniform-120-day-retention-and-processing-batches.md) 取代（2026-09-23）。

每个模型版本都是固定趋势规则、阶段映射、指标定义、来源认证与选源规则及派生公式的不可变清单；任何会改变分析规则或结果生成逻辑的变化都创建新版本。候选版本只在来源认证生效后的可认证区间生成并行版本回放，经质量、稳定性和回归验收并由用户显式批准后才原子成为唯一生效版本；发布历史、旧派生结果和报告快照永不覆盖。后来才认证的更早历史只可在通过口径与质量验收后用于离线校准和初始化预热，不生成认证前的正式版本回放。

模型回退只切换生效指针，不恢复数据库或删除较新结果。从新模型首次正式发布投影的目标交易日起，系统按中国交易日历含首日保证30个交易日内上一生效模型仍可直接运行；回退后的新模型恢复为候选状态并须重新验收。窗口结束后旧投影、报告、清单和验收记录继续可读，但不再保证旧模型可直接运行。这个边界以并行构建、可审计比较和有限兼容成本为交换，避免原地重算破坏历史，也避免永久维护所有历史运行时。
