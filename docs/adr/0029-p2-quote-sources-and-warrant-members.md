# P2 行情指标按来源性质分别处理，仓单按仓库合计成员

2026-09-25 用户选择（真实完整运行 run-f26f88cbd9e0681f397a 剩余缺口的取舍访谈）。三个 P2 日频行情指标只登记了网页检索，候选全为 `period_mismatch`：搜索不擅长给出“某日收盘值”，每轮白花预算。

- **USDCNY 16:30 在岸收盘价**：推翻 [官方缺口来源审计](../research/official-gap-source-audit.md) 7.2 节“无 CFETS 授权不自动持久化”的结论，按**可公开接入 P2** 处理。前提：本机个人使用、只取公开页面已公布的数值、不对外分发；前提变化时回到受限授权。时效放宽为滞后一个交易日（目标日 T 持有 T-1 即现行）。以中国货币网官方直连为主；找不到稳定的 16:30 收盘接口时退回资讯规则，只认明写“16:30”的句式——中国货币网另有 03:00 夜盘收盘，“即期收盘价”不写时点的句子不取。
- **VIX**：以 Cboe 官网数据为注册来源（不限定格式，现有日历史 CSV 自 1990 年起），不再检索。滞后按实测更新时刻登记（2026-09-25 北京时间下午官网最新仅到 9/22）。
- **SOX**：按**受限授权 P2** 处理，透明缺口，不检索。Nasdaq 官网背后的行情接口可用但无公开文档、需浏览器请求头，自动抓取是否合规不明；取得授权或正式接口后再登记。
- **期货仓单**：TuShare `fut_wsr` 丢了交易所日报在仓库之下的产地、年度等分列，同一仓库一天可有多行，甚至全字段相同（郑棉 2026-09-24：163 行、22 个仓库多行）。成员为“日期＋品种＋仓库＋交易所”，多行求和为该仓库合计；同一仓库当日 `vol_chg` 之和与前一交易日仓库合计之差不等时，在回执中记注记（成员、当日与前日合计、变动之和），不拒收。
  - **2026-09-25 修订（用户选择）**：原定“不等即拒收”。实施时取郑棉 9/16–9/24 真实数据核对：6 个交易日中 2 天有仓库对不上（每天 24 个仓库中 1–2 个），整批拒收会让棉花仍长期缺数。同日核对郑商所官网仓单日报（`FutureDataWhsheet.txt`/`.xlsx` 可直接取，只有 `.htm` 有反爬挑战）：9/24 官网总计 7463 张、当日增减 −105，TuShare 合计 7372 张、−105；TuShare 漏了部分分列行，24 个仓库中 7 个合计偏低（最大为豫棉物流 538 对 492），增减全部一致。用户选择仍用 TuShare 求和、对不上只记注记；官网日报作为更权威口径留待以后接入。

取舍：USDCNY 的授权条款是 CFETS 对数据使用的限制，个人本机研究不对外分发，用户接受这一风险换取汇率背景完整；SOX 没有可依法确认的免费渠道，照受限授权处理比依赖未公开接口更稳。仓单若维持“多行即拒收”，棉花会长期缺数；按仓库合计与下游按仓库对账的结构一致。已知代价：TuShare 合计可能偏低（见上），注记让对不上的仓库-日期可追溯。

本 ADR 部分取代 [ADR-0023](0023-retrieval-verification-by-registered-parsers.md) 中这三个 P2 指标的检索渠道。
