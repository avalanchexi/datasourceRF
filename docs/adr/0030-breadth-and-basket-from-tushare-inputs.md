# 广度与商品篮子只用 TuShare 自动取得的输入

2026-09-25 用户选择（缺口取舍票 [08](../../.scratch/gap-sources-20260925/issues/08-breadth-basket-input-contract.md)）。生效目录 `metric-catalog-v0004` 登记的广度 v0002 与篮子 `ex-hog-calendar-settlement-v0002` 契约要求人工审阅的输入包：历史成员池、复权参考价事件（`official-reference-ratio`）、成交额覆盖规则、期货交易时段与发布时间证据。运行库里没有任何流程产出这些包，Worker 仍产出旧 v0001 的统一广度和收盘价篮子，入库时被契约拒收，7 项长期缺数。

**广度**（仍为 P1 背景指标，不接入卡片计算）：

- 成员：沪深北全部普通 A 股，含北交所、含 ST，排除 B 股与 CDR；按 `stock_basic` 的 L/D/P 三种状态重建上市区间，全市场接口分页取全。
- 日涨跌：`daily` 的 `close` 与 `pre_close` 直接比较，新股首日也计入；停牌或成交量为 0 的不参与。
- 窗口指标：取消 120 日两项，改为 90 日与 250 日新高新低（`stk_factor_pro` 的 `topdays`/`lowdays` ≥ N）、站上 MA90 与 MA250（前复权收盘价严格大于对应均线）。分母为当天有交易、上市满 N 个交易日、因子不为空的股票。
- 成交额占比：分子分母都只用 `daily.amount`（竞价成交额），不计盘后固定价格交易与大宗交易。
- 取数：每个交易日 `daily` 与 `stk_factor_pro` 各一次；首次初始化 120 天约 240 次，之后只取新交易日，不需要回看。

**商品篮子**：

- 不再需要交易时段证据。选合约只用前一个交易日收盘时已知的信息（`fut_basic`、`fut_trade_cal`），v0002 的日历选月规则不变。
- 固定基日仍为 2026-03-06、基值 1000。每天在上一日已有的指数水平上乘以当日收益；上一日水平缺失时，临时从基日重建整条链，只算不入库。
- 篮子与袖套不接入价格压力卡（更正规格“价格压力卡片有数”的说法）。

**版本与代码**：登记新目录 `metric-catalog-v0005` 与新模型 `model-v0013`，以 `model-activate` 切换生效。新目录生效后删除 v0002 的官方参考价比例调整链、成交额覆盖规则校验与审阅材料载入代码，以及 v0001 的统一广度与收盘价篮子计算（没有生效目录在用），连同只为它们存在的测试。

取舍：审阅包的初衷是成员完整、窗口共同、价格精确与金额范围可证明，但它依赖逐项人工材料，与 [ADR-0021](0021-registered-sources-freshness-replaces-certification.md) 的“注册来源只做结构校验”不一致，也正是 7 项一直缺数的原因。接受的代价：前复权与技术因子由 TuShare 计算，口径以其文档为准；成交额不含盘后固定价格与大宗交易；120 日窗口指标不再提供。

本 ADR 取代 v0002 广度与篮子契约中对审阅输入与交易时段证据的要求（原见 `.scratch/pring-data-acquisition-repair/issues/08–10`）。
