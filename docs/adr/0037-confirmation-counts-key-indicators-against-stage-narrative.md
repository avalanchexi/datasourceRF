# 确认度：按关键指标计数的阶段叙事确认

2026-10-06 用户经 `/grill-with-docs` 逐题确认（[宏观语义与确认度](../../.scratch/macro-semantics-20261006/README.md)）。依据：[旧项目审计](../research/legacy-pring-model-audit.md)、[普林格指标需求](../research/pring-indicator-requirements.md)、[缺失指标可得性](../research/pring-missing-indicator-availability.md)、[供需可区分性](../research/commodity-supply-demand-separability.md)。

正式阶段仍只由三个核心价格机械决定（[ADR-0001](0001-price-only-formal-pring-stage.md)）。用户需要一个说明"这个阶段的经济叙事有多少证据支持"的量。旧项目的"置信度 71%"是 90% 起分、按宏观一致性、阶段序号融合与 DR007 平移层层扣减的规则分：中性被当熊、商品看多不可达、同一信息反复计入，35 次历史结果的最终阶段全部偏离三资产映射，没有任何统计校验。本项目不沿用它。

决定：

- **确认度**是当前正式阶段典型经济叙事获得多少证据支持的**计数**，不是阶段正确的概率、预测概率或投资胜率；不影响阶段、不阻止发布、不改写阶段史；非典型组合时不适用。
- **以关键指标为计数单位**：PMI、社融、GDP、工业增加值、CPI、PPI、M1/M2、DR007、LPR、降准等各自给出读法与确认关系，等权计数；政策、信用、过热、物价、库存五个维度只分组与汇总。库存例外：由需求、生产、库存三条线联合推断的库存象限作为一项计数。派生值（PMI 差值、信用脉冲、M1−M2、DR007 政策利差、实际库存近似）不单独计数；同一次发布出新数据前不重复计数。
- **四种确认关系**：支持、反证、仅观察（不计数）、未确认（不计数）。关键指标先列全部成员的一致与分化，再由预先指定的主要成员给意见；有成员与主要成员相反即为分化，不高于仅观察。
- **方向读法**：水平、动量，月度关键指标加斜率变化；方向不明一律未确认，持平不支持"缓和"。
- **指标时序**：先行、同步、滞后；滞后未转或先行已转记仅观察并作转折提示，超过宽限（月度 2 期、季度 1 期）才记反证。
- **信号成熟度**：转折信号分萌芽、成形、确认三级，全部由指标判定；只有确认才计数。
- **预期表**（六阶段 × 关键指标，每格支持／反证／仅观察条件）与关键指标清单、主要成员、读法、时序随模型版本冻结。底稿见 [expectation-table.md](../../.scratch/macro-semantics-20261006/expectation-table.md)、[key-indicators.md](../../.scratch/macro-semantics-20261006/key-indicators.md)。
- **同源证据不确认阶段**：与核心同类的价格（债券类 930916、中债 030；股票类中证指数、广度、估值、融资；商品类 NHCI、篮子、WTI、Brent）作为观察接口挂在核心下，不计数；三核心相对动量与股市广度构成价格内部一致性，检查阶段在周期中的位置与转折时机，不计数；债券归因用政策与增长通胀两轴解释债券趋势的推动力，不计数，不由宽松程度推算债券牛熊。
- **退役四个单一维度标签**：政策方向、信用响应、过热状态、物价压力改为维度汇总（组内关键指标读法加确认关系计数）；库存象限保留并按新规则推断。原标签存在不可达状态（`overheated`）、未知被判中性或缓和、升温降温标准不对称等缺陷。
- **商品上涨或下跌的供需属性**只作需求一致性检验与供给嫌疑附注；现有数据不能确认推动力。

放弃的方案：旧项目置信度公式与固定阈值权重；按维度投票或全部成员同向才算一致；用货币宽松度推算债券牛熊；在没有指标依据时设"政策暗示"级；把同类价格或相对动量计为独立确认。

后果：宏观与库存的页面和 AI 报告输入改读维度汇总与确认关系；预期表需在新模型版本中实现并冻结；缺失指标（收益率曲线、信用利差、社零、EIA 收支等）接入后，相应"仅观察／未确认"格按新模型版本升级。
