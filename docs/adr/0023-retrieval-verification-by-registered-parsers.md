# 检索结果只从注册白名单来源取值，P0/P1 由登记解析器解析

2026-09-23 用户选择：降级链为 TuShare → 注册官方直连 → Tavily → AI WebSearch，**Exa 只在 Tavily 月度限额耗尽后顶替 Tavily**。搜索渠道只是到达注册白名单来源页面的传输手段：P0/P1 按网址重抓原文、由登记解析器解析，搜索渠道给出的数值不采用，且与解析值在小数位数或时效上差异明显时不采纳；P2 可接受 Tavily/AI 从白名单页面抽取的数值并保存原文，AI WebSearch 对 P2 放开。页面须有发布日期且统计期不早于应有期；公开可用时间与注册来源同式。不通过即记检索证据缺口并以“检索未通过”向用户列出候选网址与原因。预算取消每日硬上限：Tavily 16、Exa 8 次／每次运行，AI WebSearch 不设次数上限但每个缺口每次运行至多一次。

取舍：放弃“与注册源交叉核对、容差内即可”的第二条准确性路径——走到搜索时注册源本期已缺值，没有同期值可核对，只会引入通用抽取器与逐指标容差的维护负担。白名单与解析器同在代码常量中按家族登记、随代码版本变化。三核心为此须新写中证指数官网与南华官网解析器。细节见[WebSearch 验证规则](../../.scratch/pring-fast-refactor-20260923/issues/05-websearch-verification-rule.md)。

本 ADR 取代 [ADR-0005](0005-cost-aware-evidence-retrieval.md)。
