# AI 报告只接收已验证结果，不再引用证据链

2026-09-24 用户选择（首次真实运行后的报告二期访谈）：AI 报告的输入只包含已验证结果，每项三样：结果值、数据来源、是否有异常（核心沿用、缺口、落后、冲突）。上下文证据、逐条证据行、观测序列与证据编号一律不交给 AI，报告也不再逐段引用证据或反证。追溯由分析投影与加工批次承担，不由报告承担。生成后只校验两点：AI 没有改写正式阶段、核心状态和宏观/库存结论；输出符合固定结构。单适配器超时保持 300 秒，Codex 首选、Claude 备用、两路失败回落确定性报告的做法不变。

取舍：首次真实运行的证据包约 14.6 万字节，其中逐观测证据 ID 与允许引用清单占去一大块；Codex 与 Claude 各跑满 300 秒，都没有任何输出。放宽超时只会拉长每日运行，未必成功。报告的价值在于解释结论，逐条引用的校验成本和提示体积都远大于它带来的可信度；证据的可信度已由三道门与检索验证在入库时保证。放弃的是“报告中每个关键事实都能直接点回证据”，数据来源名称仍保留在报告里。

本 ADR 部分取代 [ADR-0003](0003-ai-explains-but-does-not-classify.md)：“每个关键事实必须关联指标或来源”改为只关联数据来源；AI 只解释、不参与分类、不改写正式阶段的原则不变。本 ADR 同时部分取代 [ADR-0009](0009-cli-only-evidence-report-adapters.md)：“逐段绑定支持证据与反证”以及引用语义的后置校验取消，确定性事实骨架不再包含证据引用；CLI-only 适配器、双适配器降级、300 秒超时与快照审计不变。
