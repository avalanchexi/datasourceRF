# 观测身份按相同定义认，不按目录版本号

2026-10-02 用户选择（[真实运行发现 02](../../.scratch/run-findings-20261002/issues/02-catalog-switch-hides-unchanged-claims.md)）。模型 v0014 只改了信用脉冲的单位，却把目录升为 v0006 并给全部 61 个指标换上新版本号；读取按版本号严格相等，观测编号也把版本号算进哈希，v0005 下取得的来源声明对 v0014 全部不可见。后果是 OMO 利率失去沿用基准、DR007 政策利差算不出，广度、商品篮子、郑商所仓单整窗重取（运行 57 分钟，基线约 10 分钟）。v0012→v0013 切换时广度也这样重取过。

决定：

- **相同定义**：同一指标在两个目录版本中，单位（含允许单位）、频率、维度、来源代码都相同，派生指标的公式版本也相同，即为相同定义。中文名、优先级、角色、候选网址、认证状态、发布规则不参与比较——它们不改变数值含义。按此规则，v0012→v0013 只隔离来源代码变了的广度与篮子，v0013→v0014 只隔离信用脉冲。
- **可见范围**：相同定义下取得的来源声明，在任一使用该定义的模型中都可见，不限先后（回退到旧模型时也能看见新取得的），只受留存期约束。
- **同一统计期新旧版本值不一致**：版本号不产生新的经济事实，按来源区分——同一来源是修订，按 [ADR-0022](0022-uniform-120-day-retention-and-processing-batches.md) 取最新；跨来源照常按 [ADR-0033](0033-cross-source-values-compatible-within-half-percent.md) 判相容或冲突。
- **读取时归并，不改写存储**：库中已存的观测编号不动；读取、选值、冲突、原件复核、入库查重、已持有日判断都把相同定义的各版本视为一组，按指标＋统计期＋维度归为同一观测。观测编号从此只是存储键，不等于观测身份。
- **已发布历史不重算**：规则只影响之后的运行。

放弃的方案：新模型清单显式声明哪些指标沿用（每次都要记得写，漏写就重演本次问题）；只给变化的指标升版本、目录版本只作集合标签（更干净，但要改清单结构与观测身份规则，影响面最大）；把观测编号改成定义指纹并重算全部已存声明（批量改写不可变的来源声明）。
