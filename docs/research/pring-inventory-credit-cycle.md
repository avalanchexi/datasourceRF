# Pring 六阶段、库存周期与中国货币/信贷周期：证据边界与系统建议

> 研究日期：2026-08-20  
> 研究问题：面向中国市场的约 120 交易日中期趋势系统，Pring 六阶段与库存周期、货币/信贷周期之间，哪些关系可由原始或权威资料支持？  
> 结论性质：研究输入，不是投资建议，也不是已经验证的模型规格。

## 结论摘要

1. **Pring 六阶段的公开定义很窄而且明确**：它首先是债券、股票、商品三类资产各自处于牛/熊趋势时的六种顺序组合，不是“库存 + 信贷 + 若干宏观指标”的加权总分。公开定义为：阶段 1 `债牛/股熊/商品熊`，阶段 2 `债牛/股牛/商品熊`，阶段 3 `三者皆牛`；阶段 4～6 依次反转为 `债熊/股牛/商品牛`、`债熊/股熊/商品牛`、`三者皆熊`。[Pring Turner 官方说明](https://www.pringturner.com/pring-turner-approach-to-business-cycle-investing/)
2. **无法从公开资料复刻 Pring Research 的实际识别器**：官方明确称三类资产的 barometer 由专有的技术与跨市场关系构成。新项目若自行使用 30/120 日收益率、均线、斜率或权重，只能称为“Pring 六阶段框架下的自有 barometer”或“Pring-inspired”，不能称为 Pring 原模型复刻。
3. **库存、货币与信贷有充分理由成为独立驱动层**。经典库存研究支持“销售预期偏差—库存偏离目标—生产调整—经济波动”的机制；货币/信贷研究支持金融条件与经济增长、金融稳定存在阶段性关系。但现有原始资料**不支持**把某个中国库存四象限或某组 M1/M2/社融权重一一映射到 Pring 六阶段。
4. **“约 120 个交易日”是本项目的中期观测窗口，不是 Pring 或 Kitchin 文献给出的常数**。TuShare 提供按日期范围获取日线的接口；30 日、120 日变化及技术特征应由系统从日序列派生，而不是误称为 TuShare 的两种聚合数据。
5. 推荐最终同时输出三个独立对象：`Pring 市场阶段`、`库存周期状态`、`货币/信贷状态`，再输出它们的**一致/冲突关系和置信度**。这比把所有指标压成一个分数更容易定位“改版后不准确”的根因。

## 一、三套概念必须分开

### 1. Martin Pring 的六阶段模型

Pring Turner 把一个典型商业周期描述为三类资产各有一个底部和一个顶部，共六个转折点；阶段从经济放缓、债券价格筑底开始，直至商品价格见顶。[官方 PDF](https://www.pringturner.com/wp-content/uploads/2016/01/Pring-Turner-Approach-to-Business-Cycle-Investing.pdf) 给出的公开状态表如下：

| 阶段 | 债券 | 股票 | 商品 | 公开定义所表达的市场顺序 |
| --- | --- | --- | --- | --- |
| 1 | 牛 | 熊 | 熊 | 债券先转强 |
| 2 | 牛 | 牛 | 熊 | 股票随后转强 |
| 3 | 牛 | 牛 | 牛 | 商品最后转强 |
| 4 | 熊 | 牛 | 牛 | 债券先转弱 |
| 5 | 熊 | 熊 | 牛 | 股票随后转弱 |
| 6 | 熊 | 熊 | 熊 | 商品最后转弱 |

可证实的限制同样重要：

- 官方说阶段长度并不相等，只是“多数时候”按顺序移动。
- 一个实际周期可能跳过阶段、倒退到上一阶段，因而不能用“只准顺时针”的硬状态机掩盖数据冲突。
- 实际 barometer 的组件和阈值是专有的；公开资料只说明组件多数为买入信号时该资产为 bullish，多数为卖出信号时为 bearish。
- [Wiley 对 Pring 1992 年原著《The All-Season Investor》的书目页](https://www.wiley-vch.de/en/areas-interest/finance-economics-law/the-all-season-investor-978-0-471-54977-2) 可核实原著和章节主题，但并未公开可复现的算法参数。

因此，项目应该分别记录 `framework = pring_six_stage` 与 `barometer_method = <项目自有版本>`，不能让“六阶段名称”掩盖识别算法已被改成自定义权重这一事实。

### 2. 经典库存周期文献

[Joseph Kitchin 1923 年原论文](https://doi.org/10.2307/1927031)研究的是英美经济因素中的约 40 个月短周期。仅凭这篇原论文，**不能**推出今天常见的“PPI 同比 × 产成品存货同比四象限”就是 Kitchin 的原始模型。

库存作用于经济波动的更直接原始证据来自后续库存研究：

- [Abramovitz 的 NBER 专著（1950）](https://www.nber.org/books-and-chapters/inventories-and-business-cycles-special-reference-manufacturers-inventories)发现库存对经营活动变化调整缓慢，库存积累速度与经营活动大致同时到达峰谷，并且商业周期中总产出变化的很大一部分表现为用于增加库存的产出变化。
- [Blinder 的 NBER 模型（1980）](https://www.nber.org/papers/w0460)明确区分生产与最终销售，并让库存水平反向影响生产；其模型说明库存水平、库存变化、产出之间的相关方向并不等同，不能只看一个库存同比数值就断言经济阶段。
- [Ramey 与 West 的 NBER 综述（1997）](https://www.nber.org/papers/w6315)记录了库存的顺周期性和持续性，但也明确指出，对库存行为的生产成本冲击、生产调整成本和加速器动机等解释尚未形成唯一共识。

可证实的机制是：需求或销售偏离预期会使库存偏离企业目标，企业随后调整订货和生产，这种滞后调整能够传播或放大经济波动。不能由这些资料直接推出的是：一个固定的中国库存四阶段、固定时滞、固定指标权重，以及库存阶段与 Pring 阶段的一一对应。

### 3. 中国货币/信贷周期与官方统计口径

货币、信贷和金融周期不是同义词：

- 货币量反映货币存量。[中国人民银行当前口径](https://www.pbc.gov.cn/rmyh/109339/2025080818580470423/index.html)中，M1 包括 M0、单位和个人活期存款、非银行支付机构客户备付金；M2 再加入单位和个人定期存款及其他存款。M1 从 2025 年 1 月起采用新口径，因此跨口径历史比较必须使用可比回溯数据，不能直接拼接旧值。[口径修订公告](https://www.pbc.gov.cn/chubanwu/fileDir/resource/cms/2025/06/2025062416082199683.pdf)
- 社会融资规模增量是一定时期内实体经济从金融体系获得的资金额；存量是期末余额。人民银行表格同时记录了政府债券、企业资产支持证券等历史纳入口径变化，说明长样本必须保存口径版本。[社融增量定义与变更](https://www.pbc.gov.cn/diaochatongjisi/attachDir/2025/11/2025110417000975309.pdf)、[社融存量定义与变更](https://www.pbc.gov.cn/diaochatongjisi/attachDir/2025/11/2025110511314347909.pdf)
- 人民银行工作论文可作为研究证据，但不能当作官方政策结论。例如[陈雨露、马勇、阮卓阳（2016）](https://www.pbc.gov.cn/yanjiuju/fileDir/resource/cms/2016/04/2016040818085153098.pdf)使用私人部门信贷/GDP 测度金融周期，对 68 个经济体的面板研究发现，金融高涨期和衰退期均与较低增长和较高金融危机概率相关；论文本身明确声明只代表作者观点。它支持“信贷状态会影响宏观环境与风险”，不支持“社融上升必然对应某个 Pring 阶段”。

## 二、中国库存数据能说明什么

国家统计局的定义决定了指标不能混用：

- [产成品存货](https://www.stats.gov.cn/sj/zxfbhjd/202606/t20260627_1964019.html)是企业已完成全部生产过程并验收入库、可销售的产品；产成品存货周转天数则是库存与营业成本的比率型指标。前者是名义余额，后者更接近库存压力，二者含义不同。
- 规模以上工业企业范围每年会调整，官方同比增速按可比口径计算；当前报告值与上一年发布的名义历史值可能不可直接计算同比。因此应优先使用官方发布的可比同比，不要无条件用两个余额自行重算。
- [PPI](https://www.stats.gov.cn/zs/tjws/tjzb/202301/t20230101_1903637.html)反映工业品第一次出售时的出厂价格总体变化，也可辅助监测通胀/通缩；它是价格指标，不是实物需求或库存数量本身。
- [制造业 PMI](https://www.stats.gov.cn/zs/tjws/zytjzbqs/cgzlzs/202501/t20250121_1958396.html)是经季节调整的月度环比扩散指数。新订单、生产、产成品库存、原材料库存是不同分类指数；50 附近表达扩张/收缩扩散程度，不等于同比增速。

由此可得到一个**待验证的项目操作化方案**，但不能把它写成“经典理论事实”：

- 库存状态至少同时观察需求（PMI 新订单）、生产（PMI 生产或工业增加值）、价格（PPI 环比/同比）、库存（产成品存货可比同比、库存周转天数、PMI 产成品/原材料库存）。
- 常见的“PPI 方向 × 产成品存货方向”四象限只能作为候选摘要。PPI 是名义价格，库存余额也受价格影响；应增加库存周转天数和 PMI 库存作交叉验证。
- 月度数据在发布日期之后才可进入模型。所属月份不是可用日期；例如三月数据在四月发布，就只能从四月实际发布时间起影响阶段判断。

## 三、Pring、库存与信贷的关系：证据与假设

### 可由资料支持的关系

1. Pring 模型的观察对象是三类金融市场的主要趋势，三类市场通常存在先后转折顺序，但并非每轮都完整或严格有序。
2. 库存偏离目标后引发的生产调整能够传播经济波动；库存积累与生产、销售的关系需要多个指标共同辨别。
3. 货币与信贷条件通过融资数量、价格和金融中介行为影响实体经济；金融周期过热与过冷都可能带来风险。
4. PPI、工业库存、PMI、M1/M2、社融都具有明确但彼此不同的官方统计口径，适合用于解释中国市场背景。

### 只能作为待检验机制假说的关系

以下因果链条在经济逻辑上合理，但**不能直接冒充已有资料结论**：

`货币/信贷条件变化 → 融资成本和可得性变化 → 需求/投资变化 → 销售预期误差与库存调整 → 生产、利润与价格变化 → 债券/股票/商品市场依次重估`

系统可以用历史数据检验每一条边的方向、时滞和稳定性，却不能预先写死为六阶段映射。中国的政策调控、债券市场结构、股票风险溢价、期货品种和房地产信用占比都可能使三类资产跳阶段或逆序。

### 不能由资料推出的假设清单

- 120 个交易日是 Pring 或 Kitchin 的理论周期。
- PPI 同比和产成品存货同比的四象限就是 Kitchin 原始模型。
- 某个库存阶段必然等于某个 Pring 阶段。
- M1、M2、社融或贷款同比对 Pring 阶段有固定领先月数或固定权重。
- 新增指标越多，识别准确率一定越高。
- 公开资料足以复刻 Pring Research 的专有 barometer。
- 数据缺失时，Codex/Claude 的 Web Search 找到的新闻数值可以无条件替代官方时间序列。
- 旧项目中的任何自定义权重、修正规则或提示词来自上述理论；它们必须被视为待审计的项目实现。

## 四、推荐的指标分层

| 层级 | 职责 | 推荐指标/产物 | 是否能直接改变 Pring 阶段 |
| --- | --- | --- | --- |
| 核心层：市场 barometer | 保持 Pring 六阶段语义 | 中国债券总回报代理、宽基股票总回报代理、宽基商品/期货指数；从完整日序列派生 30/120 日收益、趋势斜率、波动、回撤、趋势转折 | 是，但只通过三类资产各自的牛/熊/不确定状态 |
| 确认层 A：库存 | 判断需求—生产—库存—价格是否相互验证 | PMI 新订单、生产、产成品/原材料库存；工业增加值；产成品存货官方可比同比与周转天数；PPI 环比/同比 | 否；影响置信度、候选阶段和根因解释 |
| 确认层 B：货币/信贷 | 判断资金数量、价格与传导 | M1/M2 可比增速；社融存量同比与增量；人民币贷款；政策利率、DR007/Shibor、LPR、国债收益率；必要时区分企业中长期信贷 | 否；影响置信度、候选阶段和根因解释 |
| 解释层 | 回答“为什么变化、证据来自哪里” | 官方发布稿、政策文件、数据异常说明，以及 Codex CLI 或 Claude Code CLI 生成的带引用叙述 | 否；禁止改写原始值和确定性信号 |
| 展示层 | 向个人用户呈现可核验结果 | 阶段、置信度、冲突、数据新鲜度、版本和变更原因 | 否 |

建议给三个引擎不同名称：

- `PringMarketStage`：仅由债券、股票、商品 barometer 产生。
- `InventoryCycleState`：项目自定义、经回测验证的中国库存状态。
- `CreditCycleState`：项目自定义、经回测验证的货币/信贷状态。

最终产品状态可以是 `ChinaMediumTermRegime`，其值包含三者，而不是把三者混成一个无法追溯的总分。若库存与信贷共同指向扩张、Pring 却转弱，应展示“宏观驱动与市场定价背离”，而不是静默覆盖某一方。

### 核心 barometer 的实现约束

- 债券使用**价格/总回报**方向；若数据源只有收益率，必须显式反号并标记为收益率代理，避免“收益率上涨”被误判为“债券牛市”。
- 股票优先使用宽基总回报指数，避免单一行业或价格指数分红缺失改变长期趋势。
- 商品优先使用规则稳定的宽基商品指数；若由期货合成，必须冻结主力/连续合约换月规则，并展示换月影响。
- 30/120 日只是候选快慢窗口。阈值、平滑、滞回区间和最短持续期应在训练段确定，再在时间外样本验证。
- 允许 `uncertain` 或候选阶段。把临界值强制二值化通常会制造日间反复跳段。

## 五、TuShare 能力边界

TuShare 可作为统一访问层，但接口事实与理论判断要分开：

- [指数日线 `index_daily`](https://tushare.pro/document/1?doc_id=95)和[期货日线 `fut_daily`](https://tushare.pro/document/2?doc_id=138)均支持 `start_date/end_date` 范围查询。它们提供日序列，并没有定义“30 日趋势”或“120 日趋势”；窗口收益、均线和斜率由本项目派生。
- [A 股月线 `monthly`](https://tushare.pro/document/2?doc_id=145)是市场行情月线，不能与宏观月度发布混为一谈。
- [PMI `cn_pmi`](https://www.tushare.pro/document/41?doc_id=325)是宏观月度接口。其他 M1/M2、社融、PPI 接口也只能证明 TuShare 能提供相应字段，最终语义以人民银行和国家统计局口径为准。
- 应保存 `provider=tushare` 与 `upstream_authority` 两个字段。首次使用和口径变更时，与官方发布交叉核对。
- 本研究不读取也不需要读取任何 token。生产实现应从环境变量或密钥存储注入，不能写进仓库、日志、提示词或 Web 页面。

数据缺失时，Codex CLI 与 Claude Code CLI 可以相互替代执行 Web Search，但必须共享相同的结构化输出契约。搜索结果只能成为：

1. 指向官方发布页的备用取数证据；或
2. 标有来源、发布时间和低等级可信度的解释材料。

若找不到同口径官方数值，核心模型应保留缺失并降低置信度/暂不判定，不能从媒体描述猜一个数字填入历史序列。

## 六、无前视偏差的阶段“真值”与评估

### 1. 先承认没有唯一官方真值

Pring 阶段是由市场 barometer 定义的隐状态，中国也没有一个官方机构每日公布可供监督学习的 Pring 阶段。因此必须把三种“真值”分开：

- **实现真值**：固定版本规则在当时可用数据上计算出的阶段。用于单元测试、回归测试和新旧版本对比。
- **事后周期基准**：使用完整历史和双边滤波识别的宏观峰谷。只能评价转折延迟，不能作为实时输入。
- **结果检验**：阶段出现后 20/60/120 交易日三类资产的收益、回撤和相对排名。未来收益只能用于评价，不能反过来生成当日标签。

一个有用的警示来自上述人民银行工作论文：其金融周期峰谷定义会比较 `t-1` 和 `t+1`，因此天然包含未来一期信息。这样的标签适合作为事后研究基准，不适合作为在线真值。

### 2. 建立 point-in-time 数据账本

每条数据至少保存：

```text
indicator_id
observation_period       # 数据所属日/月
release_at               # 官方首次发布时间
available_at             # 本系统实际可用时间
fetched_at
value
vintage_id               # 首发/修订版本
provider
upstream_authority
source_url
unit
frequency
quality_status           # official / verified-fallback / explanatory-only
```

回放任意时点 `T` 时，只允许 `available_at <= T` 的当时版本进入模型。国家统计局的[年度发布日程](https://www.stats.gov.cn/xw/tjxw/tzgg/202512/t20251224_1962137.html)还说明数据发布库可能在新闻发布后约三个工作日才更新，因此应以实际首次可取得时间为准，而不是只存月份。

市场日线也要遵守时点：收盘数据只能在收盘并完成数据源更新后使用；节假日、停牌、夜盘、期货交易日归属和连续合约换月不得用后来才知道的信息回填。

### 3. 推荐评估流程

1. 冻结资产代理、派生公式、阈值、最短持续期、缺失规则和模型版本。
2. 按时间顺序划分开发期、验证期、完全未见测试期；使用 walk-forward，不做随机切分。
3. 每个历史日从 point-in-time 快照重放，月度指标在实际发布后阶梯式生效。
4. 新旧模型并行输出，不让新版标签覆盖旧版历史；保留每日差异原因。
5. 指标至少包括：数据覆盖率、暂不判定率、阶段平均持续期、短期反复跳段率、跳阶段/倒退次数、转折检测延迟、阶段置信度校准、20/60/120 日资产收益与最大回撤、三类资产相对排名、宏观数据修订导致的标签变更率。
6. 120 日前瞻窗口彼此高度重叠，统计显著性要使用时间序列稳健方法或非重叠子样本，不能把每个交易日当独立样本夸大样本量。
7. 先用多个完整周期验证，再决定库存/信贷指标是否有资格从“解释”升级为“确认”；只有跨时期稳定改善结果的指标才能进入更高层。

## 七、Web 页面必须暴露的可解释性字段

首页不应只显示一个大号“阶段 N”。建议至少显示：

| 区域 | 字段 |
| --- | --- |
| 总览 | `as_of`、Pring 当前阶段、候选阶段、置信度、状态持续天数、上次变化时间、是否暂不判定 |
| 三类核心资产 | 代理名称与代码、牛/熊/不确定、30/120 日收益、趋势分数、关键阈值距离、最近转折日、数据更新时间、来源 |
| 库存驱动 | 当前自定义库存状态、需求/生产/价格/库存四组证据、最新月与上期/同比/环比、发布日期、冲突项 |
| 信贷驱动 | 当前自定义信贷状态、数量/价格/传导三组证据、M1 口径版本、社融口径版本、发布日期、冲突项 |
| 联合判断 | 三引擎一致/背离矩阵、置信度加减原因、不可用指标、备用来源、为何没有强制输出 |
| 变化解释 | “较上一报告为什么变了”：新数据、数值修订、市场越阈值、代理换月、代码/参数版本变化分别列出 |
| 可复现性 | `data_snapshot_id`、`model_version`、参数版本、规则哈希、生成时间、使用的 CLI（Codex 或 Claude）、提示词/输出 schema 版本 |
| 证据 | 每个事实的官方链接；AI 搜索内容明确标 `explanatory-only`，禁止与原始指标混排 |

推荐允许从总阶段逐层下钻到 `阶段 → 三类 barometer → 原始数据 → 来源/版本`。这样才能在 Pring 识别“不准确”时回答：是数据缺失、资产代理改变、债券符号弄反、期货换月、阈值漂移、宏观口径变化，还是 AI 叙述与确定性结果不一致。

## 八、对下一轮规格讨论的直接建议

在实现前需要形成可回答的决策清单：

1. 中国债券、股票、商品分别选哪个**可长期回放**的代表性总回报/宽基代理？
2. 旧版与改版分别如何把日线转为 bullish/bearish？先做逐行公式审计，不能只比较最终阶段。
3. `uncertain`、滞回和最短持续期如何定义？
4. 库存引擎的“需求、生产、价格、库存”各选哪些官方指标，谁只是展示？
5. 货币/信贷引擎如何区分总量、价格、结构与政策信号？
6. 缺失时 Web Search 的官方来源白名单、解析 schema、置信度降级和人工复核条件是什么？
7. 以哪一段历史为完全未见测试期，新旧模型的成功标准是什么？

在这些决策完成前，最稳妥的产品输出是三层并列与冲突说明，而不是继续扩充一个混合权重表。
