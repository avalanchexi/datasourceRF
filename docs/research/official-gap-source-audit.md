# Pring 周期驾驶舱 V1 官方缺口数据源审计

> 研究日期：2026-08-20  
> 范围：央行政策行动、核心 CPI、工业增加值／利润／库存／产能、信用结构、官方在岸人民币汇率。  
> 证据边界：仅使用中国人民银行、国家统计局、中国外汇交易中心／中国货币网的一手页面、附件和规范；未读取或使用任何 token、API key 或 `.env`。

## 1. 结论

TuShare 的这些缺口不需要统一诉诸搜索服务。人民银行和国家统计局公开的 HTML、XLS/XLSX 与 PDF 足以承担 V1 的主要官方直连；搜索只应在官方栏目改版、正式发布未按期出现或解析失败时发现新的官方 URL，不能替代固定适配器。

| 缺口 | V1 结论 | 首选一手来源 | 关键边界 |
| --- | --- | --- | --- |
| 央行 7 天逆回购与政策利率 | **V1 可自动接入** | 人民银行公开市场业务交易公告 | 每次操作是事件；不得把 DR007 当政策行动。历史公告格式变化，回填需版本化解析 |
| 降准 | **V1 当前事件可接入，历史需人工核验** | 人民银行降准公告／文告 | 必须分别保存公告时点和生效日；定向降准不能压成单一全市场百分点 |
| 各工具净投放 | **V1 可接入月度官方总表；更早全工具历史暂缺** | 人民银行“中央银行各项工具操作情况” | 该月表自 2025 年 6 月起新增；更早数据不能用单一逆回购净额冒充全工具净投放 |
| 核心 CPI | **V1 可自动接入，历史回填需抽检** | 国家统计局 CPI 正式发布 HTML／XLSX | 2013 年开始正式发布；当前表同时给环比、同比和年内平均，旧档案版式变化需版本化解析 |
| 工业增加值 | **V1 可自动接入** | 国家统计局工业生产正式发布及 XLSX | 同比是扣除价格因素的实际增速；环比会随季调模型滚动修订 |
| 工业利润 | **V1 可自动接入累计口径；单月增速为可选字段** | 国家统计局工业企业利润正式发布及 XLSX | 正式表以年内累计为主，单月同比常在正文；不得把累计值伪装成单月值 |
| 工业库存 | **V1 可自动接入名义库存与周转天数** | 同上 | 全国工业产成品存货是名义余额，不是实物数量；优先采用官方可比同比，不能用两个余额重算同比 |
| 工业产能利用率 | **V1 可自动接入** | 国家统计局季度正式发布及 XLSX | 季频且未经季节调整；当前可一致回填的正式季度发布序列从 2017Q1 起审计 |
| 信用结构 | **V1 可自动接入** | 人民银行金融机构人民币信贷收支表、社融增量／存量表 | 官方表是月末存量和社融分项；月度贷款增量与信用脉冲是项目派生量，必须另标 |
| USD/CNY 中间价 | **V1 可自动接入** | 人民银行中间价公告；CFETS 为上游发布机构 | 中间价是 9:15 官方定盘，不是在岸成交收盘价 |
| USD/CNY 16:30 在岸收盘价 | **V1 仅人工核验或持牌接入** | CFETS／中国货币网 | CFETS 明确要求市场数据保存、使用和处理取得授权；未取得书面授权前不自动持久化 |

这些指标全部只属于政策行动、转折观察、阶段特征卡或宏观事后确认；按照 [ADR-0001](../adr/0001-price-only-formal-pring-stage.md) 和 [ADR-0003](../adr/0003-ai-explains-but-does-not-classify.md)，它们不得改写三类核心资产价格机械映射出的正式阶段。

## 2. 统一的点时取数规则

官方页面通常同时存在“统计期”“页面发布时间”和“数据库更新时间”，三者不能混用。每个适配器至少保存：

```text
indicator_id
observation_period
release_at              # 官方页面标示的实际发布时间；没有时为空
available_at            # 本系统首次成功取得并通过校验的时间
fetched_at
value
unit
frequency
vintage_id
provider                 # 例如 pbc_html、nbs_xlsx
upstream_authority       # PBOC、NBS 或 CFETS
source_url
content_hash
quality_status
```

运行规则如下：

1. `next_expected_release` 可以来自官方年度日程，但不能当成 `release_at`。国家统计局明确说日程只是初步计划，可能调整；其数据发布库约在新闻发布后 3 个工作日更新，因此新闻发布页和数据库是两个不同的可用时点。[国家统计局 2026 年发布日程](https://www.stats.gov.cn/xw/tjxw/tzgg/202512/t20251224_1962137.html) 本次环境实测 `data.stats.gov.cn` 动态查询请求返回 HTTP 403（`UrlACL`），所以 V1 以首发 HTML 和同页 XLSX 为主源，国家数据只作为延迟对账源；403 是本次运行时观测，不代表国家统计局的普遍访问政策。
2. 页面没有可靠发布时间时，`release_at` 留空，使用首次成功取得的 `available_at`，禁止把附件路径中的时间戳当成正式发布时间。
3. 官方栏目页或年度表可能原 URL 就地替换附件。首次取得后保存原始响应、内容哈希和字段映射版本；内容变化生成新 `vintage_id`，不覆盖旧观测。
4. 当前刷新只允许严格字段白名单、统计期校验、单位校验和表头哈希校验。正文正则未命中时转人工核验，不从新闻摘要猜值。
5. 历史回放只使用当时已可得的 vintage；后来的数据库回填或修订不得提前进入历史时点。

## 3. 央行政策行动

### 3.1 7 天逆回购、政策利率与操作量

人民银行的[公开市场业务交易公告栏目](https://www.pbc.gov.cn/zhengcehuobisi/125207/125213/125431/125475/index.html)是首选事件流。栏目当前公开 3,700 余条公告，最早可追溯到 2004 年 1 月；一条当前格式公告直接给出期限、操作利率、投标量和中标量，并带页面发布时间。[2025 年第 252 号公告](https://www.pbc.gov.cn/zhengcehuobisi/125207/125213/125431/125475/2025122608571540479/index.html)

V1 字段：

| 字段 | 单位／类型 | 统计期与频率 | 真实可用时点 |
| --- | --- | --- | --- |
| `operation_date` | 日期 | 每次操作／交易日 | 公告页面实际发布时间后 |
| `operation_type` | 枚举 | 逆回购、买断式逆回购、MLF 等 | 同上 |
| `tenor_days` | 天 | 每次操作 | 同上 |
| `operation_rate_pct` | % | 每次操作 | 同上；7 天逆回购操作利率的政策利率地位自 2024 年强化，历史上不能把所有期限都称为主要政策利率 |
| `bid_amount_100m` | 亿元 | 有该字段时 | 同上 |
| `awarded_amount_100m` | 亿元 | 每次操作 | 同上 |
| `auction_method` | 枚举／原文 | 固定利率、数量招标等 | 同上 |
| `maturity_date` | 日期，派生 | 按操作日和期限派生并按交易日规则复核 | 只能在原操作公告已可得后派生 |

公告页面没有稳定、正式的公开 API，但 HTML 表格结构清晰，当前刷新机器提取可行性高。历史格式出现过字段名、期限和操作类型变化，因此回填解析器要按年份／表头版本分支，不能用一个正则扫全历史。公告未提供正式修订日志；页面内容变化以内容哈希生成新 vintage。

“逆回购净投放”只能从已认证的操作及到期账本派生，字段名必须标为 `derived_repo_net_injection`。如果页面要展示全工具净投放，优先采用人民银行自 2025 年 6 月起新增的月度栏目；[2025 年第二季度货币政策执行报告](https://www.pbc.gov.cn/zhengcehuobisi/125207/125227/125957/f5c4690f2cbd40918bf24c2d39ac58af/b3e8c1a2b07d4facb38f4a7426415252/2025081819132397368.pdf)说明该栏目在 6 月初增设、每月月初披露上月数据。月表按工具列出投放、回笼和净投放，单位为亿元。[2025 年 12 月各项工具流动性投放表](https://www.pbc.gov.cn/zhengcehuobisi/125207/125213/5727710/2026010517563068096/index.html) 该月频序列历史很短，更早时期暂不构造“全工具官方净投放”长序列。

### 3.2 降准

降准使用人民银行正式公告或人民银行文告。事件至少保存：

| 字段 | 单位／类型 | 说明 |
| --- | --- | --- |
| `announced_at` | 时间 | 页面正式发布时间；是市场首次知道政策的时点 |
| `effective_date` | 日期 | 实际生效日；不能代替公告时点 |
| `rrr_change_pp` | 百分点 | 上调为正、下调为负；保留原文方向 |
| `institution_scope` | 枚举＋原文 | 全面、定向、机构例外等 |
| `post_change_rrr_pct` | %，可空 | 只在公告明确给出时记录 |
| `released_funds_100m` | 亿元，可空 | 只在公告明确给出时记录，不从媒体估算 |

[2012 年 2 月降准公告](https://www.pbc.gov.cn/zhengcehuobisi/125207/125213/125434/125798/2858069/index.html)在 2012-02-18 20:00 公告、2012-02-24 生效，证明这两个时点必须分开。公开页面可免登录访问，但降准是不规则事件，历史措辞和适用机构差异大。V1 自动监控新公告；历史事件表从至少 2012 年起回填后逐条人工核验，定向降准保留机构范围，不压成一个全国统一序列。

### 3.3 MLF 与 LPR 边界

中期借贷便利使用人民银行[MLF 官方栏目](https://www.pbc.gov.cn/zhengcehuobisi/125207/125213/125437/125446/index.html)，历史从 2014 年起。V1 保存操作／招标公告发布时间、操作日、期限、操作量（亿元）、到期量、期末余额和 `auction_regime`；机器提取可行，但公告与月度操作表需分别解析。2025 年 3 月起 MLF 改为固定数量、利率招标、多重价位中标，人民银行[货币政策执行报告](https://www.pbc.gov.cn/zhengcehuobisi/125207/125227/125957/f5c4690f2cbd40918bf24c2d39ac58af/2025091218344076234/2025081517321679368.pdf)明确说明取消统一中标利率。因此 `operation_rate_pct` 在新机制下必须为空，不能为维持长序列而虚构一个单一 MLF 利率。

LPR 是报价行基于公开市场操作利率等形成的贷款市场报价利率，不是一次央行投放或回笼行动；若后续接入，只能归入政策传导指标并保存 2019 年 8 月形成机制断点，不能混进本票的央行操作事件表。

## 4. 核心 CPI

核心 CPI 的一手来源是国家统计局每月 CPI 正式发布。表内字段名为“不包括食品和能源”；当前 HTML 和同页 XLSX 同时给出环比、同比和年初至当月平均同比。例如[2026 年 6 月正式发布](https://www.stats.gov.cn/sj/zxfb/202607/t20260709_1964084.html)在 2026-07-09 09:30 发布，三列分别为 -0.1%、1.0% 和 1.2%。官方解读正文可用于交叉验证，但不是主解析源。

| 字段 | 单位 | 频率／统计期 | V1 要求 |
| --- | --- | --- | --- |
| `core_cpi_yoy_pct` | % | 月度／自然月 | 必填；严格匹配“不包括食品和能源”行与“同比”列 |
| `core_cpi_mom_pct` | % | 月度／自然月 | 必填；严格匹配同一行的“环比”列 |
| `core_cpi_ytd_avg_yoy_pct` | % | 月度／年初至当月 | 必填；保存官方累计平均同比，不用月度同比算术平均替代 |
| `service_cpi_yoy_pct` | % | 月度／自然月 | 可选支持字段；不能代替核心 CPI |
| `service_cpi_mom_pct` | % | 月度／自然月 | 可空 |

国家统计局年度日程把 CPI 月报安排在次月约 9:30，实际页面时间才是 `release_at`。机器提取可行性高：正式表与同页附件公开、免登录；解析器必须用“统计期＋不包括食品和能源行＋环比／同比／累计列”校验，旧版页面表头未唯一命中时转人工核验。

[国家统计局 2013 年政府信息公开工作报告](https://www.stats.gov.cn/xxgk/gknb/tjj_gknb/202006/t20200612_1758485.html)明确记载当年新增核心 CPI 发布；[2013 年 12 月正式发布表](https://www.stats.gov.cn/sj/zxfb/202302/t20230203_1898425.html)已有“不包括食品和能源”行，而[2012 年 12 月正式发布表](https://www.stats.gov.cn/sj/zxfb/202302/t20230203_1898248.html)没有。因此官方公开历史起点定为 2013 年，首次回填逐月做完整性检查。页面未提供逐值修订日志；CPI 每五年轮换基期，2026 年起采用 2025 年基期，分类、代表规格品、网点和权数均有调整，所以保存原始响应、内容哈希与 `base_period_version`，不静默覆盖首发值。

## 5. 工业增加值、利润、库存与产能

### 5.1 规模以上工业增加值

国家统计局工业生产正式发布同时提供 HTML 表格和“相关数据表”下载。当前发布明确说明，同比增速是扣除价格因素的实际增速，规模以上工业企业范围每年变化；环比增速会根据季节调整模型自动修订此前月份。[2026 年 6 月工业增加值发布](https://www.stats.gov.cn/sj/zxfbhjd/202607/t20260715_1964123.html)

| 字段 | 单位 | 频率／统计期 | 修订与口径 |
| --- | --- | --- | --- |
| `industrial_va_yoy_real_pct` | % | 月度／当月 | 官方可比价实际同比；不得由绝对量重算 |
| `industrial_va_ytd_yoy_real_pct` | % | 月度／年内累计 | 累计值单独存储 |
| `industrial_va_mom_sa_pct` | % | 月度／当月 | 季调环比；每次发布随模型滚动修订，保留 vintage |
| `industrial_va_sector_yoy_pct` | % | 月度／当月 | 采矿、制造、电热燃水及白名单行业 |
| `product_sales_ratio_pct` | % | 月度／当月 | 产销衔接支持字段 |

该数据通常随“国民经济运行情况”在次月中旬约 10:00 发布；1 月数据免报，3 月发布 1—2 月累计和 2 月／1—2 月对应口径，不能制造不存在的 1 月单月值。国家统计局官网的正式发布档案至少覆盖 2012 年月度数据，足以开始十年以上回填，但 2011 年规模以上工业门槛调整和后续调查范围变化必须登记为口径事件。HTML/XLSX 免登录，机器提取可行性高。

### 5.2 工业利润与工业库存

国家统计局“规模以上工业企业利润”正式发布在同一份 HTML/XLSX 中提供利润、营业收入、营业成本、产成品存货和周转天数。[2026 年 1—6 月工业企业利润发布](https://www.stats.gov.cn/sj/zxfbhjd/202607/t20260727_1964194.html)

| 字段 | 单位 | 频率／统计期 | V1 处理 |
| --- | --- | --- | --- |
| `industrial_profit_ytd_100m` | 亿元 | 月度／年内累计 | 正式表必取 |
| `industrial_profit_ytd_yoy_pct` | % | 月度／年内累计 | 采用官方可比同比 |
| `industrial_profit_month_yoy_pct` | % | 月度／当月 | 可选；只在正文明确给出时记录 |
| `industrial_revenue_ytd_100m`、`industrial_cost_ytd_100m` | 亿元 | 月度／年内累计 | 用于利润率和成本压力解释 |
| `finished_goods_inventory_100m` | 亿元 | 月末 | 名义余额，不称实物库存 |
| `finished_goods_inventory_yoy_pct` | % | 月末 | 使用官方可比同比，不用两个余额自行重算 |
| `finished_goods_turnover_days` | 天 | 月末／累计公式 | 与名义存货共同判断库存压力 |
| `finished_goods_turnover_days_yoy_change` | 天 | 月末 | 官方披露的同比增减 |

正式表的利润、收入和成本以年内累计为主；正文偶尔补充单月利润同比，解析失败不影响累计字段入库。1 月财务报表免报，通常从 1—2 月累计开始。发布多在次月 27 日 9:30 左右，必须以当期页面时间为准。

利润、收入等增速按可比口径计算。国家统计局明确说企业调查范围每年调整，也会因统计执法、基数修正和去重改变可比基数，所以本期与上年发布的名义金额不能直接计算同比。V1 保存官方同比、调查范围说明和内容 vintage。官方发布档案可支持利润长历史；当前所需“名义产成品存货＋周转天数”组合至少可从 2015 年一致回填，满足十年以上目标。HTML/XLSX 免登录，机器提取可行性高。

这里仍有一个明确的暂缺：全国规模以上工业“实物数量库存”不是这份财务表的字段。V1 只把 `finished_goods_inventory_100m` 标为名义产成品存货，并用周转天数与 PMI 库存交叉验证；不能把名义余额除以 PPI 后宣称得到官方实物库存。

### 5.3 工业产能利用率

国家统计局按季公布全国、三大门类和主要行业的产能利用率；指标是实际产出与生产能力（均按价值量）的比率，调查未经季节调整。[2026 年二季度产能利用率发布](https://www.stats.gov.cn/sj/zxfbhjd/202607/t20260715_1964130.html)

| 字段 | 单位 | 频率／统计期 | 说明 |
| --- | --- | --- | --- |
| `industrial_capacity_utilization_pct` | % | 季度／当季 | 全国规模以上工业 |
| `industrial_capacity_utilization_yoy_change_pp` | 百分点 | 季度／当季 | 与上年同期比较 |
| `industrial_capacity_utilization_ytd_pct` | % | 季度／年内累计 | 页面有该列时记录 |
| `industry_capacity_utilization_pct` | % | 季度／当季 | 只接入冻结行业白名单 |

一、二、三、四季度通常在季后国民经济发布日 10:00 公布，实际页面时间为准。HTML/XLSX 免登录，机器提取可行性高。国家统计局[指标沿革说明](https://www.stats.gov.cn/zs/tjws/tjzb/202301/t20230101_1903791.html)记载年度调查从 2006 年开始、2017 年四季度开始常规公布季度数据；当前官方季度数据覆盖从 2017Q1 起。年度结果和季度序列不得无缝拼接，也不能据年度值伪造 2017 年前季度历史。页面没有稳定的历史修订表，调查范围、样本量和行业分类变化按 vintage 保存。

## 6. 信用结构

### 6.1 人民币贷款结构

人民银行[统计数据总目录](https://www.pbc.gov.cn/diaochatongjisi/116219/116319/index.html)按年份发布金融机构信贷收支统计。当前年份页面同时提供 HTML、XLSX 和 PDF；[2026 年金融机构信贷收支统计](https://www.pbc.gov.cn/diaochatongjisi/116219/116319/2026ntjsj/jrjgxdsztj/index.html)可直接机器提取。

V1 从“金融机构人民币信贷收支表”取得以下月末存量，单位均为亿元：

- 住户贷款总额、短期贷款、中长期贷款；
- 企（事）业单位贷款总额、短期贷款、中长期贷款、票据融资；
- 非银行业金融机构贷款；
- 人民币各项贷款总额。

频率为月度，统计期为月末。`monthly_change_100m`、同比和结构占比只有在同口径前值已验证后由项目派生，必须标记 `calculation_method`，不能称为人民银行原生字段。目标交叉分类从 2015 年年度表起可一致回填超过十年；更早年度表虽有贷款期限和部门数据，但表结构不同，不自动拼接。

人民银行还发布自然语言“金融统计数据报告”。例如[2024 年 7 月报告](https://www.pbc.gov.cn/diaochatongjisi/116219/116225/8980a8a6f1414f649d3443cc09352c2b/index.html)于 2024-08-13 17:01 发布，包含年初至当期的住户／企业短期、中长期和票据融资增量，并明确当期数据是初步数。该报告用于取得真实 `release_at` 和交叉核对，结构化存量以 HTML/XLSX 为主。人民银行没有固定到某日某时的年度发布日程，因此定时任务在月后工作日轮询栏目，首次成功取得写入 `available_at`。

年度栏目与附件公开、免登录，但旧文件使用 GB2312 和 Excel 导出的 HTML，表头也会变化；解析器需要编码检测、字段别名表和表头哈希。数据被标为初步数，且 2015、2023 等年份存在统计范围调整，必须保存原始附件和 vintage。

### 6.2 社会融资结构

人民银行[2026 年社会融资规模页面](https://www.pbc.gov.cn/diaochatongjisi/116219/116319/2026ntjsj/shrzgm/index.html)同时给出增量与存量表的 HTML/XLSX/PDF。V1 至少接入：

| 类型 | 字段 | 单位／频率 |
| --- | --- | --- |
| 增量 | 社融总量、人民币贷款、外币贷款折人民币、委托贷款、信托贷款、未贴现银行承兑汇票、企业债券、政府债券、非金融企业境内股票融资、存款类机构 ABS、贷款核销 | 亿元／月度流量 |
| 存量 | 社融存量总额及上述可用分项的期末余额、同比增速 | 万亿元或亿元及 %／月末；严格按表内单位 |

人民银行从 2011 年起正式编制发布社融，现有[官方历史数据说明](https://www.pbc.gov.cn/goutongjiaoliu/113456/113469/2863557/2021122418533735135.pdf)可将流量回溯到 2002 年；项目直接使用的逐年结构化目录从 2012 年起可回填。官方注释记录了统计口径扩展，例如 2018 年纳入地方政府专项债、存款类机构 ABS 和贷款核销，2019 年调整企业债券和政府债券范围；因此保存 `methodology_version`，不要跨口径直接比较分项。信用脉冲不是人民银行字段，只能在 V1 指标目录冻结公式、GDP 分母 vintage 和年化方式后派生。

## 7. 官方在岸人民币汇率

### 7.1 USD/CNY 中间价

人民银行[人民币汇率中间价公告栏目](https://www.pbc.gov.cn/zhengcehuobisi/125207/125217/125925/index.html)和独立历史栏目公开每日公告。美元、欧元、日元和港币的官方可查询起点为 2006-01-04，中国货币网的[带电子签名汇价查询说明](https://www.chinamoney.com.cn/chinese/hjcxfw/)也确认了这一历史边界。

| 字段 | 单位／方向 | 频率／统计期 | 可用时点 |
| --- | --- | --- | --- |
| `usd_cny_central_parity` | 1 美元兑人民币元 | 每个工作日／当日 | CFETS 受权于 9:15 公布；PBC 适配器以人民银行页面首次成功取得为 `available_at` |
| `currency_pair` | `USD/CNY` | 同上 | 同上 |
| `quote_direction` | `CNY per USD` | 同上 | 防止与“人民币 1 元兑外币”字段混向 |

[人民银行 2025-05-07 公告](https://www.pbc.gov.cn/zhengcehuobisi/125207/125217/125925/5699853/index.html)带 09:25:54 页面时间并给出 1 美元兑人民币数值；[人民银行／外汇局公告](https://www.pbc.gov.cn/chubanwu/114566/114579/4533165/4834545/2023033009003384902.pdf)确认中间价由 CFETS 每个工作日上午 9:15 对外公布。HTML 免登录、字段稳定，机器提取可行性高；无正式逐值修订日志，仍保存页面哈希和首次取得时间。

中间价是官方定盘，不是在岸市场收盘成交价。页面和报告必须显示完整名称，禁止把它简称为“USD/CNY 收盘”。

### 7.2 16:30 在岸收盘价

> 2026-09-25：本节“不自动持久化”的结论已由用户选择推翻（本机个人使用、不对外分发），见 [ADR-0029](../adr/0029-p2-quote-sources-and-warrant-members.md)。

人民银行和外汇局公告确认，银行间人民币外汇市场虽已延长交易至次日 3:00，CFETS 仍在北京时间 16:30 发布人民币对美元即期收盘价。[延长银行间外汇市场交易时间公告](https://www.pbc.gov.cn/chubanwu/114566/114579/4533165/4834545/2023033009003384902.pdf)

但 CFETS 的[市场数据服务说明](https://www.chinamoney.com.cn/english/svcmds/)明确表示，机构或个人保存、使用、传播或处理 CFETS 市场数据应申请并取得书面许可。V1 未取得相应授权前：

- 不自动抓取或持久化 `USD/CNY 16:30 close` 历史；
- 页面只展示已获授权供应商返回的明确在岸代码，或标记 `manual_verification_required`；
- 不用 FXCM 离岸 `USDCNH`、中间价或当日末笔海外报价静默替代；
- 将授权状态作为数据源配置而不是运行时搜索判断。

因此，V1 的无授权官方直连只承诺 `usd_cny_central_parity`。真正的在岸市场收盘序列在取得 CFETS 书面授权或采购有再使用权的数据源前属于人工核验／暂缺自动化。

## 9. 对 V1 指标目录的直接约束

1. 冻结 `core_cpi_yoy_pct`、`core_cpi_mom_pct` 和 `core_cpi_ytd_avg_yoy_pct` 为正式表字段；解析失败时置为人工核验状态，不设置“缺失即 0”。
2. 工业利润、收入和成本默认使用年内累计；只有官方正文明确披露时才增加单月利润同比观测。
3. 库存卡同时保留名义产成品存货同比和周转天数；字段名、页面文案和 AI 证据包均不得写“实物库存”。
4. 信用结构的官方原始层使用月末存量和社融分项；月增量、结构占比、信用脉冲分别登记项目派生公式和版本。
5. 政策行动分别建模公告时点、操作／生效时点和市场传导，不能混成一个“宽松分数”。
6. 官方汇率至少拆成 `USD/CNY 中间价` 和 `USD/CNY 16:30 在岸收盘价`；无授权时后者为空，离岸 `USDCNH` 只能作为不同的解释指标。
