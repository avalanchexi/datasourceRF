## 1. 本次裁决遵循的既定约束

[ADR-0013](../adr/0013-tushare-delivery-with-official-sampling.md)允许使用官方样本核对 TuShare 的交付语义、字段、单位、统计期、发布时间和许可；不要求每条正式观测具备第二来源，但 family 认证条件必须实际满足。[CONTEXT 第 161–190 行](../../GLOSSARY.md)区分实际公开、系统取得、预期发布窗口及真实发布事件：有可靠发布日期但没有时分时，适用下一本地日的既定保守规则；没有可靠日期时保持空值。

因此，下列四种事实不能直接替换为历史 `public_available_at`：业务规则中的发布时间安排、网页统计日期、文件名中的日期、当前请求完成时间。下载原件不表示相应指标已经认证。

## 2. 北交所入口、汇总范围与发布安排

### 2.1 当前官方入口的可核查内容及本机阻断

[北交所融资融券交易信息页](https://www.bse.cn/disclosure/rzrq_trans_list.html)的官方页面检索内容包含总量表头，融资买入额与融资余额单位为**万元**。说明区区分了当前标的明细与汇总：汇总还含已调出标的股票的余额余量。此处没有取得 2026-08-28 数值行，也未取得能验证舍入方式或元级精度的原始响应；不能只凭表头批准数值转换或用当前标的明细求和替代总量。

在前轮 urllib 同路径两次重定向循环的基础上，本轮改用正常 Chrome 访问 `https://www.bse.cn/`。浏览器清单已显示官方首页标题，随后读取该页的 CUA 调用发生工具超时，返回等待约 1488 秒；没有获得日期查询后的可见数值、页面 JS 或下载附件。web 读取融资页及业务指南页仍报告重定向循环。本次未解验证码、导出 cookie、关闭安全检查或寻找源站 IP。

### 2.2 查到官方备用域名，但不能称它已经可用

全国中小企业股份转让系统的[2026–2029 年 CDN 和数字证书采购公告](https://www.china-tender.com.cn/zbfw/137635.jhtml)由采购信息平台公开发布，正文明确北交所官网主用域名为 `*.bse.cn`，备用域名为 `*.bseinfo.net`。这是备用域名与交易所系统的权属依据，原公告已保存为 R4。

对搜索中实际存在的[备用站交易公开信息页](https://www.bseinfo.net/disclosure/tradepublic.html)做了一次 web 读取，仍发生重定向循环。没有猜测后台路由或利用备用域名绕过身份、授权或验证码；本轮没有得到备用站融资原件。后续若正常网页恢复，可从可见官方导航进入融资页，核实它实际使用的查询与下载入口。

### 2.3 官方规则提供预期窗口，不能证明每次实际首发

[《北京证券交易所融资融券业务指南》发布页](https://www.bse.cn/jygl_list/200013680.html)的官方检索内容标示公告日期 2022-11-11、北证公告〔2022〕40号，并展示这些条款：

- 6.1.3–6.1.4：会员交易日 22:00 前完成数据报送、校验及重报；调出标的后仍继续报送尚未了结业务。
- 6.1.5：逾时报送的补报窗口延至下一交易日 15:00；补报数据仅用于监管，不改变已经披露的数据。
- 7.1：交易所每个交易日开市前，根据会员报送数据公布前一交易日的单股信息与市场总量。

这些条款说明信息不是简单在交易日收盘时完整发布，也给出了区分原公开版本与后续监管补报的理由。本轮只取得官方页面的检索文本，直接原页读取失败，**没有可落盘的业务指南原始 HTML/PDF 哈希**；不能把搜索结果内容的哈希伪装为官方附件。

即使原件随后取得，7.1 仍是发布安排，不是 120 次实际发布记录。以 2026-08-28（周五）为例，规则指向下一交易日开市前这一预期窗口；它不能独自证明该条在 08-31 的某时刻首次可得，也不能确认当前下载版本与最初披露版本相同。本轮没有据此填充任何时间字段。

## 4. 这份原件的时间信息为什么仍不够

同一条中证数据目录及 XLSX 提供了以下不同信息，原件分别是 R1/R2：

| 信息位置 | 实际值 | 可支持的事实及限制 |
|---|---|---|
| 目录可见日期与标题 | 2026-08-28 / `融资融券市场每日数据统计20260828` | 与统计日期一致；没有证明这是首次发布日期。 |
| 目录 `aisite-article-file` 属性 | `cmsmc,d1c3478a84f34f56872c7d954b284199,2026-08-28 08:00:00` | 未取得该属性代表实际公开时间的官方定义；不能把当天开盘前的时间用于当天完整融资数据。 |
| 目录链接 `download` 属性 | `2026083108000006458.xlsx` | 是建议下载名；不能仅按数字拆出可信首发时刻。 |
| XLSX `docProps/core.xml` 创建时间 | `2026-08-30T23:30:01Z`（北京时间 08-31 07:30:01） | 文件内部生成元数据；不等于已向公众发布。 |
| XLSX HTTP `Last-Modified` | `Sun, 30 Aug 2026 23:54:01 GMT`（北京时间 08-31 07:54:01） | 服务器文件修改时间；可能与发布有关，但没有证明它是第一次公开或不可变历史版本。 |
| 本轮下载完成 | 2026-09-05 12:49:30.197267 UTC | 证明本轮取得了该内容，不能反向建立 08-31 的实际公开事件。 |

文件生成时间及下载名与周五数据在下周处理的安排相容，但这是推断，不是实际发布时间核验通过。尤其不能选择看起来最合理的时间字段填入 `public_available_at`，也不能把一日文件的元数据外推为 120 日统一发布时间。

该站有当前每日目录和[历史数据目录](https://www.csdata.cn/cmsmc/cgfb/rzrqsj/rzrqsclssj/rzrqscmrsjtj/index.html)，可继续发现日文件；但取得 120 个文件本身不会消除上述时间身份问题。本次没有为没有实际发布时间证据的条目伪造 120 日公开事件链。
