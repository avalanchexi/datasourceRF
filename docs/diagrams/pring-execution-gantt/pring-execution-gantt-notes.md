## 复现

在项目根目录执行：

```bash
node .scratch/pring-execution-gantt/render.mjs
```

这会使用已保存的 JSON 快照和本机 Archify 重新生成本次图表。`ARCHIFY_ROOT` 可指定其他 Archify 包目录。采集脚本为 `.scratch/pring-execution-gantt/build_data.py`，包含固定提交和取证逻辑；为保持进行中项的原始盘点口径，应优先重用已保存的 JSON。

HTML 与 SVG 使用系统中文字体；Windows 可使用微软雅黑。WSL 检查通过本任务新增的 `fonts.conf` 只读引用 Windows 字体，不安装或改动系统字体。
